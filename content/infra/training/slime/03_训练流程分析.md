# Slime 训练流程实现原理

> **【源码定位】** `slime/backends/megatron_utils/model.py`, `slime/backends/megatron_utils/loss.py`  
> **【阅读建议】** 需理解 PyTorch backward hook、Megatron Pipeline 并行  
> **【前置知识】** PPO/GRPO 算法原理、GAE 优势估计、混合精度训练基础

## 1. 模块概述

训练流程模块实现了 Slime 框架的**核心训练逻辑**，包括训练循环、损失计算、学习率调度以及混合精度训练。该模块支持 **PPO、GRPO、SFT、On-Policy Distillation** 等多种算法，并与 Megatron-LM 的并行训练框架深度集成。

**关键设计决策【重点】**：
1. **Pipeline 并行兼容**：训练循环支持 Megatron PP 的多阶段前向/反向
2. **动态损失计算**：根据 rollout 数据中的 `loss_mask` 灵活计算策略损失
3. **多算法统一**：通过 `loss_type` 参数切换 PPO/GRPO/SFT 等算法
4. **梯度累积**：支持 `num_microbatches > 1` 的梯度累积训练

## 2. 训练循环架构

### 2.1 整体训练流程

```
┌─────────────────────────────────────────────────────────────────┐
│                    训练主循环                                    │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  for rollout_id in range(num_rollout):                          │
│      │                                                          │
│      ├─> [阶段1] Rollout 数据生成                               │
│      │      rollout_data = rollout_manager.generate()           │
│      │          │                                               │
│      │          ├─> 前向推理获取 log_probs                      │
│      │          ├─> 计算 reward                                 │
│      │          └─> 计算 advantages (Critic)                    │
│      │                                                          │
│      ├─> [阶段2] Critic 训练（可选）                             │
│      │      if use_critic:                                      │
│      │          critic_model.train(rollout_data)                │
│      │                                                          │
│      ├─> [阶段3] Actor 训练                                     │
│      │      actor_model.train(rollout_data)                     │
│      │          │                                               │
│      │          └─> train() -> train_one_step() x N             │
│      │                                                          │
│      ├─> [阶段4] 权重同步                                       │
│      │      actor_model.update_weights()                        │

│             if should_save(rollout_id):                         │
│                 actor_model.save_model()                        │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 2.2 单步训练实现

```python
def train_one_step(args, rollout_id, step_id, data_iterator, model, optimizer, opt_param_scheduler, num_microbatches):
    """执行单个训练步骤

    流程：
    1. 清零梯度
    2. 构建前向步骤函数
    3. 执行 Pipeline 并行的前向-反向
    4. 检查梯度有效性
    5. 优化器更新
    6. 学习率调度
    """

    # 1. 清零梯度
    for model_chunk in model:
        model_chunk.zero_grad_buffer()
    optimizer.zero_grad()

    # 2. 构建前向步骤函数
    def forward_step(data_iterator, model, return_schedule_plan=False):
        batch = get_batch(data_iterator, [
            "tokens", "loss_masks", "log_probs", "ref_log_probs",
            "values", "advantages", "returns", "rollout_log_probs",
        ])

        # 前向传播
        output_tensor = model(
            input_ids=batch["tokens"],
            packed_seq_params=batch["packed_seq_params"],
            loss_mask=batch["full_loss_masks"],
        )

        # 返回输出和损失计算函数
        return output_tensor, partial(loss_function, args, batch, num_microbatches)

    # 3. Pipeline 并行的前向-反向
    forward_backward_func = get_forward_backward_func()
    losses_reduced = forward_backward_func(
        forward_step_func=forward_step,
        data_iterator=data_iterator,
        model=model,
        num_microbatches=num_microbatches,
        forward_only=False,
    )

    # 4. 检查梯度有效性
    valid_step = True
    if not args.check_for_nan_in_loss_and_grad:
        found_inf_flag = optimizer.prepare_grads()
        if found_inf_flag:
            valid_step = False

    # 5. 优化器更新
    if valid_step:
        update_successful, grad_norm, num_zeros_in_grad = optimizer.step()
        # 6. 学习率调度
        opt_param_scheduler.step(increment=args.global_batch_size)

    return loss_reduced, grad_norm
```

### 2.3 完整 train() 函数

```python
def train(rollout_id, model, optimizer, opt_param_scheduler, data_iterator, num_microbatches):
    """执行一个完整 rollout 的训练

    包含训练模式切换、钩子配置、梯度累积等
    """
    args = get_args()

    # 重置数据迭代器
    for iterator in data_iterator:
        iterator.reset()

    # 切换到训练模式
    for model_module in model:
        model_module.train()

    # 配置训练参数
    config = get_model_config(model[0])
    config.grad_scale_func = optimizer.scale_loss

    # 梯度同步重叠配置
    if args.overlap_grad_reduce:
        config.no_sync_func = [model_chunk.no_sync for model_chunk in model]
        if args.align_grad_reduce:
            config.grad_sync_func = [model_chunk.start_grad_sync for model_chunk in model]

    # 参数同步重叠配置
    if args.overlap_param_gather and args.align_param_gather:
        config.param_sync_func = [model_chunk.start_param_sync for model_chunk in model]

    # 手动垃圾回收（对齐各 rank）
    if args.manual_gc:
        gc.disable()
        gc.collect()

    # 训练迭代
    for step_id in range(num_steps_per_rollout):
        loss_dict, grad_norm = train_one_step(
            args, rollout_id, step_id, data_iterator,
            model, optimizer, opt_param_scheduler, num_microbatches[step_id]
        )

        # 日志记录
        if is_primary_rank:
            log_dict = {f"train/{key}": val for key, val in loss_dict.items()}
            log_dict["train/grad_norm"] = grad_norm
            logging_utils.log(args, log_dict, step_key="train/step")
```

## 3. 前向推理 (Forward Only)

### 3.1 用途

前向推理用于计算 Rollout 阶段需要的 log_probs 和 values：

```python
def forward_only(f, args, model, data_iterator, num_microbatches, store_prefix=""):
    """仅前向传播，不计算梯度

    用途：
    - 计算当前策略的 log_probs
    - 计算 Critic 的 value 预测
    - 计算 Reference 模型的 log_probs
    """

    # 切换到评估模式
    for model_module in model:
        model_module.eval()

    def forward_step(data_iterator, model):
        batch = get_batch(data_iterator, [
            "tokens", "loss_masks", "multimodal_train_inputs",
            "total_lengths", "response_lengths",
        ])

        output_tensor = model(
            input_ids=batch["tokens"],
            packed_seq_params=batch["packed_seq_params"],
            loss_mask=batch["full_loss_masks"],
        )

        # 使用回调函数处理输出
        return output_tensor, partial(
            f,  # get_log_probs_and_entropy 或 get_values
            args=args,
            unconcat_tokens=batch["unconcat_tokens"],
            total_lengths=batch["total_lengths"],
            response_lengths=batch["response_lengths"],
        )

    # 执行前向传播（不计算梯度）
    forward_data_store = []
    for step_id in range(num_steps_per_rollout):
        forward_data_store += forward_backward_func(
            forward_step_func=forward_step,
            data_iterator=data_iterator,
            model=model,
            num_microbatches=num_microbatches[step_id],
            forward_only=True,  # 关键：仅前向
        )

    # 恢复训练模式
    for model_module in model:
        model_module.train()

    return rollout_data
```

## 4. 损失函数实现

### 4.1 损失函数分发

```python
def loss_function(args, batch, num_microbatches, logits):
    """损失函数分发入口

    根据 --loss-type 选择对应的损失函数
    """
    match args.loss_type:
        case "policy_loss":
            func = policy_loss_function
        case "value_loss":
            func = value_loss_function
        case "sft_loss":
            func = sft_loss_function
        case "custom_loss":
            func = load_function(args.custom_loss_function_path)

    # 支持梯度检查点
    if args.recompute_loss_function:
        loss, log = checkpoint(func, args, batch, logits, sum_of_sample_mean)
    else:
        loss, log = func(args, batch, logits, sum_of_sample_mean)

    # 损失缩放（与 Megatron 集成）
    if not args.calculate_per_token_loss:
        loss = loss * num_microbatches / global_batch_size * dp_size

    return loss, normalizer, logging_dict
```

### 4.2 Policy Loss (PPO)

```python
def policy_loss_function(args, batch, logits, sum_of_sample_mean):
    """PPO 策略梯度损失

    核心公式：
    ratio = exp(log_prob - old_log_prob)
    surr1 = ratio * advantage
    surr2 = clip(ratio, 1-eps, 1+eps) * advantage
    pg_loss = -min(surr1, surr2)
    """

    # 1. 获取数据
    advantages = torch.cat(batch["advantages"], dim=0)
    old_log_probs = batch["log_probs"]

    # 2. 计算当前 log_probs
    log_probs_and_entropy = get_log_probs_and_entropy(logits, args=args, ...)
    log_probs = log_probs_and_entropy["log_probs"]

    # 3. 计算 PPO KL
    ppo_kl = old_log_probs - log_probs
    ratio = torch.exp(ppo_kl)

    # 4. PPO Clip
    surr1 = ratio * advantages
    surr2 = torch.clamp(ratio, 1 - args.eps_clip, 1 + args.eps_clip) * advantages
    pg_loss = -torch.min(surr1, surr2)

    # 5. 裁剪比例统计
    pg_clipfrac = ((ratio - 1).abs() > args.eps_clip).float()

    # 6. 熵奖励
    entropy = log_probs_and_entropy["entropy"]
    entropy_loss = sum_of_sample_mean(entropy)

    # 7. 总损失
    loss = sum_of_sample_mean(pg_loss) - args.entropy_coef * entropy_loss

    # 8. KL 损失（可选）
    if args.use_kl_loss:
        ref_log_probs = batch["ref_log_probs"]
        kl = compute_approx_kl(log_probs, ref_log_probs, kl_loss_type=args.kl_loss_type)
        kl_loss = sum_of_sample_mean(kl)
        loss = loss + args.kl_loss_coef * kl_loss

    return loss, {
        "loss": loss,
        "pg_loss": pg_loss,
        "entropy_loss": entropy_loss,
        "pg_clipfrac": pg_clipfrac,
        "ppo_kl": ppo_kl,
    }
```

### 4.3 Value Loss (带裁剪)

```python
def value_loss_function(args, batch, logits, sum_of_sample_mean):
    """PPO Value 函数损失

    裁剪策略：取原始损失和裁剪损失的较大值
    目的：防止 value 预测剧烈变化
    """

    old_values = torch.cat(batch["values"], dim=0)
    returns = torch.cat(batch["returns"], dim=0)

    # 获取当前 value 预测
    values = get_values(logits, args=args, ...)
    values = torch.cat([v.flatten() for v in values["values"]], dim=0)

    # Value 裁剪
    values_clipped = old_values + (values - old_values).clamp(-args.value_clip, args.value_clip)

    # 取较大损失（更保守）
    surr1 = (values_clipped - returns) ** 2
    surr2 = (values - returns) ** 2
    loss = torch.max(surr1, surr2)

    # 裁剪比例
    clipfrac = (values - old_values).abs() > args.value_clip

    return sum_of_sample_mean(loss), {
        "value_loss": loss,
        "value_clipfrac": clipfrac,
    }
```

```python
def sft_loss_function(args, batch, logits, sum_of_sample_mean):
    """监督微调损失

    简单的负对数似然损失
    """
    log_probs = get_log_probs_and_entropy(logits, args=args, ...)
    log_probs = torch.cat(log_probs["log_probs"], dim=0)

    # 负对数似然
    loss = -sum_of_sample_mean(log_probs)

    return loss, {"loss": loss}
```

### 5.1 支持的算法

```python
def compute_advantages_and_returns(args, rollout_data):
    """计算 advantages 和 returns

    支持算法：
    - ppo: GAE (Generalized Advantage Estimation)
    - grpo: Group Relative Policy Optimization
    - reinforce_plus_plus: 带 baseline 的 REINFORCE
    """

    # 计算 KL 散度
    kl = compute_approx_kl(log_probs, ref_log_probs)

    if args.advantage_estimator == "ppo":
        # GAE: A = Σ(γλ)^t * δ_t
        # δ_t = r_t + γV(s_{t+1}) - V(s_t)
        advantages, returns = get_advantages_and_returns_batch(
            total_lengths, response_lengths, values, rewards,
            args.gamma, args.lambd
        )

    elif args.advantage_estimator == "grpo":
        # 相对奖励：每个样本减去组均值
        rewards = torch.tensor(rewards)
        returns = get_grpo_returns(rewards, kl)
        advantages = [r for r in returns]

    elif args.advantage_estimator == "reinforce_plus_plus":
        # REINFORCE++: 带 KL 惩罚和衰减的 REINFORCE
        returns = get_reinforce_plus_plus_returns(
            rewards, kl, loss_masks, response_lengths,
            kl_coef=args.kl_coef, gamma=args.gamma
        )
        advantages = [r for r in returns]

    # 全局归一化
    if args.normalize_advantages:
        advantages = distributed_masked_whiten(
            torch.cat(advantages),
            torch.cat(loss_masks),
            process_group=dp_group
        )
```

### 5.2 GAE 计算

```python
def get_advantages_and_returns_batch(total_lengths, response_lengths, values, rewards, gamma, lambd):
    """GAE (Generalized Advantage Estimation)

    公式：
    δ_t = r_t + γV(s_{t+1}) - V(s_t)
    A_t = Σ_{l=0}^{∞} (γλ)^l * δ_{t+l}

    参数：
    - gamma (γ): 折扣因子
    - lambd (λ): GAE 平滑参数
    """
    advantages = []
    returns = []

    for i in range(len(values)):
        value = values[i]
        reward = rewards[i]
        response_length = response_lengths[i]

        # 计算 TD residual
        deltas = []
        for t in range(response_length):
            if t == response_length - 1:
                # 最后一个 token，没有下一个 value
                delta = reward[t] - value[t]
            else:
                delta = reward[t] + gamma * value[t + 1] - value[t]
            deltas.append(delta)

        # 计算 GAE
        adv = 0
        advs = []
        for t in reversed(range(response_length)):
            adv = deltas[t] + gamma * lambd * adv
            advs.insert(0, adv)
        advantages.append(torch.tensor(advs))

        # 计算 returns (targets for value function)
        ret = 0
        rets = []
        for t in reversed(range(response_length)):
            ret = reward[t] + gamma * ret
            rets.insert(0, ret)
        returns.append(torch.tensor(rets))

    return advantages, returns
```

## 6. 学习率调度

### 6.1 调度器创建

```python
def get_optimizer_param_scheduler(args, optimizer):
    """创建学习率和权重衰减调度器

    支持策略：
    - constant: 恒定
    - cosine: 余弦退火
    - polynomial: 多项式衰减
    - wsd: Warmup-Stable-Decay
    """

    # 计算训练迭代次数
    args.train_iters = args.num_rollout * args.rollout_batch_size * args.n_samples_per_prompt // args.global_batch_size

    if args.lr_decay_iters is None:
        args.lr_decay_iters = args.train_iters

    scheduler = OptimizerParamScheduler(
        optimizer,
        init_lr=args.lr_warmup_init,
        max_lr=args.lr,
        min_lr=args.min_lr,
        lr_warmup_steps=lr_warmup_steps,
        lr_decay_steps=args.lr_decay_iters * args.global_batch_size,
        lr_decay_style=args.lr_decay_style,
        start_wd=args.start_weight_decay,
        end_wd=args.end_weight_decay,
    )

    return scheduler
```

## 9. 配置参数说明

|-----|------|-------|

## 10. 常见问题

### 10.1 梯度爆炸

```
现象：loss 变成 NaN，grad_norm 极大

解决：
--clip-grad 1.0                   # 梯度裁剪
--attention-softmax-in-fp32       # 注意力 FP32
--check-for-nan-in-loss-and-grad  # 启用检查
```

### 10.2 训练不稳定

```
现象：reward 不增长或震荡

检查：
1. 学习率是否过大（降低到 1e-6）
2. KL 系数是否合适（调整 --kl-coef）
3. Advantage 归一化是否启用（--normalize-advantages）
```

### 10.3 显存不足

```
现象：OOM 错误

解决：
--micro-batch-size 1              # 减小微批次
--recompute-granularity full      # 激活重计算
--seq-length 4096                 # 减小序列长度
```

### 11.4 训练超参调优表

| 问题 | 症状 | 可能原因 | 解决方案 |
|------|------|---------|---------|
| OOM 在训练阶段 | CUDA OOM at step X | 激活值过大 | `--recompute-granularity selective` |
| 梯度爆炸 | loss = nan | 学习率过大 | `--lr 1e-6`, 加梯度裁剪 `--clip-grad 1.0` |
| 训练不稳定 | reward 震荡 | advantage 未归一化 | `--normalize-advantages` |
| 策略崩溃 | KL 发散 | KL 系数过小 | `--ppo-kl-coef 0.1` |
| Critic 发散 | value 估计不准 | value clip 禁用 | `--ppo-value-clip 0.2` |
| 学习效率低 | reward 增长慢 | 全局 batch 太小 | `--global-batch-size 256` |
