## 1. 项目概述

### 1.1 简介

**Megatron-Bridge** (也称 NeMo Megatron Bridge) 是 NVIDIA 开发的 PyTorch 原生库，作为 🤗 Hugging Face 和 **Megatron-Core** 之间的桥梁，提供：

- **双向检查点转换**: HF ↔ Megatron 格式无缝转换
- **预训练与微调**: 支持 Pretrain、SFT、LoRA/DoRA 等
- **高性能训练**: 基于 Megatron-Core 的分布式训练能力
- **自动模型检测**: 通过 `AutoBridge` 自动选择正确的转换器

### 1.2 核心依赖

| 依赖 | 版本要求 | 用途 |
|------|----------|------|
| PyTorch | >= 2.6.0 | 深度学习框架 |
| Transformers | 5.0.0 - 5.3.0 | Hugging Face 模型 |
| Megatron-Core | 子模块 | 分布式训练核心 |
| Transformer Engine | 可选 | NVIDIA 优化内核 |
| PEFT | >= 0.18.0 | 参数高效微调 |

### 1.3 Megatron-Core 子模块

```
3rdparty/Megatron-LM/  # git submodule，指向特定 commit
├── main.commit        # 稳定分支 commit
└── dev.commit         # 开发分支 commit
```

切换版本：
```bash
./scripts/switch_mcore.sh status  # 查看当前 commit
./scripts/switch_mcore.sh dev     # 切换到 dev
./scripts/switch_mcore.sh main    # 切换回 main
```

## 4. AutoBridge 自动桥接

### 4.1 AutoBridge 类

**文件位置**: `src/megatron/bridge/models/conversion/auto_bridge.py`

```python
class AutoBridge(Generic[MegatronModelT]):
    """
    自动选择并实例化适合模型的桥接器。
    
    支持:
    - HF → Megatron: 用于训练或推理
    - Megatron → HF: 用于导出模型
    - 在线转换无需中间检查点
    - 并行感知 (TP/PP/VPP/CP/EP/ETP)
    - 内存高效的逐参数流式转换
    """
    
    @classmethod
    def from_hf_pretrained(
        cls, 
        model_id: str,
        trust_remote_code: bool = False
    ) -> "AutoBridge":
        """从 HF 模型 ID 或路径创建桥接器"""
        pass
    
    def to_megatron_provider(self) -> ModelProviderMixin:
        """获取 Megatron 模型提供者"""
        pass
    
    def save_hf_pretrained(
        self,
        model: MegatronModule,
        output_dir: str
    ) -> None:
        """将 Megatron 模型保存为 HF 格式"""
        pass
    
    def export_hf_weights(
        self,
        model: MegatronModule,
        cpu: bool = True
    ) -> Iterable[HFWeightTuple]:
        """流式导出 HF 权重"""
        pass
```

### 4.2 快速上手示例

```python
from megatron.bridge import AutoBridge

# 1) 从 HF 创建桥接器
bridge = AutoBridge.from_hf_pretrained(
    "meta-llama/Llama-3.2-1B",
    trust_remote_code=True
)

# 2) 获取 Megatron 提供者并配置并行
provider = bridge.to_megatron_provider()
provider.tensor_model_parallel_size = 2
provider.pipeline_model_parallel_size = 1
provider.finalize()

# 3) 实例化分布式模型
model = provider.provide_distributed_model(wrap_with_ddp=False)

# 4a) 导出到 HF
bridge.save_hf_pretrained(model, "./hf_exports/llama32_1b")

# 4b) 或流式导出权重
for name, weight in bridge.export_hf_weights(model, cpu=True):
    print(name, weight.shape)
```

## 5. ModelProvider 模式

### 5.1 ModelProviderMixin 基类

**文件位置**: `src/megatron/bridge/models/model_provider.py`

```python
class ModelProviderMixin(abc.ABC, Generic[ModelT]):
    """
    模型提供者模式，解决生态系统碎片化问题。
    提供标准化的模型实例化方式，支持 HuggingFace 风格的 API。
    """
    
    @abc.abstractmethod
    def provide(
        self,
        pre_process: bool | None = None,
        post_process: bool | None = None,
        vp_stage: int | None = None
    ) -> ModelT:
        """抽象方法：提供模型实例
        
        Args:
            pre_process: 是否包含 embedding 层 (PP 首阶段)
            post_process: 是否包含 output 层 (PP 末阶段)
            vp_stage: 虚拟流水线阶段索引
        """
        pass
    
    def provide_distributed_model(
        self,
        ddp_config: DistributedDataParallelConfig | None = None,
        model_type=ModelType.encoder_or_decoder,
        wrap_with_ddp: bool = True,
        use_cpu_initialization: bool = False,
        ...
    ) -> list[ModelT]:
        """实例化并包装模型用于分布式训练"""
        pass
    
    @classmethod
    def from_hf_pretrained(cls, model_id: str, **kwargs):
        """从 HF 模型 ID 加载配置"""
        pass
    
    def save_hf_pretrained(self, model, output_dir: str):
        """保存模型为 HF 格式"""
        pass
```

### 6.1 训练入口函数

```python
@experimental_fn
def pretrain(
    config: ConfigContainer,
    forward_step_func: ForwardStepCallable,
    callbacks: list[Callback] | CallbackManager | None = None,
) -> None:
    """主训练入口函数
    
    Args:
        config: 配置容器，包含所有必要参数
        forward_step_func: 前向传播函数，支持多种签名
        callbacks: 可选的回调函数列表
    """
    # 创建全局状态
    state = GlobalState()
    state.cfg = config
    
    # 处理进程内重启
    if config.inprocess_restart and config.inprocess_restart.enabled:
        wrapped_pretrain, store = maybe_wrap_for_inprocess_restart(...)
        wrapped_pretrain(state, forward_step_func, callback_manager, store=store)
    else:
        _pretrain(state, forward_step_func, callback_manager)


def _pretrain(
    state: GlobalState,
    forward_step_func: ForwardStepCallable,
    callback_manager: CallbackManager | None = None,
    ...
) -> None:
    """内部训练逻辑"""
    # 设置环境
    setup_output = setup(state, dataset_provider, ...)
    model = setup_output.model
    optimizer = setup_output.optimizer
    
    # 训练
    train(forward_step_func, model, optimizer, ...)
    
    # 验证
    evaluate_and_print_results(...)
    
    # 清理
    _finish_train(state, checkpoint_manager)
```

    """主训练循环"""
    
    for iteration in range(start_iteration, total_iterations):
        # 前向传播 + 反向传播

### 6.4 前向步骤函数

**文件位置**: `src/megatron/bridge/training/gpt_step.py`

```python
def forward_step(
    data_iterator,
    model,
    return_schedule_plan: bool = False,
):
    """GPT 模型的前向步骤"""
    # 获取 batch
    tokens, labels, loss_mask, attention_mask, position_ids = get_batch(data_iterator)
    
    # 模型前向
    output = model(tokens, position_ids, attention_mask, labels=labels)
    
    # 计算损失
    losses = output.view(-1).float()
    loss_mask = loss_mask.view(-1).float()
    loss = torch.sum(losses * loss_mask) / loss_mask.sum()
    
    return loss, {"lm loss": loss}
```

## 8. PEFT 参数高效微调

### 8.1 PEFT 基类

**文件位置**: `src/megatron/bridge/peft/base.py`

```python
@dataclass
class PEFT(ABC):
    """参数高效微调抽象基类"""
    
    params_to_save: set[str] = field(default_factory=set, init=False)
    
    @abc.abstractmethod
    def transform(
        self,
        module: nn.Module,
        name: Optional[str] = None,
        prefix: Optional[str] = None
    ) -> nn.Module:
        """转换单个模块（子类必须实现）"""
        pass
    
    def __call__(self, model: ModelType, training: bool = True) -> ModelType:
        """应用 PEFT 到整个模型"""
        self.freeze_model(model, training=training)
        self._walk_model(model, self.transform)
        if training:
            maybe_enable_recompute_inputs_grad(model)
        return model
    
    def enable_adapter_layers(self, model: ModelType) -> None:
        """启用适配器层"""
        pass
    
    def disable_adapter_layers(self, model: ModelType) -> None:
        """禁用适配器层"""
        pass
```

class LoRA(PEFT):

    def __init__(
        self,
        target_modules: List[str],
        rank: int = 8,
        alpha: float = 16.0,
        dropout: float = 0.0,

        return module

## 13. 总结

### 架构优势

1. **统一的 Bridge 模式**: 标准化的 HF ↔ Megatron 转换接口
2. **AutoBridge 自动化**: 自动检测模型架构，选择正确的桥接器
3. **生产级配方**: 预配置的训练配方，开箱即用
4. **灵活的 PEFT 支持**: LoRA、DoRA 等参数高效微调
5. **全面的模型覆盖**: 支持 50+ 主流 LLM/VLM 模型

### 典型使用场景

```python
# 场景 1: HF → Megatron 转换用于训练
bridge = AutoBridge.from_hf_pretrained("meta-llama/Llama-3.2-1B")
provider = bridge.to_megatron_provider()
model = provider.provide_distributed_model()

# 场景 2: 训练后导出回 HF
bridge.save_hf_pretrained(model, "./exported_model")

# 场景 3: 使用预配置配方训练
from megatron.bridge.recipes.llama import llama32_1b_pretrain_config
cfg = llama32_1b_pretrain_config()
pretrain(cfg, forward_step)

# 场景 4: LoRA 微调
from megatron.bridge.peft import LoRA
lora = LoRA(target_modules=["query_key_value"], rank=8)
model = lora(model, training=True)
```
