# 五大处理阶段

> **【源码定位】**
> - Normalizers: `tokenizers/src/normalizers/`
> - PreTokenizers: `tokenizers/src/pre_tokenizers/`
> - Models: `tokenizers/src/models/`
> - PostProcessors: `tokenizers/src/processors/`
> - Decoders: `tokenizers/src/decoders/`

---

## 1. 五个阶段概览

```
Raw Text -> [Normalizer] -> [PreTokenizer] -> [Model] -> [PostProcessor] -> [Decoder]
                ↓                ↓              ↓              ↓              ↓
           文本清洗        初步分割        ID映射      添加特殊token    还原文本
           NormalizedString → PreTokenizedString → Encoding → Encoding → String
```

---

## 2. Stage 1: Normalizer（规范化器）

**职责**：文本清洗和标准化，处理Unicode、大小写、特殊字符等。

**核心Trait**：

```rust
pub trait Normalizer: Sync {
    fn normalize(&self, normalized: &mut NormalizedString) -> Result<()>;
}
```

### 2.1 内置Normalizers

```
NormalizerWrapper体系:
┌──────────────────────────────────────────┐
│  NormalizerWrapper                       │
│  ├── BertNormalizer                      │
│  ├── NFC/NFD/NFKC/NFKD (Unicode)         │
│  ├── Strip/StripAccents                  │
│  ├── Sequence (链式组合)                  │
│  └── Lowercase/Replace/Prepend           │
└──────────────────────────────────────────┘
```

### 2.2 常用Normalizers

| Normalizer | 说明 |
|------------|------|
| `NFC/NFD/NFKC/NFKD` | Unicode规范化形式 |
| `Lowercase` | 转换为小写 |
| `Strip` | 去除首尾空白 |
| `StripAccents` | 去除重音符号 |
| `Replace` | 正则替换 |
| `BertNormalizer` | BERT专用组合（NFD + Lowercase + StripAccents） |
| `Sequence` | 链式组合多个Normalizers |

### 2.3 使用示例

```python
from tokenizers import normalizers

# 单normalizer
tokenizer.normalizer = normalizers.Lowercase()

# 组合normalizers
tokenizer.normalizer = normalizers.Sequence([
    normalizers.NFD(),           # Unicode分解
    normalizers.Lowercase(),     # 小写化
    normalizers.StripAccents(),  # 去除重音
])
```

## 3. Stage 2: PreTokenizer（预分词器）

**职责**：将文本分割为"词"单元，是Model分词的基础单位。

**核心Trait**：

```rust
pub trait PreTokenizer {
    fn pre_tokenize(&self, pretokenized: &mut PreTokenizedString) -> Result<()>;
}
```

### 3.1 内置PreTokenizers

```
PreTokenizerWrapper体系:
┌──────────────────────────────────────────┐
│  PreTokenizerWrapper                     │
│  ├── ByteLevel                           │
│  ├── Whitespace/WhitespaceSplit          │
│  ├── BertPreTokenizer                    │
│  ├── Metaspace                           │
│  ├── Punctuation/Split/Digits            │
│  ├── UnicodeScripts                      │
│  └── Sequence (链式组合)                  │
└──────────────────────────────────────────┘
```

### 3.2 常用PreTokenizers

| PreTokenizer | 说明 | 典型应用 |
|--------------|------|----------|
| `ByteLevel` | 字节级处理，带空格前缀标记 | GPT-2/3/4 |
| `Whitespace` | 按空白分割 | 基础分词 |
| `WhitespaceSplit` | 简单空白分割（更快） | 快速处理 |
| `BertPreTokenizer` | 按空格+标点分割 | BERT系列 |
| `Metaspace` | 用▁标记空格 | T5/SentencePiece兼容 |
| `Punctuation` | 按标点分割 | 特殊处理 |
| `Digits` | 按数字分割 | 数字敏感场景 |
| `UnicodeScripts` | 按Unicode脚本分割 | 多语言处理 |

### 3.3 ByteLevel PreTokenizer详解

```python
from tokenizers import pre_tokenizers

# GPT-2风格配置
tokenizer.pre_tokenizer = pre_tokenizers.ByteLevel(
    add_prefix_space=True,      # 词前加空格标记
    trim_offsets=False,
    use_regex=True,             # 使用预定义正则
)

# 效果
# "Hello world" -> ["Hello", "Ġworld"]
# Ġ (U+0120) 表示空格前缀
```

### 3.4 使用示例

```python
from tokenizers import pre_tokenizers

# 组合使用
tokenizer.pre_tokenizer = pre_tokenizers.Sequence([
    pre_tokenizers.Whitespace(),
    pre_tokenizers.Punctuation(),
    pre_tokenizers.Digits(),
])
```

## 4. Stage 3: Model（核心分词模型）

**职责**：核心分词算法，将词单元映射为Token ID。

**核心Trait**：

```rust
pub trait Model {
    type Trainer: Trainer + Sync;
    fn tokenize(&self, sequence: &str) -> Result<Vec<Token>>;
    fn token_to_id(&self, token: &str) -> Option<u32>;
    fn id_to_token(&self, id: u32) -> Option<String>;
    fn get_vocab(&self) -> HashMap<String, u32>;
    // ...
}
```

### 4.1 ModelWrapper架构

```
ModelWrapper体系:
┌──────────────────────────────────────────┐
│  ModelWrapper                            │
│  ├── BPE                                 │
│  ├── WordPiece                           │
│  ├── WordLevel                           │
│  └── Unigram                             │
└──────────────────────────────────────────┘
```

### 4.2 模型对比

| 模型 | 算法类型 | 特点 | 代表模型 |
|------|----------|------|----------|
| **BPE** | 子词合并 | 从字符开始迭代合并高频对 | GPT系列 |
| **WordPiece** | 子词合并 | 基于似然最大化选择合并对 | BERT系列 |
| **Unigram** | 子词剪枝 | 从大量候选剪枝到目标大小 | XLNet, Albert |
| **WordLevel** | 整词映射 | 无子词拆分 | 简单任务 |

### 4.3 BPE模型配置

```python
from tokenizers import models

model = models.BPE(
    vocab: Dict[str, int],
    merges: List[Tuple[str, str]],
    cache_capacity: int = 10000,
    dropout: Optional[float] = None,
    unk_token: Optional[str] = None,
    byte_fallback: bool = False,
    continuing_subword_prefix: Optional[str] = None,
    end_of_word_suffix: Optional[str] = None,
    fuse_unk: bool = False,
)
```

### 4.4 WordPiece模型配置

```python
from tokenizers import models

model = models.WordPiece(
    vocab: Dict[str, int],
    unk_token: str = "[UNK]",
    max_input_chars_per_word: int = 100,
    continuing_subword_prefix: str = "##",
)
```

## 5. Stage 4: PostProcessor（后处理器）

**职责**：添加特殊token（如[CLS]/[SEP]），处理pair输入。

**核心Trait**：

```rust
pub trait PostProcessor {
    fn added_tokens(&self, is_pair: bool) -> usize;
    fn process_encodings(&self, encodings: Vec<Encoding>, add_special_tokens: bool)
        -> Result<Vec<Encoding>>;
}
```

### 5.1 内置PostProcessors

```
PostProcessorWrapper体系:
┌──────────────────────────────────────────┐
│  PostProcessorWrapper                    │
│  ├── BertProcessing ([CLS]/[SEP])          │
│  ├── RobertaProcessing (<s></s>)           │
│  ├── TemplateProcessing (模板)           │
│  ├── ByteLevel (偏移修正)                │
│  └── Sequence (链式组合)                  │
└──────────────────────────────────────────┘
```

### 5.2 常用PostProcessors

| PostProcessor | 说明 | 模板 |
|---------------|------|------|
| `BertProcessing` | BERT风格 | [CLS] A [SEP] B [SEP] |
| `RobertaProcessing` | RoBERTa/GPT风格 | <s> A </s></s> B </s> |
| `TemplateProcessing` | 自定义模板 | 灵活配置 |
| `ByteLevel` | 修正偏移量 | 配合ByteLevel使用 |

### 5.3 BertProcessing示例

```python
from tokenizers import processors

tokenizer.post_processor = processors.BertProcessing(
    ("[SEP]", tokenizer.token_to_id("[SEP]")),
    ("[CLS]", tokenizer.token_to_id("[CLS]")),
)

# 效果：
# encode("Hello", "World") ->
# tokens: ['[CLS]', 'hello', '[SEP]', 'world', '[SEP]']
```

### 5.4 TemplateProcessing示例

```python
from tokenizers import processors

tokenizer.post_processor = processors.TemplateProcessing(
    single="[CLS] $A [SEP]",
    pair="[CLS] $A [SEP] $B:1 [SEP]:1",
    special_tokens=[
        ("[CLS]", tokenizer.token_to_id("[CLS]")),
        ("[SEP]", tokenizer.token_to_id("[SEP]")),
    ],
)
```

## 6. Stage 5: Decoder（解码器）

**职责**：将Token ID序列还原为可读文本。

**核心Trait**：

```rust
pub trait Decoder {
    fn decode(&self, tokens: Vec<String>) -> Result<String>;
    fn decode_chain(&self, tokens: Vec<String>) -> Result<Vec<String>>;
}
```

### 6.1 内置Decoders

```
DecoderWrapper体系:
┌──────────────────────────────────────────┐
│  DecoderWrapper                          │
│  ├── ByteLevel (字节还原)                │
│  ├── WordPiece (## 前缀处理)             │
│  ├── Metaspace (▁ 处理)                 │
│  ├── ByteFallback (<0xXX> 解码)          │
│  └── BPEDecoder/CTC/Strip/Fuse           │
└──────────────────────────────────────────┘
```

### 6.2 常用Decoders

| Decoder | 说明 | 配合模型 |
|---------|------|----------|
| `ByteLevel` | 字节级解码，还原Unicode | GPT系列 |
| `WordPiece` | 处理`##`前缀 | BERT系列 |
| `Metaspace` | 处理`▁`（空格标记） | T5系列 |
| `BPEDecoder` | BPE专用解码 | BPE模型 |
| `ByteFallback` | 处理字节回退（<0xXX>） | 通用 |

### 6.3 使用示例

```python
from tokenizers import decoders

# BERT风格
tokenizer.decoder = decoders.WordPiece(prefix="##")

# GPT-2风格
tokenizer.decoder = decoders.ByteLevel()

# T5风格
tokenizer.decoder = decoders.Metaspace()
```

## 7. Pipeline组件组合实战

### 7.1 BERT完整Pipeline

```python
from tokenizers import Tokenizer, models, normalizers, pre_tokenizers, processors, decoders

# Model
tokenizer = Tokenizer(models.WordPiece(unk_token="[UNK]"))

# Normalizer
tokenizer.normalizer = normalizers.Sequence([
    normalizers.NFD(),
    normalizers.Lowercase(),
    normalizers.StripAccents(),
])

# PreTokenizer
tokenizer.pre_tokenizer = pre_tokenizers.BertPreTokenizer()

# PostProcessor
tokenizer.post_processor = processors.BertProcessing(
    ("[SEP]", 102),
    ("[CLS]", 101),
)

# Decoder
tokenizer.decoder = decoders.WordPiece(prefix="##")
```

### 7.2 GPT-2完整Pipeline

```python
from tokenizers import Tokenizer, models, pre_tokenizers, processors, decoders

# Model
tokenizer = Tokenizer(models.BPE(byte_fallback=True))

# PreTokenizer
tokenizer.pre_tokenizer = pre_tokenizers.ByteLevel(add_prefix_space=True)

# PostProcessor
tokenizer.post_processor = processors.ByteLevel(trim_offsets=False)

# Decoder（复用ByteLevel组件）
tokenizer.decoder = decoders.ByteLevel()
```

## 8. 关键点总结

1. **顺序固定**：5个阶段按固定顺序处理文本
2. **Model是核心**：其他阶段可选择性配置
3. **对齐至关重要**：Normalizers/PreTokenizers影响offset计算
4. **一致性原则**：PostProcessor和Decoder应保持语义一致
