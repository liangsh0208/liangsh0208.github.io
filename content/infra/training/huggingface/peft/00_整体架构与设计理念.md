## 1. 什么是 PEFT

**PEFT (Parameter-Efficient Fine-Tuning)** 是 Hugging Face 开发的参数高效微调库，支持多种 state-of-the-art 的轻量化微调方法。与传统全参数微调相比，PEFT 方法只训练少量参数（通常 <1%），却能达到接近全参数微调的性能。

### 1.1 核心功能

| 功能类别 | 说明 |
|---------|------|
| **多种微调方法** | LoRA、AdaLoRA、IA3、Prompt Tuning、Prefix Tuning、P-Tuning、(IA)³、BOFT、OFT、LoHa、LoKr、VeRA 等 |
| **多任务支持** | Causal LM、Seq2Seq、Token Classification、Sequence Classification、Question Answering 等 |
| **量化集成** | 与 BitsAndBytes、GPTQ、AWQ 等量化方案无缝集成 (QLoRA) |
| **分布式训练** | 原生支持 DeepSpeed、FSDP、Accelerate |
| **多种保存格式** | 支持 safetensors、PyTorch 原生格式 |
| **推理优化** | 支持 Adapter 合并、多_ADAPTER 切换、推理加速 |

## 2. 设计哲学

### 2.1 非侵入式集成

PEFT 通过**包装器模式**包装原始模型，不修改原始模型代码。

```
Base Model → PeftModel (包装器) → 注入 Adapter 层 → 训练/推理
```

### 2.2 配置驱动

所有 PEFT 方法都通过配置类定义，结构清晰：

| 配置类 | 用途 |
|--------|------|
| `PeftConfig` | 通用 PEFT 配置基类 |
| `LoraConfig` | LoRA 具体配置 |
| `IA3Config` | IA3 方法配置 |
| `PromptLearningConfig` | 提示学习方法基类 |

### 2.3 统一接口

不同的 PEFT 方法都遵循相同的 `get_peft_model()` 接口：

```python
from peft import get_peft_model, LoraConfig

# 无论使用哪种 PEFT 方法，入口相同
model = get_peft_model(base_model, peft_config)
```

### 2.4 弹性架构

使用**注册机制**动态支持新的 PEFT 方法：

```python
# 注册新的 PEFT 方法到系统中
register_peft_method(
    name="lora",
    config_cls=LoraConfig,
    model_cls=LoraModel,
    is_mixed_compatible=True
)
```

## 4. 辅助模块架构

| 文件 | 功能 |
|------|------|
| `peft_types.py` | PeftType/TaskType 枚举定义 |

| 文件 | 功能 |
|------|------|
| `mapping.py` | PEFT 类型 → 配置/模型的注册表映射 |
| `mapping_func.py` | `get_peft_model()` 主入口函数 |

## 5. Adapters vs Prompt Learning

| 特性 | Adapters (适配器) | Prompt Learning (提示学习) |
|------|-------------------|---------------------------|
| **修改位置** | 在模型层中注入可训练参数 | 在输入序列前添加可训练 token |
| **代表方法** | LoRA、IA3、AdaLoRA | Prompt Tuning、P-Tuning、Prefix Tuning |
| **修改对象** | 修改中间表示 | 不修改模型内部 |
| **计算开销** | 中等 | 较小 |
