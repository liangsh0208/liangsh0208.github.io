## 1. 实验性功能概述

## 2. KTOTrainer

### 概述

KTO (Kahneman-Tversky Optimization) - 无需显式偏好对的优化方法。

### 核心特点

- 只需要 "好" 或 "坏" 的标注，不需要配对比较
- 基于前景理论 (Prospect Theory)
- 对于难以收集偏好对的数据特别有用

### 核心公式

```
L_KTO = E[λ_y * (1 - σ(β * (r_θ(x,y) - z_ref)))]

其中:
- λ_y: 类别权重
- β: 温度系数
- z_ref: 参考点
```

### 配置

```python
from trl import KTOTrainer, KTOConfig

config = KTOConfig(
    beta=0.1,
    desirable_weight=1.0,    # "好" 样本权重
    undesirable_weight=1.0,  # "坏" 样本权重
)
```

### 数据格式

```python
# KTO 数据格式 (不需要配对)
{
    "prompt": "用户问题",
    "completion": "模型回答",
    "label": True  # True=好, False=坏
}
```

## 3. RLOOTrainer

### 概述

RLOO (REINFORCE Leave-One-Out) - 通过留一法计算优势，无需价值模型。

### 核心特点

- 简单有效的策略梯度方法
- 使用留一法估计基线
- 工作方式类似 GRPO，但实现更简单

### 核心算法

```
# 对每个 prompt 生成 N 个样本
# 留一法优势估计: A_i = r_i - mean(r_{-i})

L_RLOO = -E[log π_θ(y|x) * A]
```

### 配置

```python
from trl import RLOOTrainer, RLOOConfig

config = RLOOConfig(
    num_generations=4,      # 每组生成数量
    mini_batch_size=1,
    learning_rate=1e-5,
)
```

## 4. ORPOTrainer

### 概述

ORPO (Odds Ratio Preference Optimization) - 将 SFT 和偏好优化结合为单一训练阶段。

### 核心特点

- 不需要参考模型
- 单阶段训练，同时学习指令跟随和偏好
- 使用 Odds Ratio 而非 Bradley-Terry 模型

### 核心公式

```
L_ORPO = L_SFT - λ * L_odd_ratio

L_odd_ratio = log σ(odds_ratio(chosen) - odds_ratio(rejected))
```

### 配置

```python
from trl import ORPOTrainer, ORPOConfig

config = ORPOConfig(
    learning_rate=1e-5,
    lambda_weight=1.0,      # SFT 和偏好优化的平衡
)
```

## 5. NashMDTrainer

### 概述

NashMD (Nash Mirror Descent) - 基于博弈论纳什均衡的优化方法。

### 核心特点

- 将 RLHF 建模为双人博弈
- 寻找纳什均衡策略
- 理论上更稳定

### 实验性状态

```
位置: trl/experimental/nashmd/
状态: 高度实验性
建议: 等待稳定后再生产使用
```

## 7. AsyncGRPO

### 概述

异步版本的 GRPO，用于提高分布式训练效率。

### 核心特点

- 异步生成和训练
- 适合多节点扩展
- 减少 GPU 等待时间

```
位置: trl/experimental/async_grpo/
状态: 实验性
```

## 8. GKD (Generalized Knowledge Distillation)

### 概述

通用知识蒸馏框架。

### 核心特点

- 从教师模型蒸馏到学生模型
- 支持多种蒸馏目标
- 可以与 SFT/DPO 结合

```
位置: trl/experimental/gkd/
状态: 实验性
```

## 10. 实战示例

### KTO 训练

```python
from trl import KTOTrainer, KTOConfig
from datasets import load_dataset

# KTO 数据: 需要 label 字段 (True/False)
dataset = load_dataset(...)

config = KTOConfig(
    output_dir="./output/kto",
    beta=0.1,
    desirable_weight=1.0,
    undesirable_weight=1.0,
)

trainer = KTOTrainer(
    model="Qwen/Qwen2.5-0.5B-Instruct",
    args=config,
    train_dataset=dataset,
)
trainer.train()
```

### RLOO 训练

```python
from trl import RLOOTrainer, RLOOConfig
from trl.rewards import accuracy_reward

config = RLOOConfig(
    output_dir="./output/rloo",
    num_generations=4,
    learning_rate=1e-5,
)

trainer = RLOOTrainer(
    model="Qwen/Qwen2.5-0.5B-Instruct",
    reward_funcs=[accuracy_reward],
    args=config,
    train_dataset=dataset,
)
trainer.train()
```

### ORPO 训练

```python
from trl import ORPOTrainer, ORPOConfig

config = ORPOConfig(
    output_dir="./output/orpo",
    learning_rate=1e-5,
    lambda_weight=1.0,  # 平衡 SFT 和偏好优化
)

trainer = ORPOTrainer(
    model="Qwen/Qwen2.5-0.5B",
```
