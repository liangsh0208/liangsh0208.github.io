## 1. 模块概述

优化器模块提供从基础Adam到大规模分片优化器的完整方案。

### 【重点】优化器层次

| 类 | 功能 | 规模 |
|------|------|------|
| `MegatronOptimizer` | 基础包装，loss scaling | optimizer.py |
| `DistributedOptimizer` | ZeRO-3分片优化器 | 132KB |
| `HybridDeviceOptimizer` | CPU/GPU混合 | hybrid_optimizer.py |
| `OptimizerParamScheduler` | LR调度，WSD支持 | 层外实现 |

## 3. 核心概念与实现

### 3.1 Range类 (分片核心)

```python
# 文件: megatron/core/optimizer/distrib_optimizer.py

class Range:
    """表示张量分片的范围 [start, end)。
    
    在DistributedOptimizer中，每个参数可能跨越多个DP rank的buffer分片，
    每个分片需要精确知道: 
    - 全局buffer中的位置 (world range)
    - DP本地视图中的位置 (local range)  
    - 原始参数中的位置 (param range)
    """
    def __init__(self, start: int, end: int):
        self.start = start
        self.end = end
        self.size = end - start
    
    def normalize(self, start: int = 0):
        """平移范围的起始位置。
        new_range = [start, start + self.size)
        用于: DP rank N的buffer分片映射到全局坐标
        """
        return Range(start, start + self.size)
```

### 3.2 参数到Buffer映射构建

```python
# 文件: megatron/core/optimizer/distrib_optimizer.py:122

@classmethod
def _build_model_gbuf_range_map(cls, param_and_grad_buffer, bucket_index):
    """构建参数到梯度buffer分片的映射。
    
    关键计算:
    - 每个DP rank 'owns' 1/dp_world_size的连续buffer区域
    - 但一个参数可能跨多个DP rank (如大层参数)
    - 需要计算: 参数range中哪些属于哪个DP rank
    """
    
    dp_rank = param_and_grad_buffer.data_parallel_group.rank()
    dp_size = param_and_grad_buffer.data_parallel_group.size()
    
    bucket = param_and_grad_buffer.buckets[bucket_index]
    gbuf_size = bucket.grad_data.numel()
    
    # 每个DP rank分到的最大范围大小
    max_range_size = gbuf_size // dp_size
    
    # 计算所有DP rank的world range
    all_world_ranges = []
    for r in range(dp_size):
        gbuf_start = r * max_range_size
        gbuf_end = min(gbuf_size, gbuf_start + max_range_size)
        all_world_ranges.append(Range(gbuf_start, gbuf_end))
    
    # 本rank负责的range
    my_world_range = all_world_ranges[dp_rank]
    
    # 计算每个参数在本rank range内的sub-range
    param_range_map = {}
    for param, (param_world_start, param_world_end, _) in \
        param_and_grad_buffer.param_index_map.items():
        
        # 计算与DP range的交集
        local_start = max(0, param_world_start - my_world_range.start)
        local_end = min(my_world_range.size, param_world_end - my_world_range.start)
        
        if local_end > local_start:
            # 参数在本DP range内有数据
            local_range = Range(local_start, local_end)
            world_range = local_range.normalize(param_world_start)
            
            # 计算参数坐标系内的位置
            sub_param_start = max(0, my_world_range.start - param_world_start)
            sub_param_range = local_range.normalize(sub_param_start)
            
            param_range_map[param] = {
                "gbuf_world": world_range,
                "gbuf_local": local_range,  
                "param": sub_param_range,
            }
    
    return param_range_map
```

### 3.3 DistributedOptimizer步骤

```python
# 文件: megatron/core/optimizer/distrib_optimizer.py

class DistributedOptimizer(MixedPrecisionOptimizer):
    """ZeRO-3风格的分布式优化器。
    
    核心流程:
    1. Reduce-Scatter: 各DP rank只保留对应分片的梯度
    2. 本地Optimizer Step: 只更新分片内的参数
    3. All-Gather: 将更新后的参数广播给所有DP rank
    """
    
    def step(self, args):
        """执行分布式优化器步骤。"""
        # ===== 1. Reduce-Scatter 梯度 =====
        # 每个DP rank: 拿到自己负责的梯度分片的聚合结果
        for bucket_id, bucket in self.buckets.items():
            # 从full gbuf reduce-scatter到每个rank的reduced分片
            torch.distributed.reduce_scatter_tensor(
                bucket.gbuf_reduced,  # 输出: 本rank的分片 [N/dp_size]
                bucket.gbuf,  # 输入: 完整buffer [N]
                group=self.data_parallel_group,
                op=torch.distributed.ReduceOp.SUM,
            )
            
        # ===== 2. 写回梯度 =====
        # 将 reduced buffer 写回各param的.grad
        self._copy_bucket_to_grads()
        
        # ===== 3. 本地优化器步骤 =====
        # 仅更新属于本rank的param分片 (Range管理的)
        self.optimizer.step()
        
        # ===== 4. All-Gather 参数 =====
        # 将本rank更新的param分片广播给所有DP rank
        for bucket in self.buckets:
            torch.distributed.all_gather_into_tensor(
                bucket.param,  # 目标: 完整参数buffer
                bucket.param_shard,  # 来源: 本rank的分片
                group=self.data_parallel_group,
            )
            
        # ===== 5. 写回模型参数 =====
        self._copy_params_from_bucket_to_model()
    
    def _copy_reduced_grads_to_optimizer_grads(self):
        """将reduced buffer中的梯度写回torch param.grad。
        
        这是Range映射的关键应用: 从连续buffer写出到分散的param。
        """
        for gbuf_index, gbuf_range_map in enumerate(self.gbuf_ranges):
            for (dtype, _), gbuf_range_map_for_buckets in gbuf_range_map.items():
                for bucket in gbuf_range_map_for_buckets:
                    for param, ranges in bucket["param_map"].items():
                        # 从gbuf_local range读取，写入param range
                        gbuf_view = self._get_bucket_buffer_view(
                            ranges["gbuf_local"]
                        )
                        param.grad.view(-1)[ranges["param"].start:ranges["param"].end] = gbuf_view
```

### 3.4 HybridDeviceOptimizer (CPU卸载)

```python
# 文件: megatron/core/optimizer/cpu_offloading/hybrid_optimizer.py

class HybridDeviceOptimizer(torch.optim.Optimizer):
    """混合设备优化器。
    
    将部分优化器状态卸载到CPU，进一步节省GPU显存。
    优势: 可将大模型训练到超过单GPU显存的规模。
    
    工作流程:
    1. 分配offload_fraction的优化器状态到CPU pinned内存
    2. 反向时: 梯度异步传输到CPU (D2H)
    3. 优化器步骤: GPU部分立即更新，CPU部分等D2H后更新
    4. 前向时: 参数异步加载回GPU (H2D)
    """
    
    def __init__(
        self,
        params,
        offload_fraction=0.5,  # 50%卸载到CPU
        cpu_optimizer_cls=torch.optim.AdamW,
        gpu_optimizer_cls=torch.optim.AdamW,
        overlap_cpu_optimizer_d2h_h2d=True,  # 重叠传输
    ):
        # 将参数分为GPU部分和CPU部分
        gpu_params, cpu_params = self._split_params(params, offload_fraction)
        
        # 创建子优化器
        self.gpu_optimizer = gpu_optimizer_cls(gpu_params, **kwargs)
        self.cpu_optimizer = cpu_optimizer_cls(cpu_params, **kwargs)
        
        # 创建CUDA流用于异步传输
        self._d2h_stream = torch.cuda.Stream()
        self._h2d_stream = torch.cuda.Stream()
        
    def step(self):
        # 1. 启动GPU优化器
        self.gpu_optimizer.step()
        
        # 2. 同步CPU参数更新 (如果有D2H传输)
        if self.cpu_optimizer is not None:
            for cpu_opt in self.cpu_optimizers:
                # 等待D2H事件
                event = self._cpu_optimizer_map_data_event.get(cpu_opt)
                if event is not None:
                    event.synchronize()
                cpu_opt.step()
```

### 3.5 与nanotron对比

| 对比项 | Megatron-LM | nanotron |
|--------|-------------|----------|
| **ZeRO实现** | DistributedOptimizer (132KB) | 简化或需外部DeepSpeed |
| **状态分片** | 精细Range映射，支持跨参数分片 | 简单按参数分片 |
| **CPU卸载** | HybridDeviceOptimizer原生 | 无 |
| **精度支持** | FP16/BF16/FP32/FP8多层次 | 基础BF16/FP32 |
| **梯度融合** | gradient_accumulation_fusion | 无 |
| **Optimizer类型** | Adam/AdamW/SGD/定制化… | 依赖PyTorch原生 |
| **代码耦合** | 与Megatron各模块深度集成 | 松耦合，易替换 |
