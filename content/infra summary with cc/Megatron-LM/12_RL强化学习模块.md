| 算法 | 实现状态 | 特点 |
|------|---------|------|

| **PPO** | 完整实现 | 经典算法，内置value model支持 |

## 3. 核心概念与实现

### 3.1 GRPO算法实现 (核心)

```python
# 文件: megatron/rl/rl_utils.py

def compute_grpo_advantages_and_policy_loss(
    old_logprobs,      # [batch, seq_len] 旧策略log概率
    new_logprobs,      # [batch, seq_len] 当前策略log概率  
    ref_logprobs,      # [batch, seq_len] 参考策略(初始模型)log概率
    rewards,           # [batch] 最终奖励
    group_size: int,   # 每组样本数 (GRPO核心)
    epsilon: float = 0.2,  # PPO裁剪参数
    kl_coeff: float = 0.01,  # KL惩罚系数
):
    """GRPO算法核心实现。
    
    GRPO与PPO的关键差异:
    1. 优势计算使用组内标准化，而非value model
    2. 每组G个答案，相对评估
    3. 更稳定，不需要训练额外的value model
    """
    
    batch_size = rewards.shape[0]
    assert batch_size % group_size == 0
    num_groups = batch_size // group_size
    
    # ===== 1. 重组为 [num_groups, group_size, ...] =====
    rewards_grouped = rewards.view(num_groups, group_size)
    old_logprobs_grouped = old_logprobs.view(num_groups, group_size, -1)
    new_logprobs_grouped = new_logprobs.view(num_groups, group_size, -1)
    # ...
    
    # ===== 2. 计算组内标准化优势 (GRPO核心) =====
    # 每组内的reward进行mean/std归一化
    mean_rewards = rewards_grouped.mean(dim=1, keepdim=True)  # [num_groups, 1]
    std_rewards = rewards_grouped.std(dim=1, keepdim=True)    # [num_groups, 1]
    
    # 优势 = (r - mean(r)) / std(r)
    # 这使得每组内最好的答案获得正优势，最差的负优势
    advantages = (rewards_grouped - mean_rewards) / (std_rewards + 1e-8)
    advantages = advantages.unsqueeze(-1)  # [num_groups, group_size, 1]
    
    # 扩展到每个token位置 (同一答案内所有token共享相同优势)
    advantages = advantages.expand_as(old_logprobs_grouped)
    
    # ===== 3. 计算ratio和PPO裁剪 =====
    # ratio = exp(new_logprob - old_logprob)  # 策略变化比率
    ratio = torch.exp(new_logprobs_grouped - old_logprobs_grouped)
    
    # 裁剪目标: 防止策略变化过大
    clipped_ratio = torch.clamp(ratio, 1 - epsilon, 1 + epsilon)
    
    policy_loss1 = -ratio * advantages  # 未裁剪
    policy_loss2 = -clipped_ratio * advantages  # 裁剪后
    policy_loss = torch.max(policy_loss1, policy_loss2).mean()  # 取最小化max
    
    # ===== 4. KL散度惩罚 (防止偏离参考模型太远) =====
    kl_div = (new_logprobs_grouped - ref_logprobs_grouped).mean()
    total_loss = policy_loss + kl_coeff * kl_div
    
    return total_loss, {
        'policy_loss': policy_loss.item(),
        'kl_div': kl_div.item(),
        'mean_advantage': advantages.mean().item(),
    }
```

### 3.2 PPO实现 (经典方法)

```python
# 文件: megatron/rl/rl_utils.py

def compute_ppo_advantages_and_policy_loss(
    old_logprobs,
    new_logprobs,
    values,            # Critic预测的value
    rewards,
    dones,             # 序列结束标记
    gamma: float = 0.99,   # 折扣因子
    gae_lambda: float = 0.95,  # GAE参数
    epsilon: float = 0.2,
):
    """PPO算法完整实现。
    
    需要显式训练的Critic网络。
    优势估计使用GAE (Generalized Advantage Estimation)。
    """
    
    # ===== 1. 计算returns (折扣累积奖励) =====
    returns = []
    running_return = 0
    for t in reversed(range(len(rewards))):
        if dones[t]:
            running_return = 0
        running_return = rewards[t] + gamma * running_return
        returns.insert(0, running_return)
    returns = torch.tensor(returns)
    
    # ===== 2. GAE优势估计 =====
    # A_t = δ_t + (γλ)δ_{t+1} + (γλ)²δ_{t+2} + ...
    # where δ_t = r_t + γV(s_{t+1}) - V(s_t)
    advantages = []
    running_advantage = 0
    for t in reversed(range(len(rewards))):
        if dones[t]:
            running_advantage = 0
        # TD error: δ_t
        delta = rewards[t] + gamma * values[t+1] * (1-dones[t]) - values[t]
        running_advantage = delta + gamma * gae_lambda * running_advantage
        advantages.insert(0, running_advantage)
    advantages = torch.tensor(advantages)
    # 可选: 标准化 advantages = (adv - mean) / std
    
    # ===== 3. PPO裁剪目标 (类似GRPO的部分) =====
    ratio = torch.exp(new_logprobs - old_logprobs)
    clipped_ratio = torch.clamp(ratio, 1 - epsilon, 1 + epsilon)
    
    policy_loss = -torch.min(ratio * advantages, clipped_ratio * advantages).mean()
    
    # ===== 4. Value loss (Critic更新) =====
    value_loss = F.mse_loss(values, returns)
    
    # 总loss = policy_loss + c1 * value_loss - c2 * entropy_bonus
    total_loss = policy_loss + 0.5 * value_loss
    
    return total_loss, {
        'policy_loss': policy_loss.item(),
        'value_loss': value_loss.item(),
    }
```
