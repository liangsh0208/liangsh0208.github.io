## 核心函数

### get_dataset_provider

```python
def get_dataset_provider(
    dataset_config: Union[FinetuningDatasetConfig, BlendedMegatronDatasetConfig, HFDatasetConfig, DatasetProvider],
) -> Callable:
    """
    根据配置类型获取数据集提供者函数。
    
    支持两种模式：
    1. 注册表模式：根据配置类型查找注册的提供者
    2. 协议模式：如果配置实现DatasetProvider 协议，使用其 build_datasets 方法
    """
    #协议模式
    if isinstance(dataset_config, DatasetProvider):
        def protocol_adapter(
            train_val_test_num_samples: list[int],
            config: DatasetProvider,
            tokenizer: Optional[MegatronTokenizer] = None,
            pg_collection: Optional[ProcessGroupCollection] = None,
        ) -> tuple[Optional[Any], Optional[Any], Optional[Any]]:
            context = DatasetBuildContext(
                train_samples=train_val_test_num_samples[0],
                valid_samples=train_val_test_num_samples[1],
                test_samples=train_val_test_num_samples[2],
                tokenizer=tokenizer,
                pg_collection=pg_collection,
            )
            return config.build_datasets(context)
        return protocol_adapter
    
    # 注册表模式
    return _REGISTRY[type(dataset_config)]
```

### is_dataset_built_on_rank

```python
def is_dataset_built_on_rank(pg_collection: ProcessGroupCollection) -> bool:
    """
    确定当前 rank 是否需要构建数据集。
    仅在 PP首阶段/末阶段且 TP rank 0 上构建数据集，以节省内存。
    """
    return (is_pp_first_stage(pg_collection.pp) or is_pp_last_stage(pg_collection.pp)) and (
        pg_collection.tp.rank() == 0
    )
```

## 预训练数据集

### pretrain_train_valid_test_datasets_provider

```python
def pretrain_train_valid_test_datasets_provider(
    train_val_test_num_samples: list[int], 
    dataset_config: BlendedMegatronDatasetConfig
) -> tuple[GPTDataset, GPTDataset, GPTDataset]:
    """
    构建预训练数据集。
    
    支持：
    - GPTDataset: 标准预训练数据集
    - MockGPTDataset: 模拟数据集（用于测试）
    - GPTFIMDataset: Fill-in-the-Middle 数据集"""
    if dataset_config.mock:
        dataset_type = MockGPTDataset
    elif hasattr(dataset_config, "fim_data"):
        dataset_type = GPTFIMDataset
    else:
        dataset_type = GPTDataset
    
    train_ds, valid_ds, test_ds = BlendedMegatronDatasetBuilder(
        dataset_type, train_val_test_num_samples, lambda: True, dataset_config
    ).build()
    
    return train_ds, valid_ds, test_ds
```

### GPTDatasetConfig

```python
@dataclass
class GPTDatasetConfig(MCoreGPTDatasetConfig, DataloaderConfig):
    """GPT 数据集配置"""
    
    data_path: str | list[str] | None = None
    """数据路径，可转换为 blend"""
    
    def finalize(self) -> None:
        # data_path → blend 转换
        if self.blend is None and self.data_path is not None:
            from megatron.core.datasets.utils import get_blend_from_list
            paths = self.data_path.split() if isinstance(self.data_path, str) else list(self.data_path)
            self.blend = get_blend_from_list(paths)
        
        super(MCoreGPTDatasetConfig, self).__post_init__()
```

## 自定义数据集协议

```python
@dataclass
class DatasetProvider(DataloaderConfig, ABC):
    """
    自定义数据集配置基类。
    
    用户实现 build_datasets 方法来构建自定义数据集。
    
    Example:
        @dataclass
        class S3DatasetConfig(DatasetProvider):
            bucket_name: str
            data_prefix: str
            
            def build_datasets(self, context: DatasetBuildContext):
                train_ds = load_s3_dataset(self.bucket_name, f"{self.data_prefix}/train", context.tokenizer)
                valid_ds = load_s3_dataset(self.bucket_name, f"{self.data_prefix}/valid", context.tokenizer)
                test_ds = load_s3_dataset(self.bucket_name, f"{self.data_prefix}/test", context.tokenizer)
                return train_ds, valid_ds, test_ds
    """
    
    @abstractmethod
    def build_datasets(self, context: DatasetBuildContext) -> Tuple[Optional[Any], Optional[Any], Optional[Any]]:
        """构建数据集"""
        pass
```

## 数据加载器类型

```python
dataloader_type: Literal["single", "cyclic", "batch", "external"]
```

- **single**: 单次遍历数据集
- **cyclic**: 循环遍历（带shuffle）
- **batch**: 批量采样（用于微调）
- **external**: 外部数据加载器

## 数据流水线流程

### 构建流程

```
配置 → 数据集构建器 → 训练/验证/测试数据集 → 数据加载器 → 迭代器
                                │
        ┌───────────────────────┼───────────────────────┐
        │                       │                       │
  ┌─────▼──────┐        ┌───────▼───────┐      ┌───────▼──────┐
  │ PP首/末阶段 │        │  Megatron     │      │  Megatron    │
  │ TP rank 0  │──────▶ │  Data Sampler  │────▶│  Distributed │
  │ 构建数据集  │        │  (随机采样)    │      │  DataLoader  │
  └─────────────┘        └───────────────┘      └──────────────┘
```

### 内存优化策略

```python
def is_dataset_built_on_rank(pg_collection) -> bool:
    """仅特定 rank 构建数据集，节省内存。"""
    return (
        is_pp_first_stage(pg_collection.pp)
        or is_pp_last_stage(pg_collection.pp)
    ) and pg_collection.tp.rank() == 0
```

- **PP 首/末阶段**: 仅首阶段和末阶段 rank 构建数据集
- **TP rank 0**: 在 TP 组内仅 rank 0 构建
- **内存节省**: 避免所有 rank 重复构建相同数据集

# 1. 数据分配确保每个数据并行 rank 看到不同切片

### VLM 数据流程

```
原始对话数据 → Processor(图像+文本) → 多模态切片 → BatchPadding → Tensor
                              │
                              ▼
                    图像编码器 → Patch Embedding → 视觉 Token
                    文本编码器 → Tokenizer → 文本 Token
                              │
                              ▼
                        交错序列输入模型
```

### NullTokenizer

VLM 训练使用 `NullTokenizer`（空分词器）：
- 分词由 processor 完成（LLaVA、Qwen-VL 等内置分词）
- NullTokenizer 仅提供 vocab_size 占位
- 实际 tokenization 发生在 `hf_processor` 中

```python
cfg.tokenizer = TokenizerConfig(
    tokenizer_type="NullTokenizer",
    vocab_size=DEFAULT_NULL_TOKENIZER_VOCAB_SIZE,
)
```

## 总结

Megatron-Bridge 的数据处理系统通过：

1. **注册表模式**: 根据配置类型自动选择数据集提供者
2. **协议模式**: 支持自定义 `DatasetProvider` 实现
3. **统一接口**: 所有数据集提供者返回 `(train, valid, test)` 三元组
4. **Packed Sequence**: 提高短序列场景的训练效率

提供了灵活、可扩展的数据处理解决方案。
