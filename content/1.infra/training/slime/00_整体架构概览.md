# Slime 训练框架整体架构概览

## 1. 框架简介

Slime 是清华 GLM 团队开源的 **LLM 后训练框架**，专为 **RL Scaling** 设计，是 GLM-5、GLM-4.5/4.6/4.7 等模型的训练基座。支持 PPO、GRPO、SFT、DPO 等多种算法，无缝集成 Megatron-LM（训练）和 SGLang（推理）两大引擎。

### 核心特性

| 特性           | 说明                                        |
| ------------ | ----------------------------------------- |
| **训练-推理一体化** | Megatron + SGLang 深度集成，支持在线权重同步           |
| **多模态支持**    | 支持文本、VLM（Qwen3-VL、GLM-4V 等）训练             |
| **灵活部署模式**   | 支持 Colocate（共享 GPU）、分离部署、异步训练             |
| **分布式扩展**    | 基于 Ray 的分布式调度，支持千卡级规模                     |
| **丰富算法**     | PPO、GRPO、SFT、On-Policy Distillation、DPO 等 |

### 支持的模型

- **Qwen 系列**: Qwen3、Qwen3-MoE、Qwen3-Next、Qwen2.5
- **DeepSeek 系列**: DeepSeek-V3、V3.1、R1
- **GLM 系列**: GLM-4、GLM-4-MoE、GLM-5
- **Llama 系列**: Llama 3.x
- **GPT 系列**: GPT-OSS

## 2. 核心设计理念

```
┌─────────────────────────────────────────────────────────────────────┐
│                    Slime 设计哲学：Agent-Oriented                    │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│    ┌─────────────┐        ┌─────────────────┐        ┌───────────┐ │
│    │  Training   │◄──────►│   Data Buffer   │◄──────►│  Rollout  │ │
│    │  (Megatron) │   ³    │   (中间桥梁)     │   ¹    │ (SGLang)  │ │
│    └─────────────┘        └─────────────────┘        └───────────┘ │
│           ▲                                                   ²    │
│           └─────────────────────────────────────────────────────┘   │
│                              权重同步                                │
│                                                                     │
│    ¹ Prompt → Generation    ² 在线策略采样    ³ 策略更新              │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

**关键设计决策：**
1. **Rollout-Training 解耦**：数据生成与训练完全分离，可独立扩展
2. **Weight Streaming**：训练后即时同步权重到推理引擎，无需重启
3. **统一数据抽象**：`Sample` 类型贯穿全流程，灵活支持各种数据变体
4. **模块化扩展**：通过 Plugin 系统支持自定义 Reward、Filter、Rollout 逻辑

## 5. 训练流程详解

### 5.1 同步训练流程（train.py）

```python
import ray
from slime.ray.placement_group import create_placement_groups, create_rollout_manager, create_training_models
from slime.utils.arguments import parse_args

def train(args):
    """标准同步训练流程"""
    configure_logger()
    
    # ========== 1. 初始化阶段 ==========
    # 创建 Placement Group，分配 GPU 资源
    pgs = create_placement_groups(args)
    
    # 初始化追踪（wandb/tensorboard）
    init_tracking(args)
    
    # 创建 Rollout Manager（内部启动 SGLang 集群）
    rollout_manager, num_rollout_per_epoch = create_rollout_manager(args, pgs["rollout"])
    
    # 创建 Actor 和 Critic 训练模型
    actor_model, critic_model = create_training_models(args, pgs, rollout_manager)
    
    # 初始权重同步（训练模型 → SGLang 引擎）
    if not args.critic_train_only:
        actor_model.update_weights()
    
    # ========== 2. 训练循环 ==========
    for rollout_id in range(args.start_rollout_id, args.num_rollout):
        
        # 2.1 评估阶段（可选，按设定间隔）
        if should_eval(rollout_id):
            ray.get(rollout_manager.eval.remote(rollout_id))
        
        # 2.2 Generation 阶段：生成 Rollout 数据
        #     调用 SGLang 集群，生成 responses 并计算 rewards
        rollout_data_ref = ray.get(rollout_manager.generate.remote(rollout_id))
        
        # 2.3 Offload 阶段（Colocate 模式）：SGLang 释放 GPU
        if args.offload_rollout:
            ray.get(rollout_manager.offload.remote())
        
        # 2.4 Training 阶段：消费 Rollout 数据更新策略
        if args.use_critic:
            # 先训练 Critic（价值函数）
            critic_train_handle = critic_model.async_train(rollout_id, rollout_data_ref)
            
            # 再训练 Actor（策略）
            if not args.critic_train_only:
                ray.get(actor_model.async_train(rollout_id, rollout_data_ref))
            
            ray.get(critic_train_handle)
        else:
            # 仅训练 Actor（如 GRPO 无需 Critic）
            ray.get(actor_model.async_train(rollout_id, rollout_data_ref))
        
        # 2.5 Checkpoint 保存
        if should_save(rollout_id):
            actor_model.save_model(rollout_id)
            if args.use_critic:
                critic_model.save_model(rollout_id)
        
        # 2.6 Offload & 权重同步
        offload_train_models(args, actor_model, critic_model, rollout_id)
        
        if args.offload_rollout:
            # SGLang 重新加载权重
            ray.get(rollout_manager.onload_weights.remote())
        
        if not args.critic_train_only:
            # 同步最新权重到 SGLang
            actor_model.update_weights()
        
        if args.offload_rollout:
            ray.get(rollout_manager.onload_kv.remote())
    
    # ========== 3. 清理阶段 ==========
    ray.get(rollout_manager.dispose.remote())
    finish_tracking(args)

if __name__ == "__main__":
    args = parse_args()
    train(args)
```

if __name__ == "__main__":
