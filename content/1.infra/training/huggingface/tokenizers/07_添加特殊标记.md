## 1. 为什么需要特殊标记

### 1.1 场景分析

```
问题：模型训练后需要添加新token（如领域特殊标记）

场景1：对话系统
添加：<|user|>, <|assistant|>, <|system|>

场景2：指令微调（Instruction Tuning）
添加：<|instruction|>, <|response|>

场景3：工具调用
添加：<|tool_start|>, <|tool_end|>

场景4：多模态
添加：<|image|>, <|audio|>

场景5：领域术语
添加：医学术语、法律术语等
```

### 1.2 设计目标

- **增量添加**：不开箱即可添加新token
- **高效匹配**：快速检测特殊token
- **语义保留**：特殊token不被拆分
- **灵活配置**：支持多种匹配策略

## 2. AddedToken 数据结构

**文件**: `tokenizers/src/tokenizer/added_vocabulary.rs`

```rust
pub struct AddedToken {
    content: String,              // token字符串
    single_word: bool,              // 是否仅匹配完整单词
    lstrip: bool,                   // 是否去除左侧空白
    rstrip: bool,                   // 是否去除右侧空白
    normalized: bool,               // 是否参与normalization
    special: bool,                  // 解码时是否跳过
}

impl AddedToken {
    /// 便捷构造方法
    pub fn new(content: &str, special: bool) -> Self {
        AddedToken {
            content: content.to_string(),
            single_word: false,
            lstrip: false,
            rstrip: false,
            normalized: true,
            special,
        }
    }
}
```

### 2.1 属性详解

| 属性 | 类型 | 说明 | 默认值 |
|------|------|------|--------|
| `content` | String | token内容 | 必需 |
| `single_word` | bool | 仅匹配完整单词边界 | false |
| `lstrip` | bool | 匹配后去除左侧空白（用于指令模板） | false |
| `rstrip` | bool | 匹配后去除右侧空白 | false |
| `normalized` | bool | 是否经过normalizer处理 | true |
| `special` | bool | 是否为特殊token（解码时跳过） | 用户指定 |

### 2.2 Python API

```python
from tokenizers import AddedToken

# 简单创建
token = AddedToken("<|special|>", special=True)

# 完整配置
token = AddedToken(
    content="<|special|>",
    single_word=False,
    lstrip=True,
    rstrip=True,
    normalized=True,
    special=True,
)
```

## 3. AddedVocabulary 系统

**文件**: `tokenizers/src/tokenizer/added_vocabulary.rs` (lines 1-150+)

### 3.1 核心结构

```rust
pub struct AddedVocabulary {
    // token -> 全局ID映射（附加到模型vocab后）
    added_tokens_map: AHashMap<String, u32>,
    
    // 全局ID -> AddedToken元数据
    added_tokens_map_r: AHashMap<u32, AddedToken>,
    
    // 高效多模式匹配（使用DoubleArrayTrie）
    added_tokens_set: MatchingSet,
    
    // 特殊token集合
    special_tokens_set: AHashMap<String, ()>,
    
    // 是否编码特殊token的标志
    encode_special_tokens: bool,
}
```

### 3.2 工作原理

```
编码流程：
Input Text -> AddedVocabulary匹配 -> Model分词 -> 合并结果
                ↓
      使用Double-Array Trie
      进行O(n)多模式匹配
```

### 3.3 Double-Array Trie

使用 **Double-Array Aho-Corasick** 算法实现O(n)的多模式匹配：

```rust
// 使用daachorse库
pub struct MatchingSet {
    patterns: AhoCorasick,  // Double-Array Trie结构
}

impl MatchingSet {
    pub fn matches(&self, text: &str) -> Vec<Match> {
        // O(n)扫描，同时匹配所有模式
        self.patterns.find_iter(text).collect()
    }
}
```

## 4. API使用指南

### 4.1 添加特殊Token

```python
from tokenizers import Tokenizer

# 加载分词器
tokenizer = Tokenizer.from_pretrained("gpt2")

# 方法1：add_special_tokens（推荐）
special_tokens = ["<|user|>", "<|assistant|>", "<|system|>"]
num_added = tokenizer.add_special_tokens(special_tokens)
print(f"Added {num_added} special tokens")

# 方法2：使用AddedToken对象
token = AddedToken("<|custom|>", special=True)
num_added = tokenizer.add_special_tokens([token])
```

### 4.2 添加普通Token

```python
# 添加普通词汇（用于领域术语扩展）
new_tokens = ["领域术语1", "领域术语2", "technical_term"]
num_added = tokenizer.add_tokens(new_tokens)

# 或使用AddedToken配置匹配行为
token = AddedToken(
    "<|instruction|>",
    single_word=False,
    lstrip=True,
    special=True,
)
num_added = tokenizer.add_tokens([token])
```

### 4.3 ID查询

```python
# 获取ID
token_id = tokenizer.token_to_id("<|user|>")
print(f"<|user|> ID: {token_id}")

# 反向查询
token_str = tokenizer.id_to_token(token_id)
print(f"ID {token_id} -> {token_str}")

# 检查是否已添加
if tokenizer.token_to_id("<|user|>") is not None:
    print("Token exists")
```

## 5. 特殊标记处理策略

### 5.1 single_word策略

```python
from tokenizers import AddedToken

# single_word=False（默认）：任何位置匹配
token1 = AddedToken("<special>", special=True)
# "hello<special>world" -> ["hello", "<special>", "world"]

# single_word=True：仅匹配完整单词边界
token2 = AddedToken("<special>", special=True, single_word=True)
# "hello <special> world" -> ["hello", "<special>", "world"]
# "hello<special>world" -> ["hello<special>world"]（不拆分）
```

### 5.2 lstrip/rstrip策略

```python
# lstrip=True：匹配后去除左侧空白
# 用于指令模板：确保token紧贴文本
instruction = AddedToken("<|instruction|>", lstrip=True)

# 输入: "  <|instruction|>  Do something"
# 处理后: "<|instruction|>Do something"

# rstrip同理
response = AddedToken("<|response|>", rstrip=True)
```

### 5.3 normalized策略

```python
# normalized=True（默认）：参与normalization
# "<special>" -> normalizer处理后 -> 可能变化

# normalized=False：绕过normalization
# 用于保留原样，如特定格式标记
raw_token = AddedToken("<NO-NORM>", special=True, normalized=False)
```

### 5.4 special策略

```python
# special=True：解码时跳过
# encode: "<|special|>" -> [token_id_1]
# decode: [token_id_1] -> ""（不输出）

# special=False：解码时保留
normal_token = AddedToken("[MARKER]", special=False)
# encode: "[MARKER]" -> [token_id]
# decode: [token_id] -> "[MARKER]"
```

## 6. 实战示例

### 6.1 对话系统模板

```python
from tokenizers import Tokenizer, AddedToken

# 加载基础分词器
tokenizer = Tokenizer.from_pretrained("gpt2")

# 添加对话特殊token
chat_tokens = [
    AddedToken("<|system|>", special=True, lstrip=True),
    AddedToken("<|user|>", special=True, lstrip=True),
    AddedToken("<|assistant|>", special=True, lstrip=True),
    AddedToken("<|endoftext|>", special=True),
]
tokenizer.add_special_tokens(chat_tokens)

# 使用示例
def format_chat(messages):
    """格式化对话为模型输入"""
    text = ""
    for msg in messages:
        role = msg["role"]
        content = msg["content"]
        text += f"<|{role}|>{content}"
    text += "<|assistant|>"
    return text

messages = [
    {"role": "system", "content": "You are a helpful assistant."},
    {"role": "user", "content": "Hello!"},
]

input_text = format_chat(messages)
encoding = tokenizer.encode(input_text)
print(encoding.tokens)
# ['<|system|>', 'You', ' are', ... '<|user|>', 'Hello', '!', '<|assistant|>']
```

### 6.2 指令微调格式

```python
from tokenizers import Tokenizer, AddedToken

tokenizer = Tokenizer.from_pretrained("meta-llama/Llama-2-7b-hf")

# Llama2风格指令标记
instruction_tokens = [
    AddedToken("[INST]", special=True, rstrip=True),      # 指令开始
    AddedToken("[/INST]", special=True, lstrip=True),     # 指令结束/回复开始
    AddedToken("<<SYS>>", special=True),                  # 系统消息开始
    AddedToken("<</SYS>>", special=True),                 # 系统消息结束
]
tokenizer.add_special_tokens(instruction_tokens)

# 格式化
prompt = "[INST] <<SYS>> You are helpful <</SYS>> What is AI? [/INST]"
encoding = tokenizer.encode(prompt)
print(encoding.tokens)
```

## 7. 与模型vocab的合并策略

### 7.1 ID分配

```
模型原始vocab大小: V
添加的token数量: N

添加的token ID范围: [V, V+N)

原始: [0, 1, ..., V-1]
添加: [V, V+1, ..., V+N-1]
```
