## 1. 性能设计概览

### 1.1 性能目标

| 指标 | 目标 | 实现方式 |
|------|------|----------|
| 单条编码 | 微秒级 | Rust原生实现，零拷贝 |
| 批量编码 | 线性加速 | Rayon数据并行 |
| 内存占用 | 可控 | LRU缓存，按需分配 |
| 缓存命中 | >90% | BPE合并缓存 |

### 1.2 瓶颈分析

```
分词性能瓶颈分布：

BPE分词：
├── 缓存查找    (快，O(1))
├── 缓存未命中  (慢，需要完整解码)
│       └── 合并算法 (O(n * merges))
└── 缓存写入    (快)

批量处理：
├── Python循环  (慢，GIL限制)
└── Rust并行    (快，Rayon线程池)
```

## 2. Rayon并行处理

### 2.1 Rayon简介

Rayon是Rust的数据并行库，使用**work-stealing**调度算法：

```rust
// 简单并行迭代示例
use rayon::prelude::*;

let results: Vec<_> = inputs
    .par_iter()           // 并行迭代
    .map(|input| process(input))
    .collect();
```

### 2.2 Tokenizers中的并行实现

**文件**: `tokenizers/src/tokenizer/mod.rs`

```rust
impl<M, N, PT, PP, D> TokenizerImpl<M, N, PT, PP, D>
where 
    M: Model + Send + Sync,
    // ... Send约束确保线程安全
{
    /// 并行批量编码
    pub fn encode_batch(
        &self,
        inputs: Vec<EncodeInput>,
        add_special_tokens: bool,
    ) -> Result<Vec<Encoding>> {
        // 分配结果数组
        let mut encodings: Vec<Encoding> = Vec::with_capacity(inputs.len());
        
        // 使用Rayon并行处理
        inputs.into_par_iter()
            .map(|input| self.encode(input, add_special_tokens))
            .collect_into_vec(&mut encodings);
        
        Ok(encodings)
    }
    
    /// 并行批量解码
    pub fn decode_batch(
        &self,
        sentences: Vec<Vec<u32>>,
        skip_special_tokens: bool,
    ) -> Result<Vec<String>> {
        sentences.into_par_iter()
            .map(|ids| self.decode(&ids, skip_special_tokens))
            .collect()
    }
}
```

### 2.3 Python层绕过GIL

```rust
// Python绑定中释放GIL
#[pyfunction]
fn encode_batch(py: Python, tokenizer: &Tokenizer, texts: Vec<String>) -> PyResult<Vec<Encoding>> {
    py.allow_threads(|| {
        // 此处Python GIL已释放
        // Rust可以启动多线程处理
        tokenizer.encode_batch(texts, true)
    })
}
```

## 3. 缓存优化

### 3.1 BPE缓存系统

**文件**: `tokenizers/src/utils/cache.rs`

```rust
pub struct Cache<T: Clone> {
    map: LruCache<String, T>,
    capacity: usize,
}

impl<T: Clone> Cache<T> {
    pub fn get(&mut self, key: &str) -> Option<T> {
        self.map.get(key).cloned()
    }
    
    pub fn set(&mut self, key: String, value: T) {
        self.map.put(key, value);
    }
}
```

### 3.2 BPE中的缓存应用

**文件**: `tokenizers/src/models/bpe/model.rs`

```rust
pub struct BPE {
    cache: Option<Cache<Vec<Token>>>,
    cache_capacity: usize,
}

impl BPE {
    pub fn tokenize(&self, sequence: &str) -> Result<Vec<Token>> {
        // 1. 尝试缓存查找
        if let Some(cached) = self.cache.as_ref().and_then(|c| c.get(sequence)) {
            return Ok(cached);
        }
        
        // 2. 缓存未命中，执行完整算法
        let tokens = self.full_tokenize(sequence)?;
        
        // 3. 写入缓存
        if let Some(cache) = &self.cache {
            cache.set(sequence.to_string(), tokens.clone());
        }
        
        Ok(tokens)
    }
}
```

## 4. 线程池控制

### 4.1 Rayon环境变量

```bash

# 或运行时设置

```

### 4.2 线程数选择

| 场景 | 推荐线程数 | 说明 |
|------|-----------|------|
| 小批量 (<100) | 4 | 减少线程开销 |
| 大批量 (>1000) | CPU核心数 | 充分利用并行 |
| 多实例处理 | CPU核心数/实例数 | 避免争抢 |

## 5. 性能调优指南

### 5.1 批量大小选择

```python
import time
from tokenizers import Tokenizer

tokenizer = Tokenizer.from_pretrained("gpt2")
texts = ["Example text"] * 10000

# 测试不同批量大小
for batch_size in [1, 10, 100, 1000]:
    start = time.time()
    for i in range(0, len(texts), batch_size):
        batch = texts[i:i+batch_size]
        tokenizer.encode_batch(batch)
    elapsed = time.time() - start
    print(f"Batch size {batch_size}: {elapsed:.2f}s")

# 通常建议：
# - 小批量：100-500条
# - GPU推理场景：与batch_size对齐
```

## 6. 性能诊断

### 6.1 常见问题

| 现象 | 原因 | 解决 |
|------|------|------|
| 首次编码慢 | 缓存冷启动 | 预热编码常用词 |
| 批量处理慢 | Python循环代替encode_batch | 使用encode_batch |
| 内存占用高 | 缓存未限制 | 调整cache_capacity |
| CPU利用率低 | 单线程Python | 使用批处理API |

### 6.2 性能监控

```python
import time
from tokenizers import Tokenizer

tokenizer = Tokenizer.from_pretrained("gpt2")

# 监控单条性能
start = time.perf_counter()
for _ in range(1000):
    tokenizer.encode("Test sentence")
elapsed = time.perf_counter() - start
print(f"Single: {elapsed/1000*1000:.3f}ms per text")

# 监控批量性能
texts = ["Test sentence"] * 1000
start = time.perf_counter()
tokenizer.encode_batch(texts)
elapsed = time.perf_counter() - start
print(f"Batch: {elapsed/1000*1000:.3f}ms per text")
print(f"Speedup: {1000/(elapsed*1000):.1f}x")
```

## 8. 最佳实践总结

1. **始终使用encode_batch**：比Python循环快10-20倍
2. **预热缓存**：对于固定vocab，预编码高频词
3. **合理设置线程数**：通常等于物理核心数
4. **控制批量大小**：100-1000条效果最佳
5. **监控缓存命中率**：确保>90%
6. **使用合适的数据类型**：避免Python对象转换开销
