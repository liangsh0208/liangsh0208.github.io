## 1. 模块概述

张量并行（Tensor Parallel, TP）在层内进行切分，单节点（通常是8 GPU）内最高效。

### 【重点】层设计模式

| 层类型 | 切分维度 | 输入处理 | 输出通信 | 适用位置 |
|--------|---------|---------|---------|---------|
| `ColumnParallelLinear` | 输出列 (dim₀) | Copy/Identity | Gather (可选) | Attention QKV, MLP FC1 |
| `RowParallelLinear` | 输入行 (dim₁) | Scatter | All-Reduce | Attention Output, MLP FC2 |
| `VocabParallelEmbedding` | 词表维度 | Reduce-Scatter (可选SP) | All-Reduce | 输入Embedding |

**经典Pattern**: `ColumnParallelLinear → RowParallelLinear` 形成完整MLP，中间无需跨全局同步。

## 3. 核心概念与实现

### 3.1 ColumnParallelLinear

```python
# 文件: megatron/core/tensor_parallel/layers.py:731

class ColumnParallelLinear(torch.nn.Module):
    """列并行线性层。
    
    数学原理:
        Y = X @ A + b，其中 A ∈ ℝ^{input×output}
        TP切分: A = [A₁ | A₂ | ... | Aₙ] (按列切分)
        每个rank计算: Yᵢ = X @ Aᵢ + bᵢ
        
    输入: 所有rank收到完整输入X (通过Copy或Identity)
    输出: 每个rank产出部分输出Yᵢ
    若gather_output=True: All-Gather合并完整输出
    若用于Attention QKV: 不gather，直接进入下一层Attention计算
    """
    
    def __init__(
        self,
        input_size: int,
        output_size: int,
        config: ModelParallelConfig,
        init_method: Callable,
        gather_output: bool = False,  # 是否All-Gather输出
        bias: bool = True,
    ):
        super().__init__()
        self.tp_size = get_tensor_model_parallel_world_size()
        self.tp_rank = get_tensor_model_parallel_rank()
        
        # 每rank负责输出维度的一个分片
        self.output_size_per_partition = divide(output_size, self.tp_size)
        
        # 权重形状: [output_size_per_partition, input_size]
        self.weight = Parameter(torch.empty(
            self.output_size_per_partition, 
            input_size,
            device=torch.cuda.current_device(),
            dtype=config.params_dtype
        ))
        
        # 初始化
        _initialize_affine_weight_gpu(self.weight, init_method, partition_dim=0)
    
    def forward(self, input_):
        # 前向: 本地矩阵乘法 (输入已复制到所有TP rank)
        # backward: 梯度All-Reduce (在autograd Function中实现)
        output_parallel = linear_with_grad_accumulation_and_async_allreduce(
            input=input_,
            weight=self.weight,
            bias=self.bias,
            gradient_accumulation_fusion=self.config.gradient_accumulation_fusion,
            async_grad_allreduce=True,  # 异步All-Reduce
            sequence_parallel=self.config.sequence_parallel,
        )
        
        if self.gather_output:
            # 需要完整输出时All-Gather
            output = gather_from_tensor_model_parallel_region(output_parallel)
        else:
            # 输出分片供下一层使用 (如Attention计算)
            output = output_parallel  # [S, B, output_size/TP]
            
        return output
```

### 3.2 RowParallelLinear

```python
# 文件: megatron/core/tensor_parallel/layers.py:1072

class RowParallelLinear(torch.nn.Module):
    """行并行线性层。
    
    数学原理:
        Y = X @ A + b，其中 A ∈ ℝ^{input×output}
        TP切分: A = [A₁; A₂; ...; Aₙ]^T (按行切分)
        X需相应切分: X = [X₁ | X₂ | ... | Xₙ]
        每个rank计算: Y = Xᵢ @ Aᵢ
        最后All-Reduce合并: Y = Σ Yᵢ
        
    输入: 已分片的输入 (来自ColumnParallel或其他分片源)
    输出: All-Reduce后的完整输出
    """
    
    def __init__(
        self,
        input_size: int,
        output_size: int,
        config: ModelParallelConfig,
        init_method: Callable,
        input_is_parallel: bool = True,  # 输入是否已分片
    ):
        super().__init__()
        self.tp_size = get_tensor_model_parallel_world_size()
        self.input_is_parallel = input_is_parallel
        
        # 每rank负责输入维度的一个分片
        self.input_size_per_partition = divide(input_size, self.tp_size)
        
        # 权重形状: [output_size, input_size_per_partition]
        self.weight = Parameter(torch.empty(
            output_size,
            self.input_size_per_partition,
            device=torch.cuda.current_device(),
            dtype=config.params_dtype
        ))
        
        _initialize_affine_weight_gpu(self.weight, init_method, partition_dim=1)
    
    def forward(self, input_):
        # 若输入未分片，先Scatter
        if not self.input_is_parallel:
            input_ = scatter_to_tensor_model_parallel_region(input_)
            
        # 本地矩阵乘法
        output_parallel = F.linear(input_, self.weight)
        
        # All-Reduce合并各rank结果
        # Forward: All-Reduce，Backward: Identity (梯度已正确分片)
        output = reduce_from_tensor_model_parallel_region(output_parallel)
        
        # 加bias (只在rank 0加，减少重复计算)
        if self.bias is not None:
            output = output + self.bias
            
        return output
```

### 3.3 通信原语 (mappings.py)

```python
# 文件: megatron/core/tensor_parallel/mappings.py

# ==================== 核心通信原语 ====================

class _ReduceFromModelParallelRegion(torch.autograd.Function):
    """All-Reduce: 前向All-Reduce，反向广播梯度"""
    @staticmethod
    def forward(ctx, input_):
        return _reduce(input_)  # All-Reduce
    @staticmethod
    def backward(ctx, grad_output):
        return grad_output  # 梯度相同，直接传递

class _GatherFromModelParallelRegion(torch.autograd.Function):
    """All-Gather: 前向收集，反向分片返回"""
    @staticmethod  
    def forward(ctx, input_):
        return _gather_along_last_dim(input_)  # All-Gather
    @staticmethod
    def backward(ctx, grad_output):
        return _split_along_last_dim(grad_output)  # 分片返回

class _ScatterToModelParallelRegion(torch.autograd.Function):
    """Split: 前向分片，反向All-Gather"""
    @staticmethod
    def forward(ctx, input_):
        return _split_along_last_dim(input_)
    @staticmethod
    def backward(ctx, grad_output):
        return _gather_along_last_dim(grad_output)

# 便捷函数接口
reduce_from_tensor_model_parallel_region = _ReduceFromModelParallelRegion.apply
gather_from_tensor_model_parallel_region = _GatherFromModelParallelRegion.apply
scatter_to_tensor_model_parallel_region = _ScatterToModelParallelRegion.apply
```

### 3.4 序列并行 (Sequence Parallel)

序列并行在TP组内沿序列维度分片，进一步减少激活显存。

```python
# 开启后，输入从 [S, B, H] 分片为 [S/TP, B, H]

# 写入处: MLP的RowParallelLinear输出
def forward(self, hidden_states):
    # ... MLP计算
    output = self.linear_fc2(intermediate)
    if self.config.sequence_parallel:
        # Reduce-Scatter: 沿序列维度分片
        output = reduce_scatter_to_sequence_parallel_region(output)
    else:
        output = reduce_from_tensor_model_parallel_region(output)
```

### 3.5 与nanotron对比

| 对比项 | Megatron-LM | nanotron |
|--------|-------------|----------|
| **层实现** | `ColumnParallelLinear` / `RowParallelLinear` | 类似，但更简洁 |
| **通信封装** | Autograd Function (隐式) | 显式调用 `all_reduce` 等 |
| **序列并行** | 完善支持，独立开关 | 简化版本 |
| **参数初始化** | GPU直接初始化 + RNG tracker | 简化初始化 |
| **融合算子** | 支持梯度累积融合 | 无 |
| **代码规模** | 38000+行 (layers.py+mappings+random) | ~2000行 |
