# 大规模数据处理

> **【文档定位】** 超大规模数据集的内存高效处理策略
>
> **【版本信息】** 基于 HuggingFace datasets v4.8.5.dev0 (`src/datasets/table.py` ~3100行)
>
> **【前置知识】** Apache Arrow、内存映射、数据分片

---

## 模块概述

datasets 库专为大规模数据处理设计，通过内存映射、数据分片、惰性加载等技术，支持处理远超物理内存的数据集（TB级）。本模块介绍高效处理大规模数据的核心技术和方法。

### 核心技术

| 技术 | 说明 | 适用场景 |
|------|------|----------|
| **内存映射** | 按需加载数据到内存 | 数据集 > RAM |
| **数据分片** | 将数据集划分为多个小文件 | 并行处理、分布式训练 |
| **流式处理** | 边读取边处理 | 无需完整数据集的流水线处理 |
| **选择性加载** | 只加载需要的列 | 减少内存占用 |
| **多进程并行** | 利用多核 CPU 加速 | CPU 密集型 transform |

## 内存管理

### 内存映射表 (MemoryMappedTable)

```python
class MemoryMappedTable(Table):
    """
    内存映射表，仅加载需要的部分到物理内存
    支持操作系统自动换页
    """
    @staticmethod
    def from_file(filename):
        # 使用 pa.memory_map 创建内存映射
        memory_mapped_stream = pa.memory_map(filename)
        reader = pa.ipc.open_stream(memory_mapped_stream)
        table = reader.read_all()  # 仅创建视图，按需读取
        return cls(table)

    # 优势:
    # 1. 可以处理 > RAM 的数据集
    # 2. 多进程共享内存
    # 3. 操作系统自动缓存管理
```

### 内存映射使用场景

```python
from datasets import load_dataset, load_from_disk

# Scene 1: 加载 Hub 上的大数据集（自动内存映射）
big_dataset = load_dataset(
    "large_corpus",
    split="train"  # 自动使用内存映射
)

# Scene 2: 从磁盘加载已保存的数据集（内存映射）
dataset = load_from_disk("/path/to/saved/dataset")

# Scene 3: 显式控制内存使用
# 加载时指定缓存目录到高速磁盘
big_dataset = load_dataset(
    "large_corpus",
    split="train",
    cache_dir="/fast_ssd/cache"  # 高速 SSD 目录
)
```

## 数据分片

### Dataset.shard() 方法

```python
def shard(self, num_shards: int, index: int, contiguous: bool = False) -> "Dataset":
    """
    将数据集分片为 num_shards 份，返回第 index 份

    Args:
        num_shards: 总分片数
        index: 当前分片索引 (0 <= index < num_shards)
        contiguous: True=连续分片, False=交错分片

    Returns:
        分片后的子数据集
    """

# 使用示例
# 4 GPUs 训练场景
dataset = load_dataset("large_corpus", split="train")

# 获取当前 GPU 对应的数据分片
train_shard = dataset.shard(num_shards=4, index=local_rank)

# 每个 GPU 只处理 1/4 的数据
for batch in DataLoader(train_shard, batch_size=32):
    # 训练
    pass
```

### 分片策略对比

| 策略 | 模式 | 适用场景 |
|------|------|----------|
| **交错分片** | `contiguous=False` | 数据分布均匀，每个分片代表性相同 |
| **连续分片** | `contiguous=True` | 需保持数据顺序，如时间序列 |

```python
# 交错分片 (默认)
# 数据分布: [0,4,8...], [1,5,9...], [2,6,10...], [3,7,11...]
shard_0 = dataset.shard(num_shards=4, index=0, contiguous=False)

# 连续分片
# 数据分布: [0-249], [250-499], [500-749], [750-999]
shard_0 = dataset.shard(num_shards=4, index=0, contiguous=True)
```

## 数据组合

### concatenate_datasets()

```python
from datasets import concatenate_datasets

# 合并多个数据集（需相同 features）
train_2022 = load_dataset("data_2022", split="train")
train_2023 = load_dataset("data_2023", split="train")
train_2024 = load_dataset("data_2024", split="train")

# 按顺序合并
combined = concatenate_datasets([train_2022, train_2023, train_2024])
# 长度 = len(train_2022) + len(train_2023) + len(train_2024)
```

### interleave_datasets()

```python
from datasets import interleave_datasets

# 混合多个数据集
en_dataset = load_dataset("en_corpus", split="train")
fr_dataset = load_dataset("fr_corpus", split="train")
de_dataset = load_dataset("de_corpus", split="train")

# 按概率混合
mixed = interleave_datasets(
    [en_dataset, fr_dataset, de_dataset],
    probabilities=[0.7, 0.2, 0.1],  # 采样概率
    seed=42,
    stopping_strategy="all_exhausted"  # 全部遍历完才停止
)
```

### 停止策略

| 策略 | 说明 |
|------|------|
| `first_exhausted` | 任一数据集遍历完即停止（默认） |
| `all_exhausted` | 所有数据集都遍历完才停止 |

## 代码示例

### 处理 > RAM 数据集

```python
from datasets import load_dataset
import os

# 设置大容量缓存目录
os.environ['HF_DATASETS_CACHE'] = '/large_disk/huggingface_cache'

# 加载 TB 级数据集（自动内存映射）
dataset = load_dataset(
    "pile",
    split="train",
    streaming=False  # 非流式，使用内存映射
)

# 随机访问任意位置（仅加载需要的数据页）
sample = dataset[100000000]  # 1亿条数据，快速访问

# 批量处理（内存高效）
def process_batch(batch):
    return {'processed': [len(t) for t in batch['text']]}

processed = dataset.map(
    process_batch,
    batched=True,
    batch_size=10000,
    num_proc=8  # 8 进程并行
)
```

### 多机分布式训练

```python
import os
import torch
import torch.distributed as dist
from datasets import load_dataset
from torch.utils.data import DataLoader

# 初始化分布式环境
dist.init_process_group(backend='nccl')
rank = dist.get_rank()
world_size = dist.get_world_size()
local_rank = int(os.environ['LOCAL_RANK'])

# 加载数据集
dataset = load_dataset("large_corpus", split="train")

# 数据分片 (每个 rank 处理 1/world_size 的数据)
sharded_dataset = dataset.shard(num_shards=world_size, index=rank)

# 设置格式
sharded_dataset.set_format(
    type='torch',
    columns=['input_ids', 'attention_mask', 'labels'],
    device=f'cuda:{local_rank}'
)

# DataLoader
dataloader = DataLoader(
    sharded_dataset,
    batch_size=32,
    num_workers=4,
    shuffle=True
)

# 训练
for batch in dataloader:
    outputs = model(**batch)
    loss = outputs.loss
    loss.backward()
    optimizer.step()
```

### 选择性列加载

```python
from datasets import load_dataset

# 加载所有列
dataset = load_dataset("large_multimodal", split="train")

# 只加载需要的列（减少内存占用）
# 方法1: 加载时指定 columns (仅 Arrow Dataset 支持)
# 方法2: 使用 remove_columns
dataset = dataset.remove_columns(['unused_col1', 'unused_col2'])

# 方法3: map 时只保留需要的列
dataset = dataset.map(
    lambda x: {'processed': x['text'].upper()},
    remove_columns=dataset.column_names  # 删除所有原始列
)
```

### 分块保存与加载

```python
from datasets import load_dataset, DatasetDict

# 大数据集分块保存
dataset = load_dataset("huge_dataset", split="train")

# 保存为多个 shard
for i in range(0, len(dataset), 1000000):  # 每 100万 条保存一个 shard
    shard = dataset.select(range(i, min(i + 1000000, len(dataset))))
    shard.save_to_disk(f"/save/path/shard_{i//1000000:04d}")

# 加载时合并（惰性）
from datasets import load_from_disk, concatenate_datasets
shards = [
    load_from_disk(f"/save/path/shard_{i:04d}")
    for i in range(num_shards)
]
dataset = concatenate_datasets(shards)
```

### 流式处理超大文件

```python
from datasets import load_dataset

# 流式模式（无需完整下载）
stream_dataset = load_dataset(
    "pile",
    split="train",
    streaming=True
)

# 边下载边处理
for example in stream_dataset:
    # 处理单条数据
    process(example['text'])

# 或使用 batches
for batch in stream_dataset.iter(batch_size=1000):
    process_batch(batch)
```

## 常见问题排查

### 内存相关问题

| 现象 | 原因 | 解决方案 |
|------|------|----------|
| 加载大 CSV 时 OOM | 默认尝试全读内存 | 使用 `load_dataset(..., streaming=True)` |
| `select` 后内存未释放 | 实际是零拷贝，内存只增不减是 Arrow 表引用 | 用 `del dataset` 配合 `gc.collect()` |
| 内存占用持续增长 | 缓存文件累积 | 定期清理缓存目录；使用流式处理 |
| 多进程内存爆炸 | 每个进程加载完整数据集 | 使用 `shard()` 分片；使用内存映射 |

### 性能相关问题

| 现象 | 原因 | 解决方案 |
|------|------|----------|
| 随机访问慢 | 内存映射页未缓存 | 预热访问；顺序预读取 |
| shard 后不均衡 | 数据分布不均 | 预 shuffle；使用交错分片 |
| 合并数据集失败 | features 不匹配 | 确保所有数据集 features 完全一致 |
| 流式处理中断 | 网络问题 | 设置重试机制；本地缓存 |

### 分布式训练问题

| 现象 | 原因 | 解决方案 |
|------|------|----------|
| 多机数据重复/遗漏 | shard 设置错误 | 确认 `num_shards=world_size, index=rank` |
| GPU 利用率低 | CPU 预处理瓶颈 | 增加 `num_workers`；优化 `collate_fn` |
| 不同步 | 各节点种子不同 | 统一设置 `set_epoch(epoch)` |
