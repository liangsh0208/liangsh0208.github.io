# 格式化输出

> **【文档定位】** 多框架数据格式转换系统
>
> **【版本信息】** 基于 HuggingFace datasets v4.8.5.dev0 (`src/datasets/formatting/` ~500行)
>
> **【前置知识】** NumPy、PyTorch、TensorFlow、JAX API

---

## 模块概述

datasets 提供统一的格式化输出系统，支持将数据转换为 NumPy 数组、PyTorch 张量、TensorFlow 张量、JAX 数组、Pandas DataFrame、Polars DataFrame 等多种格式，无缝对接主流 ML 框架。

### 支持的格式

| 格式 | 标识符 | 说明 |
|------|--------|------|
| Python | `None` / `python` | Python 原生类型（默认） |
| NumPy | `numpy` | NumPy ndarray |
| PyTorch | `torch` | torch.Tensor |
| TensorFlow | `tensorflow` | tf.Tensor |
| JAX | `jax` | jax.numpy.array |
| Pandas | `pandas` / `pd` | pandas.DataFrame |
| Polars | `polars` | polars.DataFrame |
| Arrow | `arrow` | PyArrow Table |

## 核心实现

### Formatter 基类

```python
class Formatter(ABC):
    """格式转换器基类"""
    @abstractmethod
    def format_row(self, pa_table):
        """转换单行"""
        pass

    @abstractmethod
    def format_column(self, pa_table):
        """转换整列"""
        pass

    @abstractmethod
    def format_batch(self, pa_table):
        """转换批量"""
        pass
```

### TorchFormatter 示例

```python
class TorchFormatter(Formatter):
    """PyTorch Tensor，自动处理设备放置"""

    def __init__(self, device=None, **torch_tensor_kwargs):
        self.device = device
        self.torch_tensor_kwargs = torch_tensor_kwargs

    def format_column(self, pa_column, format_columns=None):
        # 先转换为 numpy
        numpy_arr = pa_column.to_numpy(zero_copy_only=False)
        # 再转换为 torch.tensor
        tensor = torch.tensor(numpy_arr, **self.torch_tensor_kwargs)
        # 移动到指定设备
        if self.device is not None:
            tensor = tensor.to(self.device)
        return tensor

    def format_batch(self, pa_table):
        return {
            col: torch.tensor(
                pa_table[col].to_numpy(zero_copy_only=False),
                **self.torch_tensor_kwargs
            ).to(self.device) if self.device else torch.tensor(...)
            for col in pa_table.column_names
        }
```

## 代码示例

### 基础格式设置

```python
from datasets import load_dataset
import torch

dataset = load_dataset("rajpurkar/squad", split="train")

# 设置为 NumPy 格式
dataset.set_format(type='numpy')
print(dataset[0]['question'])  # np.ndarray

# 设置为 PyTorch 格式
dataset.set_format(type='torch')
print(dataset[0]['question'])  # torch.Tensor

# 恢复默认格式
dataset.reset_format()
print(dataset[0]['question'])  # Python str
```

### PyTorch 格式详解

```python
import torch
from datasets import load_dataset

dataset = load_dataset("glue", "mrpc", split="train")

# 基础设置
dataset.set_format(type='torch')

# 设置特定列
dataset.set_format(
    type='torch',
    columns=['input_ids', 'attention_mask', 'label']
)

# 设置设备（自动放置到 GPU）
dataset.set_format(
    type='torch',
    columns=['input_ids', 'attention_mask', 'label'],
    device='cuda:0'
)

# 设置数据类型
dataset.set_format(
    type='torch',
    columns=['input_ids'],
    dtype=torch.int64
)

# 访问数据
batch = dataset[0]  # dict of tensors on cuda:0
print(batch['input_ids'].device)  # cuda:0
```

### 使用 with 临时切换

```python
from datasets import load_dataset
import numpy as np

dataset = load_dataset("rajpurkar/squad", split="train")

# 默认 Python 格式
print(isinstance(dataset[0]['question'], str))  # True

# 临时切换为 numpy
with dataset.with_format('numpy'):
    batch = dataset[0:100]
    print(isinstance(batch['question'], np.ndarray))  # True

# 恢复 Python 格式
print(isinstance(dataset[0]['question'], str))  # True
```

### 批量读取与 DataLoader 集成

```python
import torch
from datasets import load_dataset
from torch.utils.data import DataLoader

dataset = load_dataset("glue", "mrpc", split="train")

# 设置格式
dataset.set_format(
    type='torch',
    columns=['input_ids', 'attention_mask', 'label']
)

# 自定义 collate 函数（可选）
def collate_fn(batch):
    return {
        'input_ids': torch.stack([x['input_ids'] for x in batch]),
        'attention_mask': torch.stack([x['attention_mask'] for x in batch]),
        'labels': torch.tensor([x['label'] for x in batch])
    }

# DataLoader
dataloader = DataLoader(
    dataset,
    batch_size=32,
    shuffle=True,
    collate_fn=collate_fn
)

# 训练循环
for batch in dataloader:
    input_ids = batch['input_ids'].to('cuda')
    labels = batch['labels'].to('cuda')
    # ...训练...
```

## 配置参数表

### set_format 参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `type` | str | `python` | 格式类型：numpy/torch/tensorflow/jax/pandas/polars |
| `columns` | list[str] | None | 指定输出的列名 |
| `output_all_columns` | bool | False | 是否输出所有列 |
| `**format_kwargs` | dict | - | 格式特定参数 |

### 格式特定参数

| 格式 | 参数 | 说明 |
|------|------|------|
| `torch` | `device` | 设备位置 (`cpu`, `cuda:0`) |
| `torch` | `dtype` | 张量数据类型 |
| `tensorflow` | - | 无特殊参数 |
| `jax` | - | 无特殊参数 |
| `pandas` | - | 无特殊参数 |
| `polars` | - | 无特殊参数 |

### to_tf_dataset 参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `columns` | list[str] | 特征列 |
| `label_cols` | list[str] | 标签列 |
| `batch_size` | int | 批次大小 |
| `shuffle` | bool | 是否打乱 |
| `collate_fn` | Callable | 自定义 collate 函数 |

## 常见问题排查

### 格式转换问题

| 现象 | 原因 | 解决方案 |
|------|------|----------|
| `TypeError: can't convert type` | Arrow 类型与目标格式不兼容 | 检查数据类型；使用 `cast_column` 预转换 |
| `RuntimeError: CUDA out of memory` | 张量已放到 GPU 但内存不足 | 减小 batch_size；使用 `device='cpu'` |
| 数据格式未变化 | 未正确调用 set_format | 确认调用后使用 `dataset.format` 属性检查 |

### 框架集成问题

| 现象 | 原因 | 解决方案 |
|------|------|----------|
| PyTorch 张量在 CPU | device 参数未设置 | `set_format('torch', device='cuda')` |
| JAX 设备不匹配 | 多设备环境 | 使用 `jax.device_put()` 手动转移 |
| TensorFlow Dataset 失败 | to_tf_dataset 参数错误 | 检查 columns 和 label_cols 是否正确 |

### 性能问题

| 现象 | 原因 | 解决方案 |
|------|------|----------|
| 批量转换慢 | 每行单独转换 | 使用切片访问 `dataset[start:end]` 批量获取 |
| 内存占用大 | 格式转换额外拷贝 | 使用 `zero_copy_only`；减少 columns |
| DataLoader 卡死 | collate_fn 问题 | 统一张量形状；检查数据类型一致性 |
