## 1. 设计哲学

Huggingface Tokenizers是一个高性能文本分词库，使用Rust实现核心，并为Python/Node.js提供绑定。库的设计哲学是**管道化（Pipeline）**架构，将分词过程解耦为多个可组合的独立阶段。

### 核心功能

| 功能 | 说明 |
|------|------|
| **多算法支持** | BPE、WordPiece、Unigram、WordLevel |
| **高性能** | 并行批处理、LRU缓存、Rust原生性能 |
| **可训练** | 支持从语料库训练新词汇表 |
| **对齐追踪** | 维护token与原始文本的偏移映射 |
| **多语言绑定** | Python、Node.js、Ruby |

---

## 2. Pipeline架构

分词被建模为**数据处理流水线**，每个阶段专注单一职责：

```
Raw Text -> [Normalizer] -> [PreTokenizer] -> [Model] -> [PostProcessor] -> [Decoder]
                ↓                ↓              ↓              ↓              ↓
           文本清洗        初步分割        ID映射      添加特殊token    还原文本
```

### 设计优势

- **可组合性**：各组件可独立替换（如更换Normalizer不影响Model）
- **可测试性**：每个阶段可单独验证
- **可扩展性**：新增组件类型无需修改核心逻辑

### 3.2 TokenizerImpl - 管道编排器

**文件**: `tokenizers/src/tokenizer/mod.rs` (lines 513-1606)

核心结构体，聚合所有管道组件：

```rust
#[derive(Clone, Debug)]
pub struct TokenizerImpl<M, N, PT, PP, D> {
    normalizer: Option<N>,          // 文本规范化
    pre_tokenizer: Option<PT>,      // 预分割
    model: M,                       // 核心分词模型（必需）
    post_processor: Option<PP>,    // 后处理
    decoder: Option<D>,             // ID解码器
    added_vocabulary: AddedVocabulary,  // 扩展词汇
    truncation: Option<TruncationParams>,
    padding: Option<PaddingParams>,
}
```

## 4. Wrapper多态模式

### 4.1 设计动机

Rust无原生动态分发，使用**Enum Wrapper**实现组件多态：

```rust

    BPE(BPE),
    WordPiece(WordPiece),
    WordLevel(WordLevel),
    Unigram(Unigram),
}
impl Model for ModelWrapper { /* 委托给内部类型 */ }
```

## 5. 偏移量追踪设计

### 5.1 核心数据结构

核心数据结构`Encoding`维护**双向映射**：
- `char_to_token`: 字符位置 -> Token索引
- `token_to_chars`: Token索引 -> 字符区间

这对NLP任务（如实体识别、问答）至关重要。

### 5.2 实现位置

**文件**: `tokenizers/src/tokenizer/encoding.rs` (lines 10-562)

```rust
#[derive(Default, PartialEq, Debug, Clone, Serialize, Deserialize)]
pub struct Encoding {
    ids: Vec<u32>,                    // Token IDs
    type_ids: Vec<u32>,              // Segment IDs (BERT的0/1)
    tokens: Vec<String>,             // Token字符串
    words: Vec<Option<u32>>,         // Word ID映射
    offsets: Vec<Offsets>,           // 字符偏移区间
    special_tokens_mask: Vec<u32>,   // 特殊标记掩码
    attention_mask: Vec<u32>,        // Attention掩码
    overflowing: Vec<Encoding>,      // 截断产生的溢出片段
    sequence_ranges: AHashMap<usize, Range<usize>>,  // 多序列范围
}
```
