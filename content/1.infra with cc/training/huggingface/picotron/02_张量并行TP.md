# 02_张量并行TP

## 1. 目标论证

**为什么需要 Tensor Parallel？**

Transformer层(Llama-34B+)的单个线性层权重 > 10GB，超出单A100显存限制。
- 问题: Attention前投影层(hidden_size=8192, num_heads=64)的形状巨大
- 影响: 无法完整加载模型到单设备

**Megatron-LM切分策略：**
- 将矩阵乘法拆分列/行两个维度
- 每个设备仅存储 1/N 权重
- 通信开销: 每层的2次All-Reduce(gigabyte带宽可接受)

## 2. 工作假设

**约束条件：**
- `num_attention_heads % tp_size == 0` (头数可被TP整除)
- `num_key_value_heads % tp_size == 0` (GQA要求)
- `hidden_size % tp_size == 0` (嵌入维度要求)

**通信假设：**
- 节点内NVLink带宽 > 50GB/s
- TP组限制在单节点内(避免跨机通信)

## 3. 解决方案

### 3.1 列并行线性层

```python
# 文件: tensor_parallel/tensor_parallel.py
class ColumnParallelLinear(nn.Module):
    """
    切分方式: 按输出维度切分
    Y = [XW_1, XW_2, ...]  # 每TP rank计算部分输出
    需要: All-Reduce聚合最终输出
    """
    def __init__(self, in_features, out_features, bias=True, ...):
        # 计算本地输出维度
        output_size_per_partition = out_features // tp_world_size
        
        # 权重形状: (out_features/tp_size, in_features)
        self.weight = nn.Parameter(torch.Tensor(
            output_size_per_partition, in_features
        ))
        
    def forward(self, x):
        # 自动触发All-Reduce
        return linear_with_all_reduce(x, self.weight, self.bias)
```

### 3.2 行并行线性层

```python
class RowParallelLinear(nn.Module):
    """
    切分方式: 按输入维度切分
    Y = sum([X_1, X_2, ...] @ W)  # 各部分结果All-Reduce求和
    """
    def forward(self, x):
        # 先本地计算
        output_parallel = F.linear(x, self.weight)
        
        # All-Reduce聚合: + 操作在反向传播时自动处理
        return ReduceFromModelParallelRegion.apply(output_parallel)
```

### 3.3 All-Reduce通信算子

```python
class ReduceFromModelParallelRegion(torch.autograd.Function):
    """前向All-Reduce, 反向Identity"""
    
    @staticmethod
    def forward(ctx, input_):
        # 前向: 聚合所有进程的结果
        return all_reduce(input_, group=tp_group)
    
    @staticmethod
    def backward(ctx, grad_output):
        # 反向: 梯度已经在All-Reduce后相同
        return grad_output

class GatherFromModelParallelRegion(torch.autograd.Function):
    """前向Gather, 反向Scatter(词表并行输出层)"""
    
    @staticmethod
    def forward(ctx, input_):
        # 收集所有分片的logits
        return gather(input_, dim=-1, group=tp_group)
    
    @staticmethod
    def backward(ctx, grad_output):
        # 梯度只回传到对应分片
        return scatter(grad_output, dim=-1, group=tp_group)
```

### 3.5 应用TP到模型

```python
def apply_tensor_parallel(model):
    """
    遍历模型，替换Linear层为TP版本
    """
    for name, module in model.named_modules():
        # 根据层类型选择切分方式
        if is_qkv_proj(name):
            new_module = ColumnParallelLinear(...)
        elif is_output_proj(name):
            new_module = RowParallelLinear(...)
        # ... 其他层
        
    # 特殊处理: 强制创建独立lm_head
    # 避免与embed_tokens的tied weights问题
    model.lm_head = nn.Linear(..., bias=False)
```

## 4. 故障模式

| 问题 | 可能原因 | 解决方案 |
|-----|---------|---------|
| `num_attention_heads not divisible` | TP size不能整除头数 | 调整头数或TP size |
| Output形状不匹配 | Gather后维度错误 | 检查gather的dim参数(通常在-1) |
| 梯度爆炸 | 权重初始化未按TP缩放 | 使用 `init_method=kaiming` 且按sqrt(tp_size)缩放 |
| 词汇表损失计算异常 | lm_head与embedding权重共享问题 | 强制创建独立lm_head |
| 通信死锁 | TP组内进程未同步 | 确认所有进程调用相同的All-Reduce |
