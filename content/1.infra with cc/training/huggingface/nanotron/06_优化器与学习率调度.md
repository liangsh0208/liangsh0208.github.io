## 2. 模块概述

Nanotron 的优化器系统提供了一个完整的分布式训练优化解决方案，包含以下核心功能：

### 2.1 主要组件

| 组件 | 文件 | 功能描述 |
|------|------|----------|
| **NamedOptimizer** | `named_optimizer.py` | 带参数名称映射的优化器包装器 |
| **ZeroDistributedOptimizer** | `zero.py` | ZeRO Stage 1 分布式优化器实现 |
| **FP32GradientAccumulator** | `gradient_accumulator.py` | FP32 梯度累积器，支持混合精度训练 |
| **lr_scheduler_builder** | `helpers.py` | 学习率调度器构建器 |
| **clip_grad_norm** | `clip_grads.py` | 梯度裁剪实现 |
| **Optimizer Args** | `config/config.py` | 优化器配置参数定义 |

### 2.2 支持的优化器类型

- **AdamW** (`torch.optim.AdamW`): 默认优化器，支持融合内核 (`fused=True`)
- **Adam** (`torch.optim.Adam`): 标准 Adam 优化器
- **SGD** (`torch.optim.SGD`): 随机梯度下降

### 2.3 学习率调度策略

- **Warmup**: `linear` (线性预热), `constant` (常数预热)
- **Decay**: `cosine` (余弦退火), `linear` (线性衰减), `1-sqrt` (平方根衰减)
- **Constant 阶段**: 预热后的常数阶段，衰减后的最小学习率阶段

### 2.4 混合精度支持

- **FP16/BF16**: 模型前向/后向使用低精度
- **FP32 梯度累积**: 可选的 `accumulate_grad_in_fp32` 模式
- **FP8**: 通过 Transformer Engine 支持（需额外配置）

```python
    )
```

```python
def lr_scheduler_builder(
    optimizer: Optimizer, 
    lr_scheduler_args: LRSchedulerArgs, 
    total_training_steps: int
):
    """构建学习率调度器，支持 warmup + decay + constant 多阶段调度"""
    
    # 计算衰减步数
    if lr_scheduler_args.lr_decay_steps is None:
        lr_decay_steps = total_training_steps
        if lr_scheduler_args.lr_warmup_steps is not None:
            lr_decay_steps -= lr_scheduler_args.lr_warmup_steps
        if lr_scheduler_args.lr_decay_starting_step is not None:
            lr_decay_steps -= lr_scheduler_args.lr_decay_starting_step
    else:
        lr_decay_steps = lr_scheduler_args.lr_decay_steps
    
    # 计算衰减起始步
    if lr_scheduler_args.lr_decay_starting_step is None:
        lr_decay_starting_step = (
            lr_scheduler_args.lr_warmup_steps 
            if lr_scheduler_args.lr_warmup_steps is not None 
            else 0
        )
    else:
        lr_decay_starting_step = lr_scheduler_args.lr_decay_starting_step
    
    def lr_lambda(current_step: int, initial_lr: float):
        """学习率调度函数，支持 2-4 个阶段"""
        # 1. 无预热也无衰减
        if lr_scheduler_args.lr_warmup_steps == 0 and lr_decay_steps == 0:
            return initial_lr
        
        # 2. 预热阶段
        elif (lr_scheduler_args.lr_warmup_style is not None and 
              current_step <= lr_scheduler_args.lr_warmup_steps):
            if lr_scheduler_args.lr_warmup_style == "linear":
                lmbda = initial_lr * current_step / max(lr_scheduler_args.lr_warmup_steps, 1)
            elif lr_scheduler_args.lr_warmup_style == "constant":
                lmbda = lr_scheduler_args.learning_rate
            else:
                raise ValueError(f"Unknown warmup style {lr_scheduler_args.lr_warmup_style}")
        
        # 3. 可选常数阶段（在 learning_rate）
        elif current_step < lr_decay_starting_step:
            lmbda = initial_lr
        
        # 4. 衰减阶段
        elif (lr_scheduler_args.lr_decay_style is not None and 
              current_step < lr_decay_starting_step + lr_decay_steps):
            
            progress = (current_step - lr_decay_starting_step) / lr_decay_steps
            
            if lr_scheduler_args.lr_decay_style == "cosine":
                # 余弦退火
                lmbda = (
                    lr_scheduler_args.min_decay_lr
                    + (initial_lr - lr_scheduler_args.min_decay_lr)
                    * (1 + math.cos(math.pi * progress)) / 2
                )
            elif lr_scheduler_args.lr_decay_style == "linear":
                # 线性衰减
                lmbda = (
                    lr_scheduler_args.min_decay_lr
                    + (initial_lr - lr_scheduler_args.min_decay_lr)
                    * (1 - progress)
                )
            elif lr_scheduler_args.lr_decay_style == "1-sqrt":
                # 平方根衰减
                lmbda = lr_scheduler_args.min_decay_lr + (
                    initial_lr - lr_scheduler_args.min_decay_lr
                ) * (1 - math.sqrt(progress))
            else:
                raise ValueError(f"Unknown decay style {lr_scheduler_args.lr_decay_style}")
        
        # 5. 最终常数阶段（在 min_decay_lr）
        else:
            lmbda = lr_scheduler_args.min_decay_lr
        
        # PyTorch LambdaLR 需要归一化
        lmbda /= initial_lr
        return lmbda
    
    # 为每个参数组创建学习率函数
    lr_lambdas = [
        partial(lr_lambda, initial_lr=pg["lr"])
        for pg in optimizer.get_base_optimizer().param_groups
    ]
    
    lr_scheduler = LambdaLR(optimizer.get_base_optimizer(), lr_lambda=lr_lambdas)
    return lr_scheduler
```

```python
@torch.profiler.record_function("clip_grad_norm")
def clip_grad_norm(
    mp_pg: dist.ProcessGroup,           # 模型并行进程组 (TP x PP)
    named_parameters: Iterable[Tuple[str, NanotronParameter]],
    max_norm: float,                    # 最大梯度范数
    grad_accumulator: Optional[GradientAccumulator],
    norm_type: float = 2.0,            # 范数类型 (2.0=L2, inf=无穷范数)
) -> torch.Tensor:
    """梯度裁剪实现，支持分布式和 FP32 梯度累积"""
    
    # 选择裁剪来源：普通梯度或 FP32 累积梯度
    if grad_accumulator is None:
        grads = [
            p.grad for _, p in named_parameters 
            if not p.is_tied or world_rank == p.get_tied_info().global_ranks[0]
        ]
    else:
        grads = [
            grad_accumulator.get_grad_buffer(name)
            for name, p in named_parameters
            if not p.is_tied or world_rank == p.get_tied_info().global_ranks[0]
        ]
    
    # 计算梯度范数（FP32 精度）
    if norm_type == torch.inf:
        # 无穷范数：取最大绝对值
        total_norm = torch.max(
            torch.stack([
                torch.linalg.vector_norm(g.detach(), ord=torch.inf, dtype=torch.float) 
                for g in grads
            ])
        )
        dist.all_reduce(total_norm, group=mp_pg, op=dist.ReduceOp.MAX)
    else:
        # L2 范数（或其他 p-范数）
        total_norm = torch.linalg.vector_norm(
            torch.stack([
                torch.linalg.vector_norm(g.detach(), ord=norm_type, dtype=torch.float) 
                for g in grads
            ]),
            ord=norm_type,
            dtype=torch.float,
        ).pow(norm_type)
        dist.all_reduce(total_norm, group=mp_pg, op=dist.ReduceOp.SUM)
        total_norm.pow_(1.0 / norm_type)
    
    # 计算裁剪系数并应用
    clip_coef = max_norm / (total_norm + 1.0e-6)
    clip_coef_clamped = torch.clamp(clip_coef, max=1.0)
    
    for name, param in named_parameters:
        if grad_accumulator is None:
            param.grad.detach().mul_(clip_coef_clamped)
        else:
            grad_accumulator.get_grad_buffer(name).detach().mul_(clip_coef_clamped)
    
    return total_norm
```

```python
class FP32GradientAccumulator(GradientAccumulator):
    """在 FP32 精度下累积梯度，支持混合精度训练"""
    
    def __init__(
        self,
        named_parameters: Iterator[Tuple[str, NanotronParameter]],
        grad_buckets_named_params: Optional[Iterator[Tuple[str, NanotronParameter]]] = None,
    ):
        # 1. 构建 FP32 梯度缓冲区
        self.fp32_grad_buffers, self._contiguous_fp32_grad_buffer = self.build_grad_buffers(
            named_parameters=grad_buckets_named_params
        )
        
        # 2. 创建 FP32 参数副本用于优化器更新
        big_flat_buffer = torch.empty(length, dtype=torch.float, device="cuda")
        self.parameters = {
            name: {
                "fp32": big_flat_buffer[start_weight:end_weight].view_as(param),
                "half": param,  # BF16/FP16 原始参数
            }
            for name, (start_weight, end_weight, param) in segment_index.items()
        }
        
        # 3. 从 half 精度复制到 fp32
        with torch.inference_mode():
            for _, elt in self.parameters.items():
                elt["fp32"].copy_(elt["half"])
                elt["fp32"].requires_grad = True
    
    def _accumulate_grad(self, name: str, half_param: NanotronParameter) -> None:
        """累积 half 精度梯度到 FP32 缓冲区"""
        assert half_param.grad is not None, f"Expected param {name} to have gradient."
        fp32_grad = self.get_grad_buffer(name=name)
        
        if not self._is_accumulation_sync_step:
            # 累积梯度
            fp32_grad.add_(half_param.grad)
        
        # 清空 half 精度梯度
        half_param.grad = None
        
        # 将 FP32 梯度赋给优化器使用的参数
        if name in self.parameters:
            fp32_param = self.parameters[name]["fp32"]
            fp32_param.grad = fp32_grad
    
    def sync_gradients_across_dp(self, dp_pg: dist.ProcessGroup, reduce_op: dist.ReduceOp, reduce_scatter: bool):
        """跨数据并行进程同步梯度"""
        if reduce_scatter:
            # ZeRO-1: 使用 reduce_scatter 代替 all_reduce
            dist.reduce_scatter_coalesced(
                output_tensor_list=[...],  # 当前 rank 的切片
                input_tensor_lists=[...],   # 所有 rank 的完整梯度
                group=dp_pg,
            )
        else:
            # 标准 DDP: all_reduce
            dist.all_reduce(self._contiguous_fp32_grad_buffer, op=reduce_op, group=dp_pg)
    
    def step(self):
        """将 FP32 更新后的权重复制回 half 精度"""
        for name in self.parameters.keys():
            fp32_param = self.parameters[name]["fp32"]
            half_param = self.parameters[name]["half"]
            half_param.copy_(fp32_param)  # FP32 → BF16/FP16
```

```python
        named_params_or_groups: Iterable[Union[Tuple[str, NanotronParameter], Dict[str, Any]]],
        optimizer_builder: Callable[[Iterable[Dict[str, Any]]], BaseOptimizer],
        dp_pg: ProcessGroup,
    ):
        self.dp_pg = dp_pg
        
        # 1. 计算参数到 DP rank 的映射（分片方案）
        self.param_name_to_dp_rank_offsets = self._partition_parameters()
        
        # 2. 获取当前 DP rank 的参数切片
        current_dp_rank = dist.get_rank(self.dp_pg)
        param_groups_in_rank = [
            {
                "named_params": [
                    (
                        name,
                        get_sliced_tensor(
                            param=param,
                            start_offset=self.param_name_to_dp_rank_offsets[name][current_dp_rank][0],
                            end_offset=self.param_name_to_dp_rank_offsets[name][current_dp_rank][1],
                        ),
                    )
                    for name, param in param_group["named_params"]
                    if current_dp_rank in self.param_name_to_dp_rank_offsets[name]
                ],
                # 其他参数组属性...
            }
            for param_group in self.zero_named_param_groups
        ]
        
        # 3. 使用切片后的参数构建基础优化器
        optimizer = optimizer_builder(param_groups_in_rank)
        super().__init__(optimizer=optimizer, id_to_name=optimizer.id_to_name)
    
    def _partition_parameters(self) -> Dict[str, Dict[int, Tuple[int, int]]]:
        """将参数均匀分片到各个 DP rank"""
        for name, param in named_params:
            # 计算每个 DP rank 的偏移量
            numel = param.numel()
            padded_numel_per_dp = (numel - 1) // self.dp_pg.size() + 1
            sizes = np.full(shape=(self.dp_pg.size()), fill_value=padded_numel_per_dp)
            
            # 调整最后一个 rank 的大小（可能不需要 padding）
            remainder = padded_numel_per_dp * self.dp_pg.size() - numel
            if remainder > 0:
                sizes[-remainder:] -= 1
            
            end_offsets = np.cumsum(sizes)
            start_offsets = np.concatenate([[0], end_offsets[:-1]])
            
            param_name_to_dp_rank_offsets[name] = {
                dp_rank: (start_offsets[dp_rank], end_offsets[dp_rank])
                for dp_rank in range(self.dp_pg.size())
                if start_offsets[dp_rank] < end_offsets[dp_rank]
            }
        
        return param_name_to_dp_rank_offsets
    
    @torch.no_grad()
    def step(self, closure: Optional[Callable[[], float]] = None) -> Optional[float]:
        """执行本地参数更新后 all-gather 到所有 rank"""
        loss = super().step(closure=closure)
        
        # All gather 更新后的参数
        self._all_gather_params()
        return loss
    
    @torch.profiler.record_function("all_gather_params")
    def _all_gather_params(self):
        """将所有 DP rank 的参数更新聚合到所有 rank"""
        current_dp_rank = dist.get_rank(self.dp_pg)
        dist.all_gather_coalesced(
            output_tensor_lists=[  # 接收所有 rank 的切片
                [
                    tensor[slice(*self.param_name_to_dp_rank_offsets[name][dp_rank])]
                    if dp_rank in self.param_name_to_dp_rank_offsets[name]
                    else torch.empty(0, dtype=tensor.dtype, device=tensor.device)
                    for dp_rank in range(self.dp_pg.size())
                ]
                for name, tensor in all_named_tensors_to_gather
            ],
            input_tensor_list=[  # 发送当前 rank 的切片
                tensor[slice(*self.param_name_to_dp_rank_offsets[name][current_dp_rank])]
                if current_dp_rank in self.param_name_to_dp_rank_offsets[name]
                else torch.empty(0, dtype=tensor.dtype, device=tensor.device)
                for name, tensor in all_named_tensors_to_gather
            ],
            group=self.dp_pg,
        )
```

```yaml
optimizer:

    lr_decay_style: cosine     # 衰减策略: linear|cosine|1-sqrt
    lr_decay_steps: 80000      # 衰减步数（可选，默认剩余步数）
    lr_decay_starting_step: 2000  # 衰减起始步（可选，默认预热结束）
    min_decay_lr: 3.0e-5       # 最小学习率
```

### 5.2 学习率调度配置详解

| 参数 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| `learning_rate` | float | 必需 | 初始（最大）学习率 |
| `lr_warmup_steps` | int | 0 | 学习率从 0 预热到 `learning_rate` 的步数 |
| `lr_warmup_style` | str | "linear" | 预热策略："linear" 或 "constant" |
| `lr_decay_style` | str | "linear" | 衰减策略："linear", "cosine", "1-sqrt" |
| `lr_decay_steps` | int | None | 衰减步数，默认 `total_steps - lr_warmup_steps	ep - lr_decay_starting_step` |
| `lr_decay_starting_step` | int | None | 衰减开始步，默认 `lr_warmup_steps` |
| `min_decay_lr` | float | `learning_rate` | 衰减后的最小学习率 |

### 5.3 调度策略对比

| 策略 | 公式 (学习率比例) | 适用场景 |
|------|------------------|----------|
| **Linear** | `1 - (step / total_steps)` | 稳定收敛，通用场景 |
| **Cosine** | `0.5 * (1 + cos(π * step / total_steps))` | 平滑衰减，大模型训练 |
| **1-sqrt** | `1 - sqrt(step / total_steps)` | 快速衰减初期，缓慢后期 |
| **Constant** | `1.0` | 需要固定学习率的阶段 |

## 6. 常见问题 (FAQ)

### 6.1 优化器相关问题

**Q1: 如何选择 ZeRO Stage 0 和 ZeRO Stage 1？**

A: 
- **ZeRO Stage 0 (zero_stage=0)**: 所有 DP rank 保持完整的优化器状态。适用于：
  - 模型较小，单个 GPU 能容纳完整优化器状态
  - 追求最大训练速度（减少通信开销）
  
- **ZeRO Stage 1 (zero_stage=1)**: 优化器状态跨 DP 分片。适用于：
  - 大模型训练，内存受限
  - 可以容忍额外的 all-gather 通信
  - 通常节省约 `2/DP_SIZE` 的优化器状态内存

**Q2: FP32 梯度累积 (`accumulate_grad_in_fp32`) 的优缺点？**

A:
- **优点**: 
  - 梯度精度更高，训练更稳定
  - 避免 BF16/FP16 梯度下溢问题
  - 与 ZeRO-1 结合使用可实现更精确的梯度 sharding
  
- **缺点**:
  - 需要额外 FP32 内存存储梯度缓冲区和参数副本
  - 约增加 `4 bytes * num_params` 的内存开销
  - 略慢于纯低精度训练

**Q3: 如何处理权重衰减的参数排除？**

```yaml
# 推荐使用正则表达式排除特定参数
weight_decay_exclude_named_params:
  - ".*bias"              # 所有 bias 参数
  - ".*norm.*"           # 所有归一化层参数
  - ".*embeddings.*"     # 嵌入层参数
  - ".*lm_head.*"        # 语言模型头（可选）
```

### 6.2 学习率调度问题

**Q4: 如何设计适合长训练的调度策略？**

A: 推荐配置（例如 100K steps）：
```yaml
learning_rate: 1.0e-4       # 较低初始学习率
lr_warmup_steps: 2000       # 2% warmup
lr_decay_style: cosine      # 余弦退火更平滑
lr_decay_steps: 95000       # 95% decay
lr_decay_starting_step: 5000  # 5% 常数阶段
min_decay_lr: 1.0e-5        # 最终学习率为初始的 10%
```

**Q5: 学习率没有按预期变化？**

A: 检查点：
1. 确保 `lr_scheduler.step()` 在每个 training step 被调用
2. 验证 `total_training_steps` 计算正确
3. 检查 PyTorch 的 `LambdaLR` 是否正确配置
4. 查看日志中的学习率值确认变化

### 6.3 梯度裁剪问题

**Q6: 如何选择 `clip_grad` 值？**

A: 经验法则：
- **1.0**: 保守选择，大多数情况稳定
- **0.5**: 如果训练不稳定，梯度爆炸
- **5.0**: 如果模型收敛太慢，可以放宽限制
- 对于大模型（>7B），通常使用 1.0-2.0

### 6.4 混合精度问题

**Q7: BF16 vs FP16 的选择？**

A:
| 特性 | BF16 | FP16 |
|------|------|------|
| 动态范围 | 较大 (8位指数) | 较小 (5位指数) |
| 精度 | 较低 (7位尾数) | 较高 (10位尾数) |
| 需要 Loss Scaling | 否 | 是 |
| 硬件支持 | Ampere+ | Volta+ |
| 推荐场景 | 训练稳定性优先 | 精度要求高 |

**Q8: 如何解决梯度上溢/下溢问题？**

A: 检查清单：
- [ ] 启用 `accumulate_grad_in_fp32: true`
- [ ] 使用 BF16 代替 FP16（如果硬件支持）
- [ ] 降低初始学习率
- [ ] 增加 warmup 步数
- [ ] 检查数据质量和预处理
- [ ] 尝试梯度裁剪（如 clip_grad=1.0）
