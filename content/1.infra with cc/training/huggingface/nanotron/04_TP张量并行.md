## 2. 模块概述

### 2.1 什么是张量并行 (TP)

张量并行 (Tensor Parallelism) 是一种模型并行技术，将单个层的计算和参数切分到多个 GPU 上并行执行。在 Megatron-LM 和 Nanotron 中，主要采用**列并行 (Column Parallel)** 和**行并行 (Row Parallel)** 两种策略。

### 2.2 TP 的核心思想

```
┌─────────────────────────────────────────────────────────────┐
│                      原始 Linear Layer                       │
│              Y = X @ W^T + b  (M × N)                      │
│  X: [batch, seq_len, in_features]                          │
│  W: [out_features, in_features]                            │
│  Y: [batch, seq_len, out_features]                         │
└─────────────────────────────────────────────────────────────┘
                              ↓ 切分到 4 个 GPU
┌─────────────────┬─────────────────┬─────────────────┬──────┐
│   GPU 0         │   GPU 1         │   GPU 2         │GPU 3 │
│  W0: [N/4, M]   │  W1: [N/4, M]   │  W2: [N/4, M]   │W3    │
│  b0: [N/4]      │  b1: [N/4]      │  b2: [N/4]      │b3    │
└─────────────────┴─────────────────┴─────────────────┴──────┘
```

### 2.3 两种主要切分模式

| 模式 | 切分维度 | 输出处理 | 典型应用 |
|------|----------|----------|----------|
| **Column Parallel** | 输出维度 (dim=0) | AllGather 或 AllReduce | Q/K/V 投影, MLP 第一层 |
| **Row Parallel** | 输入维度 (dim=1) | AllReduce/ReduceScatter | MLP 第二层, Output 投影 |

### 2.4 两种 TP 通信模式

```python
# src/nanotron/parallel/tensor_parallel/enum.py
class TensorParallelLinearMode(Enum):
    ALL_REDUCE = auto()      # 标准模式，使用 AllReduce
    REDUCE_SCATTER = auto()  # 序列并行模式，使用 ReduceScatter
```

- **ALL_REDUCE**: 传统 TP 模式，所有 rank 获得完整结果
- **REDUCE_SCATTER**: 序列并行模式，结合上下文并行进一步切分序列维度

### 4.2 TP_ColumnLinear 类 (列并行线性层)

**文件**: `src/nanotron/parallel/tensor_parallel/nn.py` (46-110行)

```python
class TensorParallelColumnLinear(nn.Linear):
    """列并行线性层
    
    切分策略:
    - 输出维度 (out_features) 切分到各个 GPU
    - 每个 GPU 只存储 1/world_size 的权重
    
    通信模式:
    - ALL_REDUCE: 每个 rank 计算完整输出
    - REDUCE_SCATTER: 结合序列并行，每个 rank 输出部分结果
    """
    def __init__(
        self,
        in_features,           # 完整输入维度
        out_features,          # 完整输出维度
        pg: dist.ProcessGroup, # TP 进程组
        mode: TensorParallelLinearMode,
        bias=True,
        async_communication: bool = False,  # 是否异步通信
        tp_recompute_allgather: bool = True, # 反向时是否重计算 allgather
    ):
        self.world_size = pg.size()
        assert out_features % self.world_size == 0
        
        # 实际存储的是切分后的输出维度
        self.out_features = out_features // self.world_size
        
        super().__init__(
            in_features=in_features,
            out_features=self.out_features,  # 切分后的输出维度
            bias=bias,
        )
        
        # 标记参数为分片状态
        split_config = SplitConfig(split_dim=0)
        mark_all_parameters_in_module_as_sharded(self, pg=pg, split_config=split_config)
```

**关键特点**:
- `out_features` 被切分为 `out_features // world_size`
- 权重在 dim=0 (输出维度) 切分
- 支持 `contiguous_chunks` 用于不均匀切分 (如 GQA)

```python
class TensorParallelRowLinear(nn.Linear):
    """行并行线性层
    
    切分策略:
    - 输入维度 (in_features) 切分到各个 GPU
    - 每个 GPU 只存储 1/world_size 的权重
    
    通信模式:
    - ALL_REDUCE: 聚合各 GPU 的部分结果
    - REDUCE_SCATTER: 聚合并切分结果到各 rank
    
    特点: 只有 rank 0 有 bias，避免重复添加
    """
    def __init__(
        self,
        in_features,           # 完整输入维度
        out_features,          # 完整输出维度
        pg: dist.ProcessGroup,
        mode: TensorParallelLinearMode,
        bias=True,
        async_communication: bool = False,
    ):
        self.world_size = pg.size()
        assert in_features % self.world_size == 0
        
        # 实际存储的是切分后的输入维度
        self.in_features = in_features // self.world_size
        
        # 只有 rank 0 有 bias，避免重复累加
        bias = dist.get_rank(pg) == 0 and bias
        
        super().__init__(
            in_features=self.in_features,
            out_features=out_features,  # 保持完整输出维度
            bias=bias,
        )
        
        # 标记参数为分片状态 (dim=1 是输入维度)
        split_config = SplitConfig(split_dim=1)
        self._mark_all_parameters_in_module_as_sharded(split_config)
```

**关键特点**:
- `in_features` 被切分为 `in_features // world_size`
- 权重在 dim=1 (输入维度) 切分
- 只有 TP rank 0 存储 bias

### 4.4 TensorParallelEmbedding (词表切分)

**文件**: `src/nanotron/parallel/tensor_parallel/nn.py` (232-314行)

```python
class TensorParallelEmbedding(nn.Embedding):
    """词表并行 Embedding
    
    切分策略:
    - 词表维度 (num_embeddings) 切分到各个 GPU
    - 每个 GPU 负责 vocab_size / world_size 个词的嵌入
    
    索引处理:
    - 将全局 token ID 映射到本地 shard 索引
    - mask 掉不属于本 rank 的索引
    - 通信聚合各 rank 的嵌入结果
    """
    def __init__(self, num_embeddings, embedding_dim, pg, mode, ...):
        self.world_size = pg.size()
        assert num_embeddings % self.world_size == 0
        block_size = num_embeddings // self.world_size
        
        # 本 rank 负责的 token ID 范围
        self.rank = dist.get_rank(pg)
        self.min_id = self.rank * block_size
        self.max_id = (self.rank + 1) * block_size
        
        # 只存储 vocab/world_size 的 embedding
        super().__init__(block_size, embedding_dim, ...)
    
    def forward(self, input_ids: torch.Tensor) -> torch.Tensor:
        # mask 掉不属于本 rank 的 token
        input_mask = torch.logical_or(self.min_id > input_ids, 
                                      input_ids >= self.max_id)
        masked_input = input_ids.clone() - self.min_id
        masked_input[input_mask] = 0
        
        out = super().forward(masked_input)
        # 将非本 rank 的 token 嵌入置零
        out = out * (~input_mask[..., None])
        
        # 聚合各 rank 的结果
        if mode is TensorParallelLinearMode.ALL_REDUCE:
            out = differentiable_all_reduce_sum(out, group=pg)
        elif mode is TensorParallelLinearMode.REDUCE_SCATTER:
            out = differentiable_reduce_scatter_sum(out, group=pg)
```

### 4.5 column_linear 函数通信详解

**文件**: `src/nanotron/parallel/tensor_parallel/functional.py` (547-566行)

```python
def column_linear(
    input: torch.Tensor,
    weight: torch.Tensor,
    bias: Optional[torch.Tensor],
    group: dist.ProcessGroup,
    tp_mode: TensorParallelLinearMode,
    async_communication: bool,
    tp_recompute_allgather: bool = True,
):
    """列并行线性层前向计算
    
    两种模式:
    1. ALL_REDUCE: 保持完整 batch，不通信
    2. REDUCE_SCATTER (序列并行): 先 AllGather 输入，计算后 ReduceScatter
    """
    if async_communication:
        return _ColumnLinearAsyncCommunication.apply(
            input, weight, bias, group, tp_mode, tp_recompute_allgather
        )
    
    if tp_mode is TensorParallelLinearMode.ALL_REDUCE:
        # 标准 TP，不需要通信
        input = differentiable_identity(input, group=group)
        return F.linear(input, weight, bias)
    
    if tp_mode is TensorParallelLinearMode.REDUCE_SCATTER:
        # 序列并行: 先 AllGather 输入，计算，再 ReduceScatter 输出
        return _ColumnLinearNoAsyncCommunicationReduceScatterMode.apply(
            input, weight, bias, group, tp_recompute_allgather
        )
```

**通信原语** (`distributed_differentiable_primitives.py`):

```python
class DifferentiableAllGather(torch.autograd.Function):
    """AllGather 操作 (前向 gather, 反向 scatter)"""
    @staticmethod
    def forward(ctx, tensor, group):
        # 将 tensor 从 [B/world_size, ...] gather 到 [B, ...]
        unsharded_batch_size = tensor.shape[0] * group.size()
        unsharded_tensor = torch.empty(unsharded_batch_size, ...)
        dist.all_gather_into_tensor(unsharded_tensor, tensor, group=group)
        return unsharded_tensor
    
    @staticmethod
    def backward(ctx, grad_output):
        # 反向: ReduceScatter
        return DifferentiableReduceScatterSum.apply(grad_output, group), None

class DifferentiableReduceScatterSum(torch.autograd.Function):
    """ReduceScatter 操作 (前向 reduce+scatter, 反向 gather)"""
    @staticmethod
    def forward(ctx, tensor, group):
        # 将 tensor 从 [B, ...] reduce scatter 到 [B/world_size, ...]
        sharded_tensor = torch.empty(tensor.shape[0] // group.size(), ...)
        dist.reduce_scatter_tensor(sharded_tensor, tensor, group=group, 
                                   op=dist.ReduceOp.SUM)
        return sharded_tensor
    
    @staticmethod
    def backward(ctx, grad_output):
        # 反向: AllGather
        return DifferentiableAllGather.apply(grad_output, group), None
```

```python
class TiedLinear(nn.Linear):
    """权重绑定的线性层，用于共享输入/输出嵌入
    
    特点:
    - 所有 TP rank 保持完整权重副本
    - 通过 tied parameter 机制保持同步
    - 支持 ALL_REDUCE 和 ALL_GATHER 两种输出模式
    """
    def __init__(self, in_features, out_features, pg, mode, bias=True, ...):
        super().__init__(in_features, out_features, bias=bias, ...)
        
        # 标记为 tied parameter
        self._mark_all_parameters_in_module_as_tied()
    
    def forward(self, x: torch.Tensor) -> torch.Tensor:
        y = super().forward(x)
        if self.mode is TensorParallelLinearMode.ALL_REDUCE:
            y = differentiable_identity(y, group=self.pg)
        elif self.mode is TensorParallelLinearMode.REDUCE_SCATTER:
            y = differentiable_all_gather(y, group=self.pg)
        return y
```

## 6. 常见问题

### Q1: 为什么选择 Column + Row 组合?

**A**: 组合设计避免了多余的通信:
- `ColumnLinear` 输出分散在各 rank ->
- 可以直接作为 `RowLinear` 的切分输入 ->
- 中间的 Activation 不需要 AllGather
- 只在最后做一次 AllReduce

### Q2: tp_recompute_allgather 参数的作用?

**A**: 内存与速度的权衡:
- **True (默认)**: 前向不保存 gathered 激活，反向时重新 AllGather，节省显存
- **False**: 前向保存完整 gathered 激活，反向更快但需要更多显存

### Q3: CUDA_DEVICE_MAX_CONNECTIONS=1 为什么重要?

**A**: TP 需要此环境变量确保:
- 通信和计算按提交顺序执行
- 避免异步通信时的竞态条件
- Nanotron 在 TP>1 时会强制检查此设置

```python
if self.world_size > 1:
    assert os.environ.get("CUDA_DEVICE_MAX_CONNECTIONS") == "1"
```

### Q4: 如何将 TP 与 ZeRO-1 结合使用?

**A**: TP 和 ZeRO-1 是正交的:
- TP 在节点内拆分层 (高速 NVLink 通信)
- ZeRO-1 在数据并行组间拆分优化器状态
- 每个 TP 组内部参数均匀分布，减少 DP 通信量

### Q5: 词表大小不能被 TP 整除怎么办?

**A**: Current limitation:
```python
assert num_embeddings % self.world_size == 0
```
- 需要 padding 词表到 TP 的整数倍
- 或使用 Gloo backend 的 AllGather (不推荐用于训练)

### Q6: TensorParallelLinearMode 如何选择?

**A**:
| 场景 | 推荐模式 |
|------|----------|
| 标准 LLM 训练 (序列长度 <= 8K) | ALL_REDUCE |
| 长序列训练 (> 8K, 如 32K/128K) | REDUCE_SCATTER + Context Parallel |
| 推理阶段 | ALL_REDUCE (简化逻辑) |
