## 模块概述

本章节汇总 Accelerate 在实际使用中的配置方法、启动命令和常见问题的解决方案。从单机单卡到多机多卡，从 DDP 到 DeepSpeed，覆盖训练和推理的典型场景。

### 关键设计决策【重点】

| 设计决策 | 说明 | 技术实现 |
|---------|------|---------|
| **配置文件驱动** | 交互式配置生成 yaml 配置文件 | `accelerate config` |
| **命令行覆盖** | 命令行参数可覆盖配置文件 | 参数合并逻辑 |
| **环境变量注入** | 通过 expect/torchelastic 启动 | `launch.py` |
| **配置可复用** | yaml 配置文件可多处使用 | `--config_file` 参数 |
| **自动设备检测** | 自动找出可用 GPU/TPU | 枚举 + 健康检查 |

## 核心代码片段

### 表意伪代码：配置解析逻辑

```python
# ============================================================
# accelerate launch 配置解析流程
# ============================================================

def launch_command(args):
    """
    accelerate launch 命令入口
    """
    # 1. 加载配置文件
    config = load_config_from_file(
        args.config_file or DEFAULT_CONFIG_PATH
    )

    # 2. 合并命令行参数（高优先级覆盖）
    config.update_from_args(args)
    # 如：args.num_processes 覆盖 config.num_processes

    # 3. 检测环境并验证配置
    config = auto_detect_environment(config)

    # 4. 构建启动参数
    launch_args = build_launch_args(config)

    # 5. 执行启动
    launch_processes(config, launch_args)


def auto_detect_environment(config):
    """
    自动检测环境并补全配置
    """
    # 检测 GPU
    if torch.cuda.is_available():
        num_gpus = torch.cuda.device_count()

        if config.num_processes is None:
            config.num_processes = num_gpus

        if config.gpu_ids is None:
            config.gpu_ids = list(range(num_gpus))

    # 检测 TPU
    if is_tpu_available():
        config.distributed_type = DistributedType.TPU
        config.num_processes = 8  # TPU v3/v4 通常 8 核心

    # 检测配置文件中的分布式类型
    if config.deepspeed_config:
        config.distributed_type = DistributedType.DEEPSPEED

    return config


def launch_processes(config, launch_args):
    """
    根据配置选择启动方式
    """
    if config.distributed_type == DistributedType.NO:
        # 单进程：直接执行 Python
        subprocess.run([sys.executable, "train.py"] + args)

    elif config.distributed_type == DistributedType.MULTI_GPU:
        # 多 GPU：使用 torchrun
        subprocess.run([
            "torchrun",
            "--nnodes", str(config.num_machines),
            "--nproc_per_node", str(config.num_processes),
            "--master_addr", config.master_address,
            "--master_port", str(config.master_port),
            "train.py"
        ] + args)

    elif config.distributed_type == DistributedType.DEEPSPEED:
        # DeepSpeed：调用 deepspeed 命令
        subprocess.run([
            "deepspeed",
            "--num_gpus", str(config.num_processes),
            "--master_port", str(config.master_port),
            "train.py",
            "--deepspeed", config.deepspeed_config
        ] + args)
```

```python
    print(f"配置已保存: {filepath}")
    return filepath
```

## 常见问题排查

### Q1: NCCL 连接超时/失败

```bash
# 症状：torch.distributed.DistBackendError

# 解决1：检查 NCCL 环境
export NCCL_DEBUG=INFO
export NCCL_SOCKET_IFNAME=eth0     # 指定网络接口
export NCCL_IB_DISABLE=1           # 禁用 IB（如无 InfiniBand）

# 解决2：RTX 40 系列问题
export NCCL_P2P_DISABLE=1
export NCCL_IB_DISABLE=1

# 解决3：防火墙
# 确保 MASTER_PORT（默认29500）和后续端口开放
sudo ufw allow 29500:29600/tcp

# 解决4：静态路由
# 多机时确保各节点能互相通信
ping <other_node_ip>
nc -zv <other_node_ip> 29500
```

### Q2: 显存不足 (OOM)

```bash
# 症状：RuntimeError: CUDA out of memory

# 解决1：减小 batch size
# 代码中调整 DataLoader 的 batch_size

# 解决2：使用梯度累积
accelerate launch --gradient_accumulation_steps 4 train.py

# 解决3：启用 DeepSpeed ZeRO-2/3
accelerate launch --use_deepspeed train.py

# 解决4：使用 FSDP
torchrun --standalone --nproc_per_node=4 train.py

# 解决5：BF16 替代 FP16（显存开销更小）
accelerate launch --mixed_precision bf16 train.py

# 解决6：自动 batch size 搜索
from accelerate.utils import find_executable_batch_size

@find_executable_batch_size(starting_batch_size=128)
def training_loop(batch_size):
    # 你的训练代码
```


### Q5: DeepSpeed/FSDP 特定问题

```python
# DeepSpeed: 检查 zero_stage 配置
{
    "zero_optimization": {
        "stage": 3,
        "offload_optimizer": {
            "device": "cpu",  # 或 "none"
            "pin_memory": true
        }
    }
}

# FSDP: 检查包装策略
# 确保 transformer_layer_cls_to_wrap 包含正确的类名
# 可通过以下代码获取类名：
for name, module in model.named_modules():
    print(name, type(module).__name__)

# DeepSpeed 保存问题
# 确保使用 accelerator.save_state() 而非 torch.save()
accelerator.wait_for_everyone()
unwrapped_model = accelerator.unwrap_model(model)
unwrapped_model.save_pretrained(
    save_dir,
    is_main_process=accelerator.is_main_process,
    save_function=accelerator.save,
    state_dict=accelerator.get_state_dict(model)
)
```
