### 2.2 推荐使用方式

```python
from peft import LoraConfig

# 方案 1: 使用 PEFT 预定义映射（推荐）
lora_config = LoraConfig(
    r=16,
    lora_alpha=32,
    # 不指定 target_modules，自动根据模型类型推断
)

# 方案 2: 手动指定全部目标层
lora_config = LoraConfig(
    r=16,
    target_modules=[
        "q_proj", "k_proj", "v_proj", "o_proj",  # Attention
        "gate_proj", "up_proj", "down_proj"       # MLP
    ],
)

# 方案 3: 使用 all-linear 自动选择所有线性层
lora_config = LoraConfig(
    r=16,
    target_modules="all-linear",
)
```

## 3. IA3 目标模块映射

### 3.1 映射表

```python
TRANSFORMERS_MODELS_TO_IA3_TARGET_MODULES_MAPPING = {
    "llama": ["k_proj", "v_proj", "down_proj"],
    "qwen2": ["k_proj", "v_proj", "down_proj"],
    "mistral": ["k_proj", "v_proj", "down_proj"],
    "t5": ["k", "v", "wo"],
    "mt5": ["k", "v", "wi_1"],
    "gpt2": ["c_attn", "mlp.c_proj"],
    "bloom": ["query_key_value", "dense_h_to_4h"],
}
```

### 3.2 选择依据

IA3 推荐目标层（与 LoRA 不同）：
- **k_proj**: Keys，缩放注意力 key
- **v_proj**: Values，缩放注意力 value
- **down_proj**: Feed-forward 输出，缩放 FFN

## 4. 模型架构与目标层对照

### 4.1 Decoder-only 模型

| 模型 | Attention 层 | MLP 层 |
|------|-------------|--------|
| **Llama/Qwen/Mistral** | q_proj, k_proj, v_proj, o_proj | gate_proj, up_proj, down_proj |
| **GPT-2** | c_attn | c_fc, c_proj |
| **BLOOM** | query_key_value | dense_h_to_4h, dense_4h_to_h |
| **Falcon** | query_key_value | dense_h_to_4h, dense_4h_to_h |

### 4.2 Encoder-decoder 模型

| 模型 | Encoder Attention | Decoder Attention | FFN |
|------|-------------------|-------------------|-----|
| **T5/mT5** | q, k, v | q, k, v | wi_0/1, wo |
| **BART** | q_proj, k_proj, v_proj | q_proj, k_proj, v_proj | fc1, fc2 |

### 4.3 Encoder-only 模型

| 模型 | Self-Attention | FFN |
|------|-----------------|-----|
| **BERT/RoBERTa** | query, key, value | intermediate, output |
| **DeBERTa** | query, key, value | intermediate, output |

## 5. all-linear 快捷方式

### 5.1 使用方式

```python
from peft import LoraConfig

# 自动适配所有 Linear 层
lora_config = LoraConfig(
    r=16,
    lora_alpha=32,
    target_modules="all-linear",
)
```

### 5.2 原理

```python
INCLUDE_LINEAR_LAYERS_SHORTHAND = "all-linear"

# 在 tuner 中自动查找所有 nn.Linear 层
for name, module in model.named_modules():
    if isinstance(module, nn.Linear):
        target_modules.append(name)
```

## 7. 层范围选择

### 7.1 layers_to_transform

```python
# 只对特定层索引应用 LoRA
lora_config = LoraConfig(
    r=16,
    target_modules=["q_proj", "v_proj"],
    layers_to_transform=[0, 1, 30, 31],  # 只对第 0,1,30,31 层
)

# 或者使用切片
lora_config = LoraConfig(
    r=16,
    target_modules=["q_proj", "v_proj"],
    layers_pattern="layers",             # 层命名模式
    layers_to_transform=range(16, 32),   # 只对后 16 层
)
```

### 7.2 rank_pattern

```python
# 按层名指定不同的 rank
lora_config = LoraConfig(
    r=8,  # 默认 rank
    rank_pattern={
        "model.layers.0": 64,    # 第一层用高 rank
        "model.layers.1": 64,
    }
)
```

## 8. 参数数量估算

### 8.1 LoRA 参数量公式

```
参数 = 2 * r * (in_features + out_features)

示例：Llama q_proj (4096 x 4096), r=16
参数 = 2 * 16 * (4096 + 4096) = 262,144
```

### 8.2 全模型估算

```python
def estimate_lora_params(model_config, r, target_modules):
    """估算 LoRA 参数量"""
    total = 0
    for layer in range(model_config.num_hidden_layers):
        for proj in target_modules:
            # 假设 hidden_size x hidden_size
            total += 2 * r * model_config.hidden_size * 2
    return total

# Llama-2-7B, r=16, target=[q_proj, v_proj]
# 约 4.2M 可训练参数 (总参数约 0.06%)
```
