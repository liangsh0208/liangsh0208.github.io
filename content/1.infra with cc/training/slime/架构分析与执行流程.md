# Slime 框架架构分析与执行流程

## 概述

**Slime** 是一个先进的 LLM（大语言模型）后训练强化学习框架，专为 RL 规模化扩展而设计。该框架是 GLM-5、GLM-4.7、GLM-4.6、GLM-4.5 等模型的基础 RL 框架，同时支持 Qwen3 系列、DeepSeek V3 系列和 Llama 3 等模型。

---

## 一、核心架构

框架采用分布式模块化设计，包含三个主要组件：

| 组件 | 作用 | 技术实现 |
|------|------|----------|
| **Training Module** | 主训练进程，从 Data Buffer 读取数据，训练后同步参数到 Rollout | Megatron-LM / FSDP |
| **Rollout Module** | 生成训练数据（含 rewards/verifier 输出），存储到 Data Buffer | SGLang + Router |
| **Data Buffer** | 桥接模块，管理 prompt 初始化、自定义数据格式和 rollout 生成方法 | Ray Actor |

## 六、PPO/GRPO 训练算法流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    优势估计 & 策略优化                                        │
└─────────────────────────────────────────────────────────────────────────────┘

                    ┌─────────────────────────────────┐
                    │         获取 rollout 数据        │
                    │   (tokens, rewards, log_probs)  │
                    └─────────────────┬───────────────┘
                                      │
          ┌───────────────────────────┼───────────────────────────┐
          │                           │                           │
          ▼                           ▼                           ▼
┌─────────────────┐       ┌─────────────────┐       ┌─────────────────┐
│ GRPO 模式       │       │ PPO 模式         │       │ REINFORCE 模式  │
│                 │       │                  │       │                 │
│ group相对奖励   │       │ 需要 Critic      │       │ 基线减除        │
│ A = (r-μ)/σ     │       │ GAE 优势估计     │       │ A = R - b       │
└─────────────────┘       └─────────────────┘       └─────────────────┘
          │                           │                           │
          └───────────────────────────┼───────────────────────────┘
                                      │
                                      ▼
                    ┌─────────────────────────────────┐
                    │         计算策略损失             │
                    │                                  │
                    │  L = -A * min(ratio, clip(ratio))│

                    └─────────────────┬───────────────┘

                    ┌─────────────────────────────────┐
                    │          反向传播 & 更新         │

                    │  • 优化器步进                    │
                    └─────────────────────────────────┘
```

## 九、架构亮点

### 9.1 解耦训练与数据生成

训练（Megatron）和数据生成（SGLang）独立扩展，SGLang 引擎可在不中断训练的情况下更新。

### 9.2 高级内存管理

SGLang 引擎在训练周期中动态加载/卸载以优化 GPU 内存：

```
训练时: SGLang offload → 释放 GPU 内存
推理时: SGLang onload → 恢复 GPU 内存
```

### 9.3 MoE 优化

Qwen3-Next-80B-A3B 配置：
- 每层 512 专家
- Top-10 路由
- 80B 参数量，高效计算

### 9.4 专用注意力机制

- GQA（分组查询注意力）
- QK 层归一化
- 稀疏 MLA（Multi-Linear Attention）模块
