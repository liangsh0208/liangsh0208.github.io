## 1. 模块概述

`parallel_state.py` 是Megatron-LM的并行基础设施核心，负责：
- 管理15+种进程组 (TP、PP、DP、EP、CP及其组合)
- 提供正交并行组生成算法
- 维护全局rank映射与访问接口

### 【重点】进程组全景

| 进程组变量 | 用途 | 规模 |
|------------|------|------|
| `_TENSOR_MODEL_PARALLEL_GROUP` | TP层内通信 | tp_size |
| `_PIPELINE_MODEL_PARALLEL_GROUP` | PP层间通信 | pp_size |
| `_DATA_PARALLEL_GROUP` | DP梯度同步 | dp_size |
| `_EXPERT_MODEL_PARALLEL_GROUP` | MoE专家分发 | ep_size |
| `_CONTEXT_PARALLEL_GROUP` | 长序列切分 | cp_size |
| `_TENSOR_AND_DATA_PARALLEL_GROUP` | TP+DP,算子融合 | tp_size×dp_size |
| `_TENSOR_AND_CONTEXT_PARALLEL_GROUP` | TP+CP,SP优化 | tp_size×cp_size |
| `_EMBEDDING_GROUP` | 词表Embedding同步 | 特殊构造 |

## 3. 核心概念与实现

### 3.1 正交并行组生成算法

```python
# 文件: megatron/core/parallel_state.py:250

def generate_masked_orthogonal_rank_groups(
    world_size: int,
    parallel_size: List[int],  # e.g., [tp=2, cp=1, ep=1, dp=4, pp=2]
    mask: List[bool]           # e.g., mask=[True, False, False, False, False] → TP组
) -> List[List[int]]:
    """
    生成正交并行组的核心算法。
    
    数学原理:
    对于正交并行维度(tp, cp, ep, dp, pp)，global_rank满足:
        global_rank = tp_rank + cp_rank×tp_size + ep_rank×(tp_size×cp_size)
                     + dp_rank×(tp_size×cp_size×ep_size) 
                     + pp_rank×(tp_size×cp_size×ep_size×dp_size)
    
    通过mask选择保留哪些维度，组合成特定进程组。
    
    示例: world_size=16, parallel_size=[2,1,1,4,2]
    
    1. 生成DP组 (mask=[False, False, False, True, False]):
       保留第4维度(dp)，其他维度组合成组索引
       DP Group 0: [ranks where dp_rank=0] = [0,1,4,5,8,9,12,13]
       DP Group 1: [ranks where dp_rank=1] = [2,3,6,7,10,11,14,15]
       
    2. 生成TP组 (mask=[True, False, False, False, False]):
       TP Group 0: [0,2], TP Group 1: [1,3], ...
       
    3. 生成TP+DP组合组 (mask=[True, False, False, True, False]):
       组合维度大小 = 2×4 = 8，共有16/8=2组
    """
```

### 3.2 进程组初始化流程

```python
# 文件: megatron/core/parallel_state.py:549

def initialize_model_parallel(
    tensor_model_parallel_size: int = 1,
    pipeline_model_parallel_size: int = 1,
    virtual_pipeline_model_parallel_size: Optional[int] = None,
    context_parallel_size: int = 1,
    expert_model_parallel_size: int = 1,
    order: str = "tp-cp-ep-dp-pp",
    nccl_comm_cfgs: Optional[dict] = None,
) -> None:
    """
    初始化所有模型并行进程组的完整流程。
    
    Steps:
    1. 验证配置: product(all_parallel_sizes) == world_size
    2. 解析order字符串，确定rank排序规则
    3. 计算并行维度数组: sizes = [tp, cp, ep, dp, pp]
    4. 为每个并行维度创建正交组:
       - 对各维度调用 generate_masked_orthogonal_rank_groups
       - 调用 torch.distributed.new_group 创建ProcessGroup
       - 保存到全局变量 _XXX_GROUP
    5. 创建组合组 (TP+DP, TP+CP等) 用于算子融合
    6. 创建特殊组 (Embedding组用于词表同步)
    7. 初始化NCCL配置 (高优先级流等)
    """
    world_size = torch.distributed.get_world_size()
    
    # 计算dx_size
    other_product = (
        tensor_model_parallel_size 
        * context_parallel_size 
        * expert_model_parallel_size 
        * pipeline_model_parallel_size
    )
    assert world_size % other_product == 0
    data_parallel_size = world_size // other_product
    
    # 按order解析并创建各维度组
    parallel_size, order = map_order_to_parallel_size(
        tensor_model_parallel_size,
        pipeline_model_parallel_size,
        context_parallel_size,
        expert_model_parallel_size,
        data_parallel_size,
        order
    )
    
    # 为每个维度创建组
    rank = torch.distributed.get_rank()
    for order_name, order_size in zip(order, parallel_size):
        # 构造mask: 当前维度为True
        mask = [name == order_name for name in order]
        all_ranks_for_dim = generate_masked_orthogonal_rank_groups(
            world_size, parallel_size, mask
        )
        
        for ranks in all_ranks_for_dim:
            # 创建进程组
            pg_options = get_nccl_options(order_name, nccl_comm_cfgs)
            group = create_group(
                ranks=ranks,
                timeout=None,
                backend='nccl',
                pg_options=pg_options,
                group_desc=order_name,
            )
            
            # 保存到对应全局变量
            if rank in ranks:
                if order_name == 'tp':
                    _TENSOR_MODEL_PARALLEL_GROUP = group
                elif order_name == 'pp':
                    _PIPELINE_MODEL_PARALLEL_GROUP = group
                # ... etc
```

### 3.3 与nanotron对比

| 对比项 | Megatron-LM | nanotron |
|--------|-------------|----------|
| **并行状态存储** | 全局变量 (15+ `_XXX_GROUP`) | 显式对象 `ParallelContext` |
| **访问方式** | 全局函数 `get_xxx_parallel_group()` | 方法调用 `parallel_context.tp_pg` |
| **生成算法** | 正交组算法，多维度组合 | 简化实现，主要支持3D并行 |
| **组合组支持** | 丰富: TP+DP, TP+CP, EP+DP等 | 有限 |
| **模式灵活性** | 支持自定义order (tp-cp-ep-dp-pp可重排) | 固定顺序 |
| **测试友好性** | 需全局初始化，测试需mock | 可传递对象，更易单元测试 |
| **代码耦合度** | 较高，各处直接调用全局函数 | 较低，依赖注入风格 |

### 5.1 初始化失败

**Q: `RuntimeError: Default process group has not been initialized`**

```python
# 原因: 调用并行状态函数前未初始化分布式
# 解决流程
def setup_distributed():
    # 1. 必须首先初始化torch分布式
    torch.distributed.init_process_group(backend='nccl')
    
    # 2. 设置当前设备
    local_rank = int(os.environ['LOCAL_RANK'])
    torch.cuda.set_device(local_rank)
    
    # 3. 初始化Megatron并行组
    from megatron.core import parallel_state
    parallel_state.initialize_model_parallel(
        tensor_model_parallel_size=8,
        pipeline_model_parallel_size=4,
        # ...
    )
```

**Q: `AssertionError: WORLD_SIZE not divisible by model parallel size`**

```python
# 诊断: 并行配置不满足整除关系
world_size = 16
tensor_model_parallel_size = 3  # 错误，16不能被3整除

# 验证脚本
def validate_parallel_config(world_size, tp, pp, cp, ep):
    product = tp * pp * cp * ep
    dp = world_size // product
    if dp * product != world_size:
        raise ValueError(f"配置无效: tp={tp} × pp={pp} × cp={cp} × ep={ep} × dp={dp} = {product*dp} ≠ {world_size}")
    return True
```
