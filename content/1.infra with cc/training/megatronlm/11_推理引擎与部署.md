## 1. 模块概述

Megatron-LM提供框架内原生推理能力，与训练代码深度整合。

### 【重点】推理架构特性

| 特性 | 实现 | 状态 |
|------|------|------|
| **推理-训练统一** | 同一模型代码，推理模式切换 | 完整支持 |
| **Dynamic Batching** | engines/dynamic_batching.py | 支持 |
| **KV Cache优化** | 分层缓存管理 | 支持 |
| **PagedAttention** | 参考vLLM设计 | 部分支持 |
| **TensorRT-LLM导出** | TRT-LLM集成 | 工具级支持 |
| **量化部署** | FP8/INT8/INT4 | 实验性 |

## 3. 核心概念与实现

### 3.1 Dynamic Batching

```python
# 文件: megatron/core/inference/engines/dynamic_batching.py

class DynamicBatchingEngine:
    """动态批处理推理引擎。
    
    特性:
    - 请求可动态加入当前batch
    - 完成的请求立即返回，释放资源
    - 新请求可填充到未满的batch中
    """
    
    def __init__(self, inference_wrapped_model, ...):
        self.inference_wrapped_model = inference_wrapped_model
        self.kv_cache_manager = KVCacheManager(...)
        
    def generate(self, prompts: List[str], ...):
        """生成文本。"""
        # 1. Tokenize所有prompt
        input_ids = self.tokenizer.encode(prompts)
        
        # 2. 批处理对齐 (padding到相同长度或左对齐)
        batch_input = self._prepare_batch(input_ids)
        
        # 3. 迭代生成，直到所有序列都产生EOS或达到max_len
        active_requests = list(range(len(prompts)))
        
        while active_requests:
            # 前向推理 (增量解码)
            logits = self.inference_wrapped_model(batch_input, use_cache=True)
            
            # 采样next token
            next_tokens = self.sampler.sample(logits)
            
            # 识别完成的请求
            finished = [i for i, tok in enumerate(next_tokens) if tok == EOS]
            for i in finished:
                active_requests.remove(i)
            
            # 更新input_ids准备下一步
            batch_input = next_tokens
            
        return generated_sequences
```

### 3.3 与训练统一

```python
# 推理与训练使用相同模型定义
model = GPTModel(config, ...)  # 同一构造函数

# 差异在使用方式
# 训练: 调用forward直接返回loss
# 推理: 增量解码，管理KV cache，采样策略

# 推理模式切换
model.eval()

# PP场景下的推理协调
def run_inference_distributed(prompt_tokens):
    if is_pipeline_first_stage():
        # 发送输入到后续stage
        send_forward(prompt_tokens)
        # 从最后stage接收结果
        output = recv_forward()
    elif is_pipeline_last_stage():
        input_ = recv_forward()
        output = model.generate(input_, ...)
        send_forward(output)
    else:
        # middle stage: 收发并计算
        input_ = recv_forward()
        output = model(input_, ...)
        send_forward(output)
```
