## 1. 模块概述

`training.py`是Megatron-LM最核心的文件(166814字节)，实现完整的训练引擎。

### 【重点】训练循环层次

| 函数 | 职责 | 位置/规模 |
|------|------|----------|
| `pretrain()` | 入口脚本的主函数 | pretrain_gpt.py |
| `train()` | 外层epoch管理 | training.py ~5000行 |
| `train_step()` | 单步训练逻辑 | training.py |
| `forward_backward_func` | PP调度执行 | pipeline_parallel/schedules.py |

### 3.1 训练循环初始化

```python
# 文件: megatron/training/training.py
def train(forward_step_func, model, optimizer, opt_param_scheduler, ...):
    """主训练循环。"""
    
    # 1. 设置训练模式
    for model_chunk in model:
        model_chunk.train()
    
    # 2. 配置通信重叠
    if args.overlap_grad_reduce:
        # 启用梯度All-Reduce与计算重叠
        config.no_sync_func = [m.no_sync for m in model]
        config.grad_sync_func = [m.start_grad_sync for m in model]
    
    if args.overlap_param_gather:
        # 启用参数收集与优化器step重叠
        config.param_sync_func = [m.start_param_sync for m in model]
    
    # 3. 获取PP调度函数
    forward_backward_func = get_forward_backward_func(
        args.pipeline_model_parallel_size,
        args.virtual_pipeline_model_parallel_size,
    )

    while iteration < args.train_iters and ...:
```

### 3.2 train_step实现

```python
def train_step(forward_step_func, data_iterator, model, ...):
    """执行单步训练。"""
    
    # 1. 梯度清零
    for model_chunk in model:
        model_chunk.zero_grad_buffer()
    optimizer.zero_grad()
    
    # 2. 前向后向传播 (关键: PP调度在此)
    losses_reduced = forward_backward_func(
        forward_step_func=forward_step_func,  # 用户提供
        data_iterator=data_iterator,
        model=model,
        num_microbatches=get_num_microbatches(),
        seq_length=args.seq_length,
        micro_batch_size=args.micro_batch_size,
        decoder_seq_length=args.decoder_seq_length,
        forward_only=False,  # 非推理
    )
    
    # 3. 优化器步骤
    update_successful, grad_norm, num_zeros_in_grad = optimizer.step()
    
    # 4. 跨model parallel同步 (处理FP16溢出一致性)
    update_successful = logical_and_across_model_parallel_group(update_successful)
    
    # 5. LR调度
    if update_successful:
        increment = get_num_microbatches() * args.micro_batch_size * args.data_parallel_size
        opt_param_scheduler.step(increment=increment)
        skipped_iter = 0
    else:
        skipped_iter = 1
    
    # 6. Loss聚合处理
    return loss_reduced, skipped_iter, grad_norm
```

### 3.3 forward_step_func用户接口

```python
# 示例: pretrain_gpt.py 的标准实现

def forward_step(data_iterator, model):
    """用户定义的前向步骤函数。
    
    这是训练框架与具体模型任务的桥梁。
    接收: data_iterator 和 model (当前PP stage的模型)
    返回: (output_tensor, loss_func) 元组
    
    在PP模式下，只有最后stage的forward_step会返回非None的loss_func。
    """
    # 获取batch数据
    tokens, labels, loss_mask, attention_mask, position_ids = get_batch(data_iterator)
    
    # 前向传播
    output_tensor = model(
        tokens,
        position_ids,
        attention_mask,
        labels=labels,
    )
    
    # 定义loss计算 (只在PP last stage执行)
    def loss_func(output_tensor):
        # 计算cross-entropy loss
        losses = output_tensor.float()
        loss_mask = loss_mask.view(-1).float()
        loss = torch.sum(losses.view(-1) * loss_mask) / loss_mask.sum()
        
        # 返回用于聚合的格式 [loss_sum, num_tokens]
        return loss, {'lm loss': averaged_loss}
    
    return output_tensor, loss_func
```

### 3.4 与nanotron对比

| 对比项 | Megatron-LM | nanotron |
|--------|-------------|----------|
| **主循环文件** | training.py (166KB) | trainer.py (~3000行) |
| **循环复杂度** | 高度可配置，支持多种并行组合 | 简洁固定模式 |
| **用户接口** | forward_step_func回调 | 直接model forward |
| **PP调度** | 多种策略 (1F1B/Interleaved/Combined) | 简单1F1B |
| **step粒度控制** | fine-grained (gradient bucket级别) | coarse-grained |
| **扩展性** | 高度模块化，支持自定义钩子 | 有限 |
| **VLM/多模态** | 原生支持 (pretrain_vlm.py) | 需自行扩展 |
| **混合精度** | FP16/BF16/FP8多层次控制 | 基础BF16/FP32 |
