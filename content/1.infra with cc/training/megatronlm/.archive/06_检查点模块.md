# Megatron-LM 检查点模块详解

> 训练流程第六环：模型保存与加载

---

## 1. 模块概述

检查点模块负责：
- 模型权重保存与加载
- 优化器状态持久化
- 训练状态恢复
- 分布式检查点处理
- 异步保存优化

```
┌─────────────────────┐
│  模型状态            │
│  - 参数权重          │
│  - 模型配置          │
└─────────────────────┘
        │
        ▼
┌─────────────────────┐
│  优化器状态          │
│  - Adam moments     │
│  - 学习率           │
└─────────────────────┘
        │
        ▼
┌─────────────────────┐
│  训练状态            │
│  - 迭代次数          │
│  - RNG 状态         │
│  - 数据加载器状态    │
└─────────────────────┘
        │
        ▼
┌─────────────────────┐
│  分布式检查点        │
│  - ShardedTensor    │
│  - 分片策略          │
└─────────────────────┘
        │
        ▼
┌─────────────────────┐
│  存储                │
│  - 本地文件系统      │
│  - 分布式存储        │
└─────────────────────┘
```

## 2. 检查点类型

### 2.1 传统检查点 vs 分布式检查点

| 特性 | 传统检查点 | 分布式检查点 |
|------|-----------|-------------|
| 存储方式 | 每个 rank 保存完整模型 | 各 rank 只保存分片 |
| 内存占用 | 高（完整模型副本） | 低（本地分片） |
| 加载灵活性 | 需相同并行配置 | 可跨配置加载 |
| 适用场景 | 小规模训练 | 大规模分布式训练 |

## 3. ShardedTensor 核心类

**文件位置**: `megatron/core/dist_checkpointing/mapping.py`

### 3.1 ShardedTensor 数据类

```python
@dataclass
class ShardedTensor(ShardedBase):
    """分布式张量表示

    表示本地张量与全局张量之间的映射关系

    属性:
        key: 全局张量的唯一标识符
        data: 本地张量数据
        dtype: 张量数据类型
        local_shape: 本地张量形状
        global_shape: 全局张量形状
        global_offset: 本地张量在全局张量中的偏移
        axis_fragmentations: 每个维度的分片数量
        replica_id: 副本标识（用于区分重复分片）
        prepend_axis_num: 前置维度数量
        allow_shape_mismatch: 是否允许形状不匹配
    """

    key: str
    data: Optional[torch.Tensor] = field(repr=False)
    dtype: torch.dtype
    local_shape: Tuple[int, ...]
    global_shape: Tuple[int, ...]
    global_offset: Tuple[int, ...]
    axis_fragmentations: Optional[Tuple[int, ...]]
    replica_id: ReplicaId = 0
    prepend_axis_num: int = 0
    allow_shape_mismatch: bool = False
    flattened_range: Optional[slice] = None
```

### 3.2 创建 ShardedTensor

```python
@classmethod
def from_rank_offsets(
    cls,
    key: str,
    data: torch.Tensor,
    *rank_offsets: Tuple[int, int, int],
    replica_id: ReplicaId = 0,
    prepend_axis_num: int = 0,
    **init_kwargs,
):
    """从 rank 偏移创建 ShardedTensor

    Args:
        key: 唯一键
        data: 本地张量数据
        rank_offsets: 每个元组 (axis, axis_rank_offset, axis_fragm) 表示
            - axis: 维度索引
            - axis_rank_offset: 该维度上的 rank 偏移
            - axis_fragm: 该维度的分片总数

    Example:
        # TP=2, 每个rank有一半的权重
        # rank 0: [hidden_size/2, hidden_size]
        # rank 1: [hidden_size/2, hidden_size]

        # 在 rank 0:
        sharded_tensor = ShardedTensor.from_rank_offsets(
            key='weight',
            data=local_weight,  # shape: [hidden_size/2, hidden_size]
            (0, 0, 2),  # 第0维分2片，本rank是第0片
        )

        # 在 rank 1:
        sharded_tensor = ShardedTensor.from_rank_offsets(
            key='weight',
            data=local_weight,
            (0, 1, 2),  # 第0维分2片，本rank是第1片
        )
    """
    global_offset = [0] * (data.ndim + prepend_axis_num)
    global_shape = ([1] * prepend_axis_num) + list(data.shape)
    axis_fragmentations = [1] * (data.ndim + prepend_axis_num)

    for axis, axis_rank_offset, axis_fragm in rank_offsets:
        local_axis_shape = 1 if axis < prepend_axis_num else data.shape[axis - prepend_axis_num]
        global_shape[axis] = axis_fragm * local_axis_shape
        global_offset[axis] = axis_rank_offset * local_axis_shape
        axis_fragmentations[axis] = axis_fragm

    return cls(
        key, data, data.dtype,
        tuple(data.shape),
        tuple(global_shape),
        tuple(global_offset),
        tuple(axis_fragmentations),
        replica_id, prepend_axis_num,
        **init_kwargs,
    )
```

### 4.1 保存入口函数

```python
def save_checkpoint(
    iteration: int,
    model: Union[torch.nn.Module, List[torch.nn.Module]],
    optimizer: Optional[torch.optim.Optimizer],
    opt_param_scheduler: Optional[OptimizerParamScheduler],
    num_floating_point_operations_so_far: Optional[int] = None,
    checkpointing_context: Optional[Dict] = None,
    pipeline_parallel_next_rank: Optional[int] = None,
) -> None:
    """保存检查点

    Args:
        iteration: 当前迭代次数
        model: 模型（或模型列表，用于 PP）
        optimizer: 优化器
        opt_param_scheduler: 学习率调度器
        num_floating_point_operations_so_far: 已完成的浮点运算数
        checkpointing_context: 检查点上下文（用于异步保存）
        pipeline_parallel_next_rank: PP 下一个 rank
    """
    # 获取参数
    args = get_args()

    # 只在 rank 0 创建目录
    if torch.distributed.get_rank() == 0:
        os.makedirs(args.save, exist_ok=True)

    # 确定保存路径
    checkpoint_name = get_checkpoint_name(args.save, iteration)

    # 构建状态字典
    state_dict = {
        'iteration': iteration,
        'model': get_model_state_dict(model),
        'optimizer': get_optimizer_state_dict(optimizer) if optimizer else None,
        'opt_param_scheduler': opt_param_scheduler.state_dict() if opt_param_scheduler else None,
        'rng_state': get_rng_state(),
        'args': vars(args),
    }

    # 使用分布式检查点
    if args.use_dist_ckpt:
        save_dist_checkpoint(state_dict, checkpoint_name)
    else:
        save traditional_checkpoint(state_dict, checkpoint_name)
```

### 4.2 分布式检查点保存

```python
def save_dist_checkpoint(
    state_dict: Dict,
    checkpoint_dir: str,
    sharded_strategy: Optional[SaveShardedStrategy] = None,
    common_strategy: Optional[SaveCommonStrategy] = None,
    async_save: bool = False,
) -> None:
    """保存分布式检查点

    流程:
    1. 将模型状态转换为 ShardedStateDict
    2. 应用保存策略
    3. 并行保存分片
    """
    # 保存配置文件
    save_config(state_dict, checkpoint_dir)

    # 预处理：提取分片张量
    sharded_state_dict, common_state_dict = save_preprocess(state_dict)

    # 应用保存策略
    if sharded_strategy is None:
        sharded_strategy = get_default_save_sharded_strategy()

    # 并行保存
    sharded_strategy.save(sharded_state_dict, checkpoint_dir)
    common_strategy.save(common_state_dict, checkpoint_dir)
```

### 4.3 模型状态字典转换

```python
def get_model_state_dict(model: Union[torch.nn.Module, List[torch.nn.Module]]) -> ShardedStateDict:
    """获取模型的分片状态字典

    将模型的参数转换为 ShardedTensor
    """
    if isinstance(model, list):
        # Pipeline Parallel: 每个模型是 PP 的一个 stage
        state_dict = {}
        for pp_rank, pp_model in enumerate(model):
            pp_state_dict = _get_single_model_sharded_state_dict(pp_model, pp_rank)
            state_dict.update(pp_state_dict)
        return state_dict
    else:
        return _get_single_model_sharded_state_dict(model, 0)


def _get_single_model_sharded_state_dict(
    model: torch.nn.Module,
    pp_rank: int
) -> ShardedStateDict:
    """转换单个模型的状态字典"""
    state_dict = {}
    tp_rank = get_tensor_model_parallel_rank()
    tp_size = get_tensor_model_parallel_world_size()
    dp_rank = get_data_parallel_rank()
    dp_size = get_data_parallel_world_size()

    for name, param in model.named_parameters():
        # 构建全局键
        global_key = f'model.{name}'

        # 计算分片偏移
        # TP 分片维度取决于参数类型
        if 'column_parallel' in name or 'query' in name or 'key' in name or 'value' in name:
            # 列并行：输出维度分片
            rank_offsets = [(0, tp_rank, tp_size)]  # 第0维
        elif 'row_parallel' in name or 'dense' in name:
            # 行并行：输入维度分片
            rank_offsets = [(1, tp_rank, tp_size)]  # 第1维
        else:
            rank_offsets = []

        # DP 副本
        replica_id = dp_rank if dp_size > 1 else 0

        state_dict[name] = ShardedTensor.from_rank_offsets(
            key=global_key,
            data=param,
            *rank_offsets,
            replica_id=replica_id,
        )

    return state_dict
```

### 5.1 加载入口函数

```python
def load(
    sharded_state_dict: ShardedStateDict,
    checkpoint_dir: str,
    sharded_strategy: Union[LoadShardedStrategy, Tuple[str, int], None] = None,
    common_strategy: Union[LoadCommonStrategy, Tuple[str, int], None] = None,
    validate_access_integrity: bool = True,
    strict: Union[str, StrictHandling] = StrictHandling.ASSUME_OK_UNEXPECTED,
) -> Union[StateDict, Tuple[StateDict, Set[str], Set[str]]]:
    """加载分布式检查点

    流程:
    1. 加载公共状态字典
    2. 验证完整性和严格模式
    3. 加载分片张量
    4. 应用工厂合并

    Args:
        sharded_state_dict: 目标模型的分片状态字典（作为加载映射）
        checkpoint_dir: 检查点目录
        sharded_strategy: 分片加载策略
        common_strategy: 公共数据加载策略
        validate_access_integrity: 是否验证访问完整性
        strict: 严格模式（处理键不匹配的方式）

    Returns:
        加载的状态字典，可选返回缺失键和意外键
    """
    # 验证检查点并获取策略
    sharded_strategy, common_strategy = verify_checkpoint_and_load_strategy(
        checkpoint_dir, sharded_strategy, common_strategy
    )

    # 加载公共状态字典
    common_state_dict = common_strategy.load_common(checkpoint_dir)

    # 预处理
    sharded_state_dict, nonpersistent_state_dict, sh_ten_factories = load_preprocess(
        sharded_state_dict
    )
    merge(common_state_dict, nonpersistent_state_dict)

    # 验证
    if StrictHandling.requires_explicit_ckpt_mismatch_check(strict):
        ckpt_sharded_metadata = load_sharded_metadata(checkpoint_dir, sharded_strategy, common_strategy)

    if validate_access_integrity or StrictHandling.requires_global_app_metadata(strict):
        local_metadata, global_metadata = determine_global_metadata(sharded_state_dict)

    # 加载分片数据
    loaded_state_dict = sharded_strategy.load(sharded_state_dict, checkpoint_dir)
    merge(common_state_dict, loaded_state_dict)

    # 应用工厂合并
    loaded_state_dict = apply_factory_merges(common_state_dict, sh_ten_factories)

    return loaded_state_dict
```

### 5.2 训练恢复加载

```python
def load_checkpoint(
    model: Union[torch.nn.Module, List[torch.nn.Module]],
    optimizer: Optional[torch.optim.Optimizer],
    opt_param_scheduler: Optional[OptimizerParamScheduler],
    load_arg: str = 'load',
    strict: bool = True,
) -> Tuple[int, bool]:
    """加载检查点并恢复训练

    Returns:
        (iteration, success): 迭代次数和是否成功
    """
    args = get_args()
    load_dir = getattr(args, load_arg)

    # 查找可用检查点
    iteration = get_iteration(load_dir)
    checkpoint_name = get_checkpoint_name(load_dir, iteration)

    # 加载检查点
    if args.use_dist_ckpt:
        state_dict = load_dist_checkpoint(model, optimizer, opt_param_scheduler, checkpoint_name)
    else:
        state_dict = torch.load(checkpoint_name)

    # 恢复模型状态
    if isinstance(model, list):
        for pp_rank, pp_model in enumerate(model):
            pp_model.load_state_dict(state_dict['model'][pp_rank], strict=strict)
    else:
        model.load_state_dict(state_dict['model'], strict=strict)

    # 恢复优化器状态
    if optimizer is not None and state_dict.get('optimizer') is not None:
        optimizer.load_state_dict(state_dict['optimizer'])

    # 恢复学习率调度器
    if opt_param_scheduler is not None and state_dict.get('opt_param_scheduler') is not None:
        opt_param_scheduler.load_state_dict(state_dict['opt_param_scheduler'])

    # 恢复 RNG 状态
    if state_dict.get('rng_state') is not None:
        set_rng_state(state_dict['rng_state'])

    return iteration, True
```

## 6. 检查点策略

### 6.1 保存策略

```python
class SaveShardedStrategy(ABC):
    """分片保存策略基类"""

    @abstractmethod
    def save(self, sharded_state_dict: ShardedStateDict, checkpoint_dir: str):
        """保存分片状态字典"""
        pass


class FullyParallelSaveStrategyWrapper(SaveShardedStrategy):
    """完全并行保存策略

    所有 rank 并行保存自己的分片
    """
    def save(self, sharded_state_dict, checkpoint_dir):
        # 每个 rank 并行写入自己的分片
        for key, sharded_tensor in sharded_state_dict.items():
            if isinstance(sharded_tensor, ShardedTensor):
                # 构建分片文件路径
                shard_path = self._get_shard_path(checkpoint_dir, sharded_tensor)
                # 保存张量
                torch.save(sharded_tensor.data, shard_path)
```

### 6.2 加载策略

```python
class LoadShardedStrategy(ABC):
    """分片加载策略基类"""

    @abstractmethod
    def load(self, sharded_state_dict: ShardedStateDict, checkpoint_dir: str) -> StateDict:
        """加载分片状态字典"""
        pass


class FullyParallelLoadStrategyWrapper(LoadShardedStrategy):
    """完全并行加载策略

    支持:
    - 跨 TP/PP/DP 配置加载
    - 模型重分片
    """
    def load(self, sharded_state_dict, checkpoint_dir):
        loaded_dict = {}
        for key, sharded_tensor in sharded_state_dict.items():
            if isinstance(sharded_tensor, ShardedTensor):
                # 加载对应的分片数据
                loaded_dict[key] = self._load_shard(sharded_tensor, checkpoint_dir)
        return loaded_dict

    def _load_shard(self, sharded_tensor: ShardedTensor, checkpoint_dir: str):
        """加载单个分片

        支持重分片：如果检查点的分片配置与当前配置不同，自动合并/拆分
        """
        # 从元数据获取检查点的分片信息
        ckpt_metadata = load_metadata(checkpoint_dir)

        # 计算需要加载哪些分片
        required_shards = self._compute_required_shards(
            sharded_tensor.global_offset,
            sharded_tensor.local_shape,
            ckpt_metadata.fragmentations
        )

        # 加载并合并/拆分
        result = torch.empty(sharded_tensor.local_shape, dtype=sharded_tensor.dtype)
        for shard_info in required_shards:
            shard_data = torch.load(shard_info.path)
            # 复制到对应位置
            result[shard_info.local_slice] = shard_data[shard_info.source_slice]

        return result
```

### 6.3 严格处理模式

```python
class StrictHandling(Enum):
    """严格处理模式

    定义如何处理检查点与目标模型之间的键不匹配
    """
    ASSUME_OK_UNEXPECTED = auto()  # 假设没有意外键（最高性能）
    LOG_UNEXPECTED = auto()        # 记录意外键
    LOG_ALL = auto()               # 记录所有不匹配
    RAISE_UNEXPECTED = auto()      # 有意外键时抛出异常
    RAISE_ALL = auto()             # 有不匹配时抛出异常
    RETURN_ALL = auto()            # 返回所有不匹配键


def validate_integrity_and_strict_load(
    sharded_state_dict: ShardedStateDict,
    strict: StrictHandling,
    validate_access_integrity: bool,
    local_metadata,
    global_metadata,
    ckpt_sharded_metadata,
) -> Tuple[ShardedStateDict, Set[str], Set[str]]:
    """验证完整性并处理严格模式

    Returns:
        (state_dict, missing_keys, unexpected_keys)
    """
    missing_keys = set()
    unexpected_keys = set()

    if ckpt_sharded_metadata is not None:
        # 检查目标模型的键
        target_keys = set(sharded_state_dict.keys())
        ckpt_keys = set(ckpt_sharded_metadata.keys())

        missing_keys = target_keys - ckpt_keys
        unexpected_keys = ckpt_keys - target_keys

        # 根据严格模式处理
        if strict in (StrictHandling.RAISE_UNEXPECTED, StrictHandling.RAISE_ALL):
            if missing_keys or (unexpected_keys and strict == StrictHandling.RAISE_ALL):
                raise CheckpointingException(
                    f"Checkpoint mismatch: missing={missing_keys}, unexpected={unexpected_keys}"
                )

        if strict in (StrictHandling.LOG_UNEXPECTED, StrictHandling.LOG_ALL):
            if unexpected_keys:
                logger.warning(f"Unexpected keys in checkpoint: {unexpected_keys}")
            if missing_keys and strict == StrictHandling.LOG_ALL:
                logger.warning(f"Missing keys in checkpoint: {missing_keys}")

    return sharded_state_dict, missing_keys, unexpected_keys
```

### 7.1 异步保存配置

```python
def schedule_async_save(
    checkpoint_state: Dict,
    checkpoint_name: str,
) -> None:
    """调度异步保存

    将检查点保存操作放入后台队列，不阻塞训练
    """
    args = get_args()
    if not args.async_save:
        return  # 同步保存

    # 将保存任务放入队列
    async_queue.put((checkpoint_state, checkpoint_name))
```

### 7.2 异步保存工作线程

```python
def _async_save_worker():
    """异步保存工作线程"""
    while True:
        # 从队列获取任务
        checkpoint_state, checkpoint_name = async_queue.get()

        if checkpoint_state is None:
            # 终止信号
            break

        # 执行保存
        try:
            torch.save(checkpoint_state, checkpoint_name)
            logger.info(f"Async saved checkpoint to {checkpoint_name}")
        except Exception as e:
            logger.error(f"Failed to save checkpoint: {e}")

        async_queue.task_done()


# 启动工作线程
async_save_thread = threading.Thread(target=_async_save_worker, daemon=True)
async_save_thread.start()
```

### 8.3 跨配置加载

```python
# 保存时: TP=8, PP=2
# 加载时: TP=4, PP=1

# 分布式检查点自动处理重分片
args.use_dist_ckpt = True
args.dist_ckpt_format = 'fully_reshardable'

# 加载会自动将 TP=8 的分片合并为 TP=4
iteration, success = load_checkpoint(model, optimizer, lr_scheduler)
```

### 8.4 手动检查点操作

```python
from megatron.core.dist_checkpointing import save, load
from megatron.core.dist_checkpointing.mapping import ShardedTensor

# 创建分片状态字典
sharded_state_dict = {}
for name, param in model.named_parameters():
    sharded_state_dict[name] = ShardedTensor.from_rank_offsets(
        key=f'model.{name}',
        data=param,
        (0, tp_rank, tp_size),  # TP 分片
    )

# 保存
save(sharded_state_dict, '/path/to/checkpoint')

# 加载
loaded_state_dict = load(sharded_state_dict, '/path/to/checkpoint')

# 应用到模型
for name, param in model.named_parameters():
    param.data.copy_(loaded_state_dict[name])
```

## 10. 常见问题

### Q1: 加载时内存不足

**可能原因**:
- 传统检查点需要完整模型副本
- 检查点太大

**解决方案**:
```python
# 使用分布式检查点
args.use_dist_ckpt = True

# 减小模型分片
args.tensor_model_parallel_size = 8
args.pipeline_model_parallel_size = 4
```

### Q2: 跨配置加载失败

**可能原因**:
- 检查点格式不支持重分片
- 并行配置不兼容

**解决方案**:
```python
# 使用完全可重分片格式
args.dist_ckpt_format = 'fully_reshardable'

# 或转换为兼容格式
# (需要额外的转换脚本)
```

### Q3: 保存太慢影响训练

**可能原因**:
- 同步保存阻塞训练
- I/O 瓶颈

**解决方案**:
```python
# 启用异步保存
args.async_save = True

# 减少保存频率
args.save_interval = 5000

# 使用高速存储
args.save = '/mnt/nvme/checkpoints'
```

### Q4: 检查点损坏

**可能原因**:
- 存储故障
- 保存过程中断

**解决方案**:
```python
# 1. 启用备份
args.ckpt_fully_parallel_save = True  # 原子性保存

# 2. 定期验证
def validate_checkpoint(checkpoint_dir):
    try:
        load_sharded_metadata(checkpoint_dir)
        return True
    except:
        return False

# 3. 保留多个版本
args.keep_last_n_checkpoints = 5
```
