## 2. 参数初始化方法

**文件位置**: `megatron/core/tensor_parallel/layers.py` 和 `megatron/core/transformer/transformer_config.py`

### 2.1 初始化方法定义

```python
# megatron/core/transformer/transformer_config.py

def init_method_normal(sigma: float):
    """正态分布初始化工厂函数

    Args:
        sigma: 标准差

    Returns:
        初始化函数 (用于 nn.Module.apply)
    """
    def init_(tensor):
        return torch.nn.init.normal_(tensor, mean=0.0, std=sigma)
    return init_


def scaled_init_method_normal(sigma: float, num_layers: int):
    """缩放正态分布初始化

    用于输出层，标准差按 1/sqrt(2*num_layers) 缩放

    这种初始化方式确保深层网络的输出方差稳定
    """
    std = sigma / math.sqrt(2.0 * num_layers)

    def init_(tensor):
        return torch.nn.init.normal_(tensor, mean=0.0, std=std)
    return init_
```

### 2.2 TransformerConfig 中的初始化配置

```python
@dataclass
class TransformerConfig:
    # 初始化相关配置
    init_method: Callable = field(default_factory=lambda: init_method_normal(0.02))
    """权重初始化方法，默认为 std=0.02 的正态分布"""

    init_method_std: float = 0.02
    """初始化标准差"""

    output_layer_init_method: Callable = None
    """输出层初始化方法，默认使用 scaled_init_method_normal"""

    embedding_init_method: Callable = None
    """Embedding 层初始化方法"""

    embedding_init_method_std: float = 0.02
    """Embedding 初始化标准差"""
```

### 2.3 各层初始化策略

| 层类型 | 默认初始化 | 说明 |
|--------|-----------|------|
| Attention QKV | `init_method_normal(0.02)` | 标准正态 |
| Attention Output | `scaled_init_method_normal` | 缩放正态 |
| MLP fc1 | `init_method_normal(0.02)` | 标准正态 |
| MLP fc2 | `scaled_init_method_normal` | 缩放正态 |
| Embedding | `init_method_normal(0.02)` | 可单独配置 |
| Output Layer | `scaled_init_method_normal` | 缩放正态 |

## 3. 分布式参数初始化

**文件位置**: `megatron/core/tensor_parallel/layers.py`

### 3.1 CPU 初始化 (Master Weight 分发)

```python
def _initialize_affine_weight_cpu(
    weight,
    out_features,
    in_features,
    per_partition_size,
    partition_dim,
    init_method,
    stride,
    return_master_weight=False,
):
    """CPU 初始化：创建主权重后分片分发

    流程:
    1. 在所有 rank 上创建完整的主权重
    2. 应用初始化方法
    3. 每个 rank 取自己的分片

    适用场景:
    - 需要严格一致性的初始化
    - 调试阶段
    """
    # 创建主权重
    master_weight = torch.empty(out_features, in_features, dtype=weight.dtype)
    init_method(master_weight)

    # 按 TP rank 切分
    rank = get_tensor_model_parallel_rank()
    world_size = get_tensor_model_parallel_world_size()

    if partition_dim == 0:
        # 按行切分 (RowParallel)
        start = rank * per_partition_size
        end = start + per_partition_size
        weight.data.copy_(master_weight[start:end, :])
    else:
        # 按列切分 (ColumnParallel)
        start = rank * per_partition_size
        end = start + per_partition_size
        weight.data.copy_(master_weight[:, start:end])

    if return_master_weight:
        return master_weight
    return None
```

### 3.2 GPU 初始化 (分布式随机数)

```python
def _initialize_affine_weight_gpu(
    weight,
    init_method,
    partition_dim,
    stride,
):
    """GPU 初始化：每个 rank 独立但确定性

    使用 CUDA RNG Tracker 确保不同 TP rank 获得不同但可复现的随机数

    流程:
    1. 获取当前 TP rank
    2. 使用对应的状态种子初始化
    3. 直接初始化分片权重

    适用场景:
    - 生产环境
    - 大模型训练
    """
    # 使用 CUDA RNG tracker 确保可复现
    with get_cuda_rng_tracker().fork():
        init_method(weight)

    return None
```

### 3.3 RNG Tracker 工作原理

```python
# megatron/core/tensor_parallel/random.py

class CudaRNGStateTracker:
    """CUDA 随机数状态跟踪器

    确保分布式训练中各 rank 的随机数序列独立但可复现
    """
    def __init__(self):
        self._states = {}  # name -> rng state
        self._states['global'] = torch.cuda.get_rng_state()

    def fork(self, name='model_parallel'):
        """创建独立的 RNG 状态

        基于 rank 和全局种子派生，确保:
        1. 不同 rank 有不同随机序列
        2. 相同配置下可复现
        """
        if name not in self._states:
            # 基于 rank 派生新种子
            rank = get_tensor_model_parallel_rank()
            new_seed = self._seeds[name] + rank
            self._states[name] = torch.cuda.get_rng_state()
            torch.cuda.manual_seed(new_seed)

        return _RNGStateContext(self, name)

    def set_state(self, name, state):
        """恢复指定状态的 RNG"""
        self._states[name] = state
```

## 4. Embedding 层初始化

**文件位置**: `megatron/core/tensor_parallel/layers.py` (VocabParallelEmbedding)

### 4.1 词表并行 Embedding

```python
class VocabParallelEmbedding(torch.nn.Module):
    """词表并行 Embedding

    将词表按 TP rank 切分，每个 rank 只存储部分 embedding

    例如: vocab_size=50000, tp_size=8
    → 每个 rank 存储 50000/8 = 6250 个 embedding
    """
    def __init__(self, num_embeddings, embedding_dim, init_method):
        super().__init__()

        self.tp_size = get_tensor_model_parallel_world_size()
        self.tp_rank = get_tensor_model_parallel_rank()

        # 计算本 rank 的词表范围
        self.vocab_start_index, self.vocab_end_index = \
            VocabUtility.vocab_range_from_global_vocab_size(
                num_embeddings, self.tp_rank, self.tp_size
            )
        self.local_vocab_size = self.vocab_end_index - self.vocab_start_index

        # 本地 embedding 权重
        self.weight = torch.nn.Parameter(
            torch.empty(self.local_vocab_size, embedding_dim)
        )

        # 初始化
        init_method(self.weight)

    def forward(self, input_):
        """前向传播

        处理流程:
        1. 将超出本地词表范围的 token 设为 0
        2. 查表获取 embedding
        3. All-reduce 聚合所有 rank 的结果
        """
        # 创建 mask: token 是否在本地词表范围内
        input_mask = (input_ >= self.vocab_start_index) & \
                     (input_ < self.vocab_end_index)

        # 映射到本地索引
        local_input = input_ - self.vocab_start_index
        local_input = local_input * input_mask  # 超范围的设为 0

        # 查表
        output = F.embedding(local_input, self.weight)

        # All-reduce 聚合
        output = output * input_mask.unsqueeze(-1)  # mask 对应位置
        output = all_reduce(output, group=get_tensor_model_parallel_group())

        return output
```

## 5. Column/Row Parallel Linear

**文件位置**: `megatron/core/tensor_parallel/layers.py`

### 5.1 ColumnParallelLinear

```python
class ColumnParallelLinear(torch.nn.Module):
    """列并行线性层

    权重按列切分: Y = X @ [W1, W2, ..., Wn]
    每个 TP rank 处理一部分输出维度

    适用: MLP fc1, Attention QKV 投影
    """
    def __init__(
        self,
        in_features,
        out_features,
        config,
        init_method,
        bias=True,
        gather_output=False,  # 是否聚合输出
        skip_bias_add=False,
    ):
        super().__init__()

        self.tp_size = get_tensor_model_parallel_world_size()
        self.out_features_per_rank = out_features // self.tp_size

        # 本地权重 (列切片)
        self.weight = torch.nn.Parameter(
            torch.empty(self.out_features_per_rank, in_features)
        )

        if bias:
            self.bias = torch.nn.Parameter(
                torch.empty(self.out_features_per_rank)
            )

        # 初始化
        init_method(self.weight)
        if bias:
            with torch.no_grad():
                self.bias.zero_()

    def forward(self, input_):
        # 输入已经在 TP group 内复制
        # 直接做本地 matmul
        output = torch.nn.functional.linear(input_, self.weight, self.bias)

        if self.gather_output:
            # 聚合所有 rank 的输出
            output = gather_from_tensor_model_parallel_region(output)

        return output
```

### 5.2 RowParallelLinear

```python
class RowParallelLinear(torch.nn.Module):
    """行并行线性层

    权重按行切分: Y = [X1, X2, ..., Xn] @ [W1; W2; ...; Wn]
    每个 TP rank 处理一部分输入维度

    适用: MLP fc2, Attention Output 投影

    Note: 通常与 ColumnParallelLinear 配对使用
    """
    def __init__(
        self,
        in_features,
        out_features,
        config,
        init_method,
        bias=True,
        input_is_parallel=True,  # 输入是否已分片
        skip_bias_add=False,
    ):
        super().__init__()

        self.tp_size = get_tensor_model_parallel_world_size()
        self.in_features_per_rank = in_features // self.tp_size

        # 本地权重 (行切片)
        self.weight = torch.nn.Parameter(
            torch.empty(out_features, self.in_features_per_rank)
        )

        if bias:
            # Bias 只在 rank 0 初始化，然后广播
            self.bias = torch.nn.Parameter(torch.empty(out_features))

        # 初始化 (使用缩放方法)
        init_method(self.weight)

    def forward(self, input_):
        if not self.input_is_parallel:
            # 将输入分片到各 rank
            input_ = scatter_to_tensor_model_parallel_region(input_)

        # 本地 matmul
        output = torch.nn.functional.linear(input_, self.weight)

        # All-reduce 聚合结果
        output = reduce_from_tensor_model_parallel_region(output)

        if self.bias is not None:
            output = output + self.bias

        return output
```

## 6. 模型构建流程

### 6.1 GPTModel 构建

```python
# megatron/core/models/gpt/gpt_model.py

class GPTModel(LanguageModule):
    def __init__(
        self,
        config: TransformerConfig,
        transformer_layer_spec: ModuleSpec,
        vocab_size: int,
        max_sequence_length: int,
        pre_process: bool = True,
        post_process: bool = True,
        share_embeddings_and_output_weights: bool = False,
    ):
        super().__init__(config=config)

        # 1. Embedding 层 (pre_process stage)
        if self.pre_process:
            self.embedding = LanguageModelEmbedding(
                config=config,
                vocab_size=vocab_size,
                max_sequence_length=max_sequence_length,
            )

        # 2. Transformer Block (核心层)
        self.decoder = TransformerBlock(
            config=config,
            spec=transformer_layer_spec,
            pre_process=pre_process,
            post_process=post_process,
        )

        # 3. Output Layer (post_process stage)
        if self.post_process:
            self.output_layer = ColumnParallelLinear(
                config.hidden_size,
                vocab_size,
                config=config,
                init_method=config.output_layer_init_method,
                skip_weight_param_allocation=share_embeddings_and_output_weights,
            )

        # 4. 权重共享处理
        if self.pre_process or self.post_process:
            self.setup_embeddings_and_output_layer()
```

### 6.2 TransformerBlock 构建

```python
# megatron/core/transformer/transformer_block.py

class TransformerBlock(GraphableMegatronModule):
    def __init__(
        self,
        config: TransformerConfig,
        spec: ModuleSpec,
        pre_process: bool = True,
        post_process: bool = True,
    ):
        super().__init__(config=config)

        # 计算本 PP stage 的层数
        self.num_layers = get_num_layers_to_build(config)

        # 构建 Transformer Layers
        self.layers = torch.nn.ModuleList()
        for layer_idx in range(self.num_layers):
            layer = TransformerLayer(
                config=config,
                spec=spec,
                layer_number=layer_idx + 1,
            )
            self.layers.append(layer)

        # Final LayerNorm (post_process)
        if self.post_process:
            self.final_layernorm = LayerNormBuilder.build(
                config.hidden_size,
                config.layernorm_epsilon,
                config,
            )
```

### 6.3 TransformerLayer 构建

```python
# megatron/core/transformer/transformer_layer.py

class TransformerLayer(BaseTransformerLayer):
    def __init__(
        self,
        config: TransformerConfig,
        spec: ModuleSpec,
        layer_number: int = 1,
    ):
        super().__init__(config=config)

        # 1. Input LayerNorm
        self.input_layernorm = LayerNormBuilder.build(
            config.hidden_size,
            config.layernorm_epsilon,
            config,
        )

        # 2. Self Attention
        self.self_attention = build_module(
            spec.self_attention,
            config=config,
            layer_number=layer_number,
        )

        # 3. Pre-MLP LayerNorm
        self.pre_mlp_layernorm = LayerNormBuilder.build(
            config.hidden_size,
            config.layernorm_epsilon,
            config,
        )

        # 4. MLP
        self.mlp = build_module(
            spec.mlp,
            config=config,
        )

        # 5. Bias-Dropout-Add (残差连接)
        self.self_attn_bda = build_module(spec.self_attn_bda)
        self.mlp_bda = build_module(spec.mlp_bda)
```

## 7. 权重共享机制

```python
# megatron/core/models/common/language_module/language_module.py

class LanguageModule(MegatronModule):
    def setup_embeddings_and_output_layer(self):
        """设置 Embedding 和 Output Layer 的权重共享

        流程:
        1. 如果 share_embeddings_and_output_weights=True
        2. 共享权重引用
        3. 只保存一份参数
        """
        if self.share_embeddings_and_output_weights:
            # 获取 embedding 权重
            emb_weight = self.shared_embedding_or_output_weight()

            # Output layer 复用 embedding 权重
            if self.post_process and hasattr(self.output_layer, 'weight'):
                self.output_layer.weight = emb_weight

    def shared_embedding_or_output_weight(self):
        """获取共享的 embedding 权重"""
        if self.pre_process:
            return self.embedding.word_embeddings.weight
        else:
            # 从 TP group 的第一个 rank 获取
            return self.shared_embedding_weight
```

```python
# 加载预训练权重
def load_pretrained_weights(model, checkpoint_path):
    checkpoint = torch.load(checkpoint_path)

    # 处理 TP/PP 不匹配的情况
    if 'model' in checkpoint:
        state_dict = checkpoint['model']
    else:
        state_dict = checkpoint

    # 加载权重 (自动处理并行分片)
    model.load_state_dict(state_dict, strict=False)

    return model
```

## 9. 常见问题

### Q1: 初始化后 loss 为 NaN

**可能原因**:
- 初始化标准差过大
- 精度溢出

**解决方案**:
```python
# 减小初始化标准差
config.init_method_std = 0.01

# 使用更稳定的初始化
config.init_method = init_method_normal(0.01)
```

### Q2: 各 rank 参数不一致

**可能原因**:
- 未正确使用 RNG tracker
- CPU/GPU 初始化混用

**解决方案**:
```python
# 确保使用 GPU 初始化
config.use_cpu_initialization = False

# 检查 RNG tracker
from megatron.core.tensor_parallel import get_cuda_rng_tracker
get_cuda_rng_tracker().set_states(...)
```

### Q3: Embedding 和 Output 不匹配

**可能原因**:
- 权重共享未正确设置

**解决方案**:
```python
# 确保权重共享配置一致
model = GPTModel(
    config=config,
    share_embeddings_and_output_weights=True,
)
```
