# Megatron-LM 数据管道模块详解

> 训练流程第一环：数据加载与预处理

---

## 1. 模块概述

数据管道负责将原始数据高效地输送给训练循环，涉及数据集构建、采样策略、分词处理、数据预处理等环节。

```
原始数据
    │
    ▼
┌─────────────────────┐
│    Tokenizer        │  分词处理
└─────────────────────┘
    │
    ▼
┌─────────────────────┐
│  IndexedDataset     │  二进制存储 (.idx + .bin)
└─────────────────────┘
    │
    ▼
┌─────────────────────┐
│  MegatronDataset    │  序列构建
└─────────────────────┘
    │
    ▼
┌─────────────────────┐
│  BlendedDataset     │  多数据源混合 (可选)
└─────────────────────┘
    │
    ▼
┌─────────────────────┐
│  DataSampler        │  分布式采样
└─────────────────────┘
    │
    ▼
┌─────────────────────┐
│  DataLoader         │  批量加载
└─────────────────────┘
    │
    ▼
  训练循环
```

## 2. 核心组件详解

### 2.1 IndexedDataset (底层数据存储)

**文件位置**: `megatron/core/datasets/indexed_dataset.py`

**设计原理**:
- 使用内存映射 (mmap) 高效读取大规模数据
- 两个文件配合：`.idx` (索引) + `.bin` (数据)

```
.idx 文件结构:
┌────────────────────────────────┐
│ Magic Number (uint64)          │  魔数校验
├────────────────────────────────┤
│ Version (uint64)               │  版本号
├────────────────────────────────┤
│ Number of Sequences (uint64)   │  序列数量
├────────────────────────────────┤
│ Number of Tokens (uint64)      │  总 token 数
├────────────────────────────────┤
│ Sequence Lengths [N]           │  每个序列的长度
├────────────────────────────────┤
│ Sequence Pointers [N]          │  每个序列在 .bin 中的偏移
├────────────────────────────────┤
│ Document Indices [...]         │  文档边界索引
└────────────────────────────────┘

.bin 文件:
┌────────────────────────────────┐
│ Raw Token IDs (int array)      │  连续存储的所有 token
└────────────────────────────────┘
```

**关键实现**:

```python
class IndexedDataset:
    def __init__(self, path, skip_warmup=False):
        self._idx_path = path + '.idx'
        self._bin_path = path + '.bin'

        # 读取索引文件
        with open(self._idx_path, 'rb') as f:
            magic, version = struct.unpack('<QQ', f.read(16))
            self._n_sequences, self._n_tokens = struct.unpack('<QQ', f.read(16))
            # 读取序列长度和指针...

        # 内存映射二进制数据
        self._bin_buffer = np.memmap(self._bin_path, dtype=np.int32, mode='r')

    def __getitem__(self, idx):
        """获取第 idx 个序列"""
        start = self._sequence_pointers[idx]
        end = start + self._sequence_lengths[idx]
        return self._bin_buffer[start:end]
```

**优化注意事项**:
- 支持 S3/Object Storage 远程读取
- 可配置 warmup 预加载热点数据
- 支持延迟加载以节省内存

### 2.2 GPTDataset (序列构建)

**文件位置**: `megatron/core/datasets/gpt_dataset.py`

**设计原理**:
- 构建固定长度的训练序列
- 处理跨文档序列拼接
- 生成 attention mask 和 position ids

**核心实现**:

```python
class GPTDataset(MegatronDataset):
    def __init__(self, config: GPTDatasetConfig):
        self.config = config
        self.indexed_dataset = indexed_dataset
        self.sequence_length = config.sequence_length

        # 构建样本索引
        self._build_sample_index()

    def __getitem__(self, idx):
        """获取第 idx 个样本"""
        # 1. 获取序列 tokens
        start_idx = self.sample_index[idx]
        end_idx = start_idx + self.sequence_length + 1  # +1 for labels
        tokens = self.indexed_dataset[start_idx:end_idx]

        # 2. 构建注意力掩码和位置 ID
        attention_mask, loss_mask, position_ids = \
            self._get_ltor_masks_and_position_ids(tokens)

        return {
            'tokens': tokens[:-1],      # 输入
            'labels': tokens[1:],       # 目标 (左移一位)
            'attention_mask': attention_mask,
            'loss_mask': loss_mask,
            'position_ids': position_ids,
        }

    def _get_ltor_masks_and_position_ids(self, tokens):
        """生成 left-to-right 注意力掩码"""
        seq_length = len(tokens) - 1

        # 下三角注意力掩码 (因果掩码)
        attention_mask = torch.tril(torch.ones(seq_length, seq_length))

        # 位置 ID
        position_ids = torch.arange(seq_length)

        # Loss mask (排除 padding 和 EOD)
        loss_mask = torch.ones(seq_length)

        return attention_mask, loss_mask, position_ids
```

**关键配置参数**:

```python
@dataclass
class GPTDatasetConfig:
    sequence_length: int                # 序列长度
    reset_position_ids: bool = False    # 是否在文档边界重置位置
    reset_attention_mask: bool = False  # 是否在文档边界重置注意力
    eod_mask_loss: bool = False         # 是否在 EOD token 上计算损失
    add_extra_token_to_sequence: bool = True  # 添加额外 token
```

**修改优化建议**:

| 场景 | 优化方式 |
|------|---------|
| 长序列训练 | 启用 `reset_position_ids` 避免越界 |
| 多文档拼接 | 关闭 `eod_mask_loss` 跨文档学习 |
| 内存受限 | 减小 `sequence_length` 或启用 chunked loading |

### 2.3 BlendedDataset (数据混合)

**文件位置**: `megatron/core/datasets/blended_dataset.py`

**设计原理**:
- 按权重混合多个数据源
- 支持数据集级别的 curriculum learning

```python
class BlendedDataset:
    def __init__(self, datasets, weights, size):
        """
        Args:
            datasets: List[MegatronDataset] - 数据集列表
            weights: List[float] - 各数据集权重 (归一化)
            size: int - 总样本数
        """
        self.datasets = datasets
        self.weights = weights
        self.size = size

        # 计算每个数据集的样本数
        self.dataset_sizes = [int(size * w) for w in weights]

        # 构建混合索引
        self._build_blended_index()

    def __getitem__(self, idx):
        """按混合索引从对应数据集获取样本"""
        dataset_idx, sample_idx = self.blended_index[idx]
        return self.datasets[dataset_idx][sample_idx]
```

**使用示例**:

```python
# 混合 Code 和 Text 数据
builder = BlendedMegatronDatasetBuilder(
    datasets=[
        ('code_dataset', 0.3),   # 30% 代码
        ('text_dataset', 0.7),   # 70% 文本
    ],
    config=config,
)
train_dataset = builder.build()
```

### 2.4 DataSampler (分布式采样)

**文件位置**: `megatron/training/datasets/data_samplers.py`

**采样器类型**:

```python
# 1. 顺序采样 (确定性)
class MegatronPretrainingSampler:
    """每个 DP rank 获取连续的数据块"""

    def __init__(self, total_samples, micro_batch_times_data_parallel_size):
        self.total_samples = total_samples
        self.micro_batch_times_data_parallel = micro_batch_times_data_parallel_size

    def __iter__(self):
        """按 rank 分配连续样本"""
        start = self.rank * self.micro_batch_times_data_parallel
        end = start + self.batch_size_per_epoch
        for idx in range(start, end, self.micro_batch_size):
            yield list(range(idx, idx + self.micro_batch_size))


# 2. 随机采样 (每个 epoch 不同)
class MegatronPretrainingRandomSampler:
    """每个 epoch 随机打乱后按 rank 分配"""

    def __iter__(self):
        """随机打乱后按 rank 分配"""
        active_total_samples = self.total_samples - self.last_epoch_leftovers
        permutation = torch.randperm(active_total_samples)

        # 按 DP rank 分片
        start = self.rank * self.num_samples
        end = start + self.num_samples
        indices = permutation[start:end]

        for idx in range(0, len(indices), self.micro_batch_size):
            yield indices[idx:idx + self.micro_batch_size].tolist()
```

**Hybrid CP Sampler (Context Parallel)**:

```python
class HybridCPMegatronPretrainingSampler:
    """为 Hybrid Context Parallel 设计的特殊采样器

    特点:
    - 拉取完整 global batch
    - 支持 sub-schedule 和负载均衡
    - 用于长序列训练场景
    """

    def __iter__(self):
        # 一次性获取完整 batch
        batch_indices = self._get_full_batch_indices()
        # 按负载均衡策略分配
        yield self._balance_across_cp_ranks(batch_indices)
```

### 2.5 Tokenizer 集成

**文件位置**: `megatron/core/tokenizers/`

**架构设计**:

```
MegatronTokenizerBase (抽象基类)
        │
        ├── MegatronTokenizerText (文本分词器基类)
        │       │
        │       ├── GPTTokenizer (GPT 系列)
        │       ├── LlamaTokenizer (LLaMA 系列)
        │       └── ...
        │
        └── 特殊分词器
                │
                ├── SFTTokenizer (SFT 对话格式)
                └── MultimodalTokenizer (多模态)
```

**核心接口**:

```python
class MegatronTokenizerBase(ABC):
    @abstractmethod
    def tokenize(self, text: str) -> List[int]:
        """文本 → token IDs"""
        pass

    @abstractmethod
    def detokenize(self, tokens: List[int]) -> str:
        """token IDs → 文本"""
        pass

    @property
    @abstractmethod
    def vocab_size(self) -> int:
        """词表大小"""
        pass

    @property
    @abstractmethod
    def eod(self) -> int:
        """文档结束 token"""
        pass
```

**SFT Tokenizer 特殊处理**:

```python
class SFTTokenizer:
    def tokenize_conversation(self, conversation: List[Dict]):
        """处理对话格式数据

        Args:
            conversation: [
                {"role": "system", "content": "..."},
                {"role": "user", "content": "..."},
                {"role": "assistant", "content": "..."},
            ]
        """
        tokens = []
        loss_mask = []  # 只计算 assistant 的损失

        for turn in conversation:
            turn_tokens = self.tokenize(turn["content"])
            tokens.extend(turn_tokens)

            # 只有 assistant 的 token 参与损失计算
            if turn["role"] == "assistant":
                loss_mask.extend([1] * len(turn_tokens))
            else:
                loss_mask.extend([0] * len(turn_tokens))

        return tokens, loss_mask
```

**解决方案**:

```python
dataloader = DataLoader(..., num_workers=8)
```

### Q2: 显存不足

**症状**: OOM 错误

**解决方案**:
```python
# 1. 减小序列长度
config.sequence_length = 1024  # 从 2048 减半

# 2. 减小 micro batch size
args.micro_batch_size = 2
```

### 添加自定义采样器

```python
class MySampler(torch.utils.data.Sampler):
    def __init__(self, dataset, batch_size, world_size, rank):
        self.dataset = dataset
        self.batch_size = batch_size
        self.world_size = world_size
        self.rank = rank

    def __iter__(self):
        # 自定义采样逻辑
        indices = self._generate_indices()
        for i in range(self.rank, len(indices), self.world_size):
            yield indices[i:i + self.batch_size]

    def __len__(self):
        return len(self.dataset) // self.world_size
```
