## 三、前向传播流程

### 3.1 入口方法

```python
def forward_extend(self, batch: ModelWorkerBatch) -> LogitsProcessorOutput:
    """执行 Prefill (Extend) 前向传播"""

    # 1. 构建 ForwardBatch
    forward_batch = ForwardBatch.init_new(batch, self.model_config)

    # 2. 执行模型前向传播
    logits = self._forward_raw(forward_batch)

    # 3. 处理输出
    output = LogitsProcessorOutput(
        logits=logits,
        ...
    )

    return output


def forward_decode(self, batch: ModelWorkerBatch) -> LogitsProcessorOutput:
    """执行 Decode 前向传播"""

    # 1. 构建 ForwardBatch
    forward_batch = ForwardBatch.init_new(batch, self.model_config)
    forward_batch.forward_mode = ForwardMode.DECODE

    # 2. 尝试使用 CUDA Graph
    if self.cuda_graph_runner is not None:
        return self.cuda_graph_runner.forward(forward_batch)

    # 3. 普通执行
    logits = self._forward_raw(forward_batch)

    return LogitsProcessorOutput(logits=logits, ...)
```

### 3.2 核心前向传播

```python
def _forward_raw(self, forward_batch: ForwardBatch) -> torch.Tensor:
    """核心前向传播"""

    # 1. 获取嵌入
    hidden_states = self._get_embeddings(forward_batch)

    # 2. 遍历每一层
    for layer_id, layer in enumerate(self.model.layers):
        # 获取该层的 KV Cache
        kv_cache = self.token_to_kv_pool.get_kv_buffer(layer_id)

        # 执行层前向传播
        hidden_states = layer(
            hidden_states,
            positions=forward_batch.positions,
            kv_cache=kv_cache,
            attn_backend=self.attn_backend,
            forward_batch=forward_batch,
        )

    # 3. 最终层归一化
    hidden_states = self.model.norm(hidden_states)

    # 4. 计算 logits
    logits = self.model.lm_head(hidden_states)

    return logits
```

### 3.3 嵌入层处理

```python
def _get_embeddings(self, forward_batch: ForwardBatch) -> torch.Tensor:
    """获取嵌入向量"""

    if forward_batch.input_embeds is not None:
        # 多模态输入已有嵌入
        return forward_batch.input_embeds

    # 文本 token 嵌入
    return self.model.embed_tokens(forward_batch.input_ids)
```

## 四、ForwardBatch 数据结构

### 4.1 类定义

**文件位置**：`python/sglang/srt/model_executor/forward_batch_info.py`

```python
@dataclasses.dataclass
class ForwardBatch:
    """
    前向传播批次信息。

    包含执行前向传播所需的所有张量数据。
    大部分数据在 GPU 上。
    """

    # ========== 模式 ==========
    forward_mode: ForwardMode              # 前向模式

    # ========== 输入 ==========
    input_ids: torch.Tensor                # [total_tokens] 输入 token IDs
    input_embeds: Optional[torch.Tensor]   # [total_tokens, hidden_dim] 多模态嵌入
    positions: torch.Tensor                # [total_tokens] 位置编码

    # ========== 序列信息 ==========
    seq_lens: torch.Tensor                 # [batch_size] 序列长度
    seq_lens_sum: int                      # 序列长度总和
    batch_size: int                        # 批次大小

    # ========== 缓存索引 ==========
    req_pool_indices: torch.Tensor         # [batch_size] 请求池索引
    out_cache_loc: torch.Tensor            # [total_tokens] 输出缓存位置

    # ========== Prefill 相关 ==========
    prefix_lens: Optional[List[int]]       # 前缀长度 (缓存命中部分)
    extend_lens: Optional[List[int]]       # 扩展长度 (需要计算部分)
    extend_num_tokens: Optional[int]       # 扩展 token 总数

    # ========== 注意力相关 ==========
    qo_indptr: Optional[torch.Tensor]      # Query/Output 索引指针
    kv_indptr: Optional[torch.Tensor]      # KV 索引指针
    kv_indices: Optional[torch.Tensor]     # KV 索引

    # ========== 多模态 ==========
    multimodal_inputs: Optional[List]      # 多模态输入

    # ========== 采样 ==========
    sampling_info: Optional[SamplingBatchInfo]  # 采样信息

    # ========== 推测解码 ==========
    spec_info: Optional[SpecInput]         # 推测解码信息
```

### 4.2 初始化方法

```python
@classmethod
def init_new(cls, batch: ModelWorkerBatch, model_config: ModelConfig) -> "ForwardBatch":
    """从 ModelWorkerBatch 创建 ForwardBatch"""

    forward_mode = batch.forward_mode

    # 基本信息
    batch_size = len(batch.seq_lens)
    total_tokens = batch.extend_num_tokens if forward_mode.is_extend() else batch_size

    # 创建位置张量
    if forward_mode.is_extend():
        # Prefill: 每个请求的完整位置
        positions = torch.cat([
            torch.arange(seq_len, dtype=torch.long, device='cuda')
            for seq_len in batch.seq_lens
        ])
    else:
        # Decode: 每个请求的最后一个位置
        positions = torch.tensor(
            [seq_len - 1 for seq_len in batch.seq_lens],
            dtype=torch.long,
            device='cuda',
        )

    # 创建索引指针 (用于注意力)
    qo_indptr = torch.zeros(batch_size + 1, dtype=torch.int32, device='cuda')
    if forward_mode.is_extend():
        qo_indptr[1:] = torch.cumsum(torch.tensor(batch.extend_lens), 0)

    return cls(
        forward_mode=forward_mode,
        input_ids=batch.input_ids,
        positions=positions,
        seq_lens=batch.seq_lens,
        batch_size=batch_size,
        ...
    )
```

## 五、CUDA Graph 优化

### 5.1 CUDA Graph 原理

CUDA Graph 捕获一系列 GPU 操作，然后可以高效地重放：

```
普通执行 (每次都要 CPU→GPU 通信):
CPU                          GPU
 │                            │
 ├── kernel launch 1 ───────►│──► 执行
 │                            │
 ├── kernel launch 2 ───────►│──► 执行
 │                            │
 └── ...                      │

CUDA Graph (一次捕获，多次重放):
CPU                          GPU
 │                            │
 ├── graph capture ─────────►│──► 记录操作
 │                            │
 ├── graph launch ──────────►│──► 执行整个图
 │                            │
 └── graph launch ──────────►│──► 执行整个图 (低开销)
```

### 5.2 CudaGraphRunner

**文件位置**：`python/sglang/srt/model_executor/cuda_graph_runner.py`

```python
class CudaGraphRunner:
    """
    CUDA Graph 执行器。

    为固定的 batch size 捕获计算图，然后高效重放。
    """

    def __init__(
        self,
        model_runner: ModelRunner,
        max_batch_size: int = 160,
        ...
    ):
        self.model_runner = model_runner
        self.max_batch_size = max_batch_size

        # 存储不同 batch size 的图
        self.graphs: Dict[int, torch.cuda.CUDAGraph] = {}
        self.fixed_input_buffers: Dict[int, DecodeInputBuffers] = {}

        # 捕获图
        self._capture_graphs()

    def _capture_graphs(self):
        """为不同 batch size 捕获计算图"""

        for bs in self._get_batch_sizes_to_capture():
            # 创建固定输入缓冲区
            input_buffers = self._create_input_buffers(bs)
            self.fixed_input_buffers[bs] = input_buffers

            # 创建图
            graph = torch.cuda.CUDAGraph()

            # 捕获
            with torch.cuda.graph(graph):
                output = self.model_runner._forward_raw(input_buffers.forward_batch)

            self.graphs[bs] = graph

    def forward(self, forward_batch: ForwardBatch) -> LogitsProcessorOutput:
        """使用 CUDA Graph 执行前向传播"""

        bs = forward_batch.batch_size

        # 找到最接近的已捕获 batch size
        graph_bs = self._find_graph_batch_size(bs)

        # 复制输入到固定缓冲区
        self._copy_inputs_to_buffer(forward_batch, self.fixed_input_buffers[graph_bs])

        # 重放图
        self.graphs[graph_bs].replay()

        # 获取输出
        return self._get_output_from_buffer(...)
```

### 5.3 输入缓冲区

```python
@dataclasses.dataclass
class DecodeInputBuffers:
    """Decode 模式的固定输入缓冲区"""

    input_ids: torch.Tensor              # [max_bs]
    positions: torch.Tensor              # [max_bs]
    seq_lens: torch.Tensor               # [max_bs]
    out_cache_loc: torch.Tensor          # [max_bs]
    forward_batch: ForwardBatch          # 组装的 ForwardBatch

    def copy_from(self, forward_batch: ForwardBatch):
        """从 ForwardBatch 复制数据"""
        bs = forward_batch.batch_size

        self.input_ids[:bs] = forward_batch.input_ids
        self.positions[:bs] = forward_batch.positions
        self.seq_lens[:bs] = forward_batch.seq_lens
        self.out_cache_loc[:bs] = forward_batch.out_cache_loc
```

### 5.4 分段 CUDA Graph

对于动态 shape 的场景，使用分段图：

```python
class PiecewiseCudaGraphRunner:
    """
    分段 CUDA Graph 执行器。

    将模型分为多个段，每段单独捕获图。
    """

    def __init__(self, model_runner: ModelRunner):
        # 分段策略
        self.segments = self._plan_segments(model_runner.model)

        # 为每段捕获图
        self.segment_graphs = {}
        for seg_id, segment in enumerate(self.segments):
            self.segment_graphs[seg_id] = self._capture_segment(segment)

    def forward(self, forward_batch: ForwardBatch):
        """分段执行"""
        hidden_states = None

        for seg_id, segment in enumerate(self.segments):
            # 准备该段的输入
            if seg_id == 0:
                segment_input = self._get_embeddings(forward_batch)
            else:
                segment_input = hidden_states

            # 执行该段
            graph = self.segment_graphs[seg_id]
            hidden_states = self._run_segment(graph, segment_input)

        return hidden_states
```

## 六、模型层实现

### 6.1 Transformer 层

**文件位置**：`python/sglang/srt/layers/`/

```python
class TransformerBlock(nn.Module):
    """Transformer 块"""

    def __init__(self, config: ModelConfig, layer_id: int):
        self.self_attn = Attention(config)    # 自注意力
        self.mlp = MLP(config)                # 前馈网络
        self.input_layernorm = RMSNorm(...)   # 输入层归一化
        self.post_attention_layernorm = RMSNorm(...)  # 后注意力层归一化

    def forward(
        self,
        hidden_states: torch.Tensor,
        positions: torch.Tensor,
        kv_cache: Tuple[torch.Tensor, torch.Tensor],
        forward_batch: ForwardBatch,
        ...
    ):
        # Pre-norm
        residual = hidden_states
        hidden_states = self.input_layernorm(hidden_states)

        # Self-attention
        hidden_states = self.self_attn(
            hidden_states,
            positions=positions,
            kv_cache=kv_cache,
            forward_batch=forward_batch,
        )
        hidden_states = residual + hidden_states

        # Pre-norm
        residual = hidden_states
        hidden_states = self.post_attention_layernorm(hidden_states)

        # MLP
        hidden_states = self.mlp(hidden_states)
        hidden_states = residual + hidden_states

        return hidden_states
```

### 6.2 线性层

**文件位置**：`python/sglang/srt/layers/linear.py`

```python
class ReplicatedLinear(nn.Module):
    """复制的线性层 (非并行)"""

    def __init__(self, input_size: int, output_size: int, bias: bool = True):
        self.weight = nn.Parameter(torch.empty(output_size, input_size))
        if bias:
            self.bias = nn.Parameter(torch.empty(output_size))

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        return F.linear(x, self.weight, self.bias)


class ColumnParallelLinear(nn.Module):
    """列并行线性层 - TP 时按输出维度切分"""

    def __init__(self, input_size: int, output_size: int, tp_size: int):
        self.output_size_per_partition = output_size // tp_size
        self.weight = nn.Parameter(torch.empty(self.output_size_per_partition, input_size))

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        output = F.linear(x, self.weight)
        # AllReduce 通信由调用者处理
        return output


class RowParallelLinear(nn.Module):
    """行并行线性层 - TP 时按输入维度切分"""

    def __init__(self, input_size: int, output_size: int, tp_size: int):
        self.input_size_per_partition = input_size // tp_size
        self.weight = nn.Parameter(torch.empty(output_size, self.input_size_per_partition))

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        output = F.linear(x, self.weight)
        # AllReduce 合并结果
        output = all_reduce(output)
        return output
```

### 6.3 MLP 层

```python
class MLP(nn.Module):
    """前馈网络"""

    def __init__(self, config: ModelConfig):
        self.gate_up_proj = ColumnParallelLinear(
            config.hidden_size,
            config.intermediate_size * 2,  # Gate 和 Up 合并
        )
        self.down_proj = RowParallelLinear(
            config.intermediate_size,
            config.hidden_size,
        )

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        gate_up = self.gate_up_proj(x)
        gate, up = gate_up.chunk(2, dim=-1)
        x = F.silu(gate) * up  # SwiGLU 激活
        x = self.down_proj(x)
        return x
```

## 八、量化支持

### 8.1 FP8 量化

**文件位置**：`sgl-kernel/csrc/gemm/fp8_gemm_kernel.cu`

FP8 量化使用 `torch.float8_e4m3fn` 存储权重和激活，在 H100/H800 (Compute Capability >= 9.0) 上通过 FP8 Tensor Core 加速：

```python
class FP8Linear(nn.Module):
    """FP8 量化线性层"""

    def __init__(self, in_features: int, out_features: int):
        # 权重以 FP8 存储
        self.weight = nn.Parameter(torch.empty(out_features, in_features, dtype=torch.float8_e4m3fn))
        self.weight_scale = nn.Parameter(torch.ones(out_features))

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        # 反量化权重
        weight_fp16 = self.weight.to(torch.float16) * self.weight_scale.unsqueeze(1)
        return F.linear(x, weight_fp16)
```

实际推理中，FP8 GEMM 通过调用 `sgl-kernel` 的自定义 CUDA 内核完成，支持分块缩放（block-wise scaling），相比逐张量缩放精度更高：

```cpp
// fp8_blockwise_gemm_kernel.cu
// 输入 A/B 为 FP8，但每块有自己的 float scale
// 使用 Tensor Core 的 mma.sync.aligned.m64n8k16.row.col.f16.tf32 类指令
```

### 8.2 GPTQ / AWQ 支持

**文件位置**：`sgl-kernel/csrc/gemm/gptq/`

GPTQ 将权重以 INT4 (每 8 个 INT4 打包到一个 uint32 中) 存储，配合每组（group_size，通常为 128）的 scale 和 zero 进行反量化：

```python
class GPTQLinear(nn.Module):
    """GPTQ 量化线性层"""

    def __init__(self, in_features: int, out_features: int, group_size: int):
        self.qweight = nn.Parameter(...)  # [K/8, N] uint32 打包 INT4
        self.scales = nn.Parameter(...)   # [K/group_size, N] float16
        self.zeros = nn.Parameter(...)    # [K/group_size, N] float16
        self.group_size = group_size

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        # 调用 sgl-kernel 的 gptq_gemm_kernel
        return gptq_quant_linear(x, self.qweight, self.scales, self.zeros, self.group_size)
```

AWQ（Activation-aware Weight Quantization）实现类似，区别在于预先根据激活分布缩放权重，减少量化误差。

### 8.3 QServe W4A8

**文件位置**：`sgl-kernel/csrc/gemm/qserve_w4a8_per_chn_gemm.cu`

QServe 是 W4A8（权重 4bit、激活 8bit）量化方案，通过逐通道（per-channel）缩放进一步提升低精度推理质量，SGLang 将其集成到自定义 GEMM 内核中。

### 8.4 量化内核选择

```python
def select_quant_gemm_kernel(dtype, device):
    if dtype == torch.float8_e4m3fn and device.capability >= 90:
        return sgl_kernel.fp8_gemm        # H100+ FP8 Tensor Core
    elif dtype == torch.int4:
        return sgl_kernel.gptq_gemm       # INT4 GPTQ
    elif dtype == torch.int8:
        return sgl_kernel.int8_gemm       # INT8 静态量化
    else:
        return torch.matmul               # 回退到默认
```

## 十、总结

### 10.1 核心流程

```
ModelWorkerBatch
       │
       ▼
ForwardBatch.init_new()
       │
       ├── input_ids, positions, seq_lens
       ├── req_pool_indices, out_cache_loc
       └── qo_indptr, kv_indptr

       │
       ├── CUDA Graph? ──────────────────────────────────┐
       │       │                                          │
       │       ▼                                          ▼
       │   graph.replay()                           _forward_raw()
       │                                                  │
       └──────────────────────────────────────────────────┘
                                                          │
                                                          ▼
                                              embed_tokens()
                                                          │
                                                          ▼
                                              Transformer layers
                                                          │
                                                          ▼
                                              final_norm + lm_head
                                                          │
                                                          ▼
                                              LogitsProcessorOutput
```

### 10.2 关键设计

1. **CUDA Graph**：减少内核启动开销，适合 Decode 场景
2. **分段图**：支持动态 shape 的场景
3. **混合精度**：FP16/BF16 计算节省显存
4. **量化支持**：FP8/INT4 等多种量化方案
