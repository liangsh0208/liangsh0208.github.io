# 第一章：服务启动与初始化

## 一、概述

本章详细分析 SGLang 引擎的启动流程，包括进程架构、组件初始化顺序、通信机制等。

## 三、启动流程详解

### 3.1 初始化入口

```python
# Engine.__init__ 简化流程
def __init__(self, **kwargs):
    # 1. 解析服务器参数
    server_args = ServerArgs(**kwargs)

    # 2. 注册退出处理
    atexit.register(self.shutdown)

    # 3. 启动子进程
    self._launch_subprocesses(
        server_args=server_args,
        init_tokenizer_manager_func=...,
        run_scheduler_process_func=...,
    )

    # 4. 创建异步事件循环
    self._event_loop = asyncio.new_event_loop()
```

### 3.2 子进程启动流程

**`_launch_subprocesses` 方法是初始化的核心**：

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                        _launch_subprocesses 流程                             │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  1. 配置环境                                                                 │
│     ├─ configure_logger(server_args)      # 日志配置                        │

│                                                                             │
│  2. 分配 IPC 端口                                                            │

│                                                                             │
│  3. 启动 Scheduler 进程                                                      │

│                                                                             │
│  7. 等待 Scheduler 就绪                                                      │

│                                                                             │
```

### 3.3 Scheduler 进程启动

**单 DP 场景 (`dp_size == 1`)**：

```python
def _launch_scheduler_processes(...):
    procs = []
    init_infos = []

    # 为每个 TP rank 创建一个进程
    for pp_rank in pp_rank_range:
        for tp_rank in tp_rank_range:
            # 创建管道用于初始化通信
            reader, writer = mp.Pipe(duplex=False)

            # 计算当前 rank 的 GPU ID
            gpu_id = distributed.get_gpu_id(tp_rank, ...)

            # 启动进程
            proc = mp.Process(
                target=run_scheduler_process,
                args=(
                    server_args,
                    port_args,
                    gpu_id,
                    tp_rank,
                    pp_rank,
                    writer,  # 管道写入端
                    ...
                )
            )
            proc.start()
            procs.append(proc)

    return SchedulerInitResult(procs, init_infos)
```

**多 DP 场景 (`dp_size > 1`)**：

```python
def _launch_scheduler_processes(...):
    # 启动 DataParallelController 进程
    proc = mp.Process(
        target=run_data_parallel_controller_process,
        args=(server_args, port_args, ...)
    )
    proc.start()
    ...
```

### 3.4 Scheduler 进程初始化

**`run_scheduler_process` 函数**：

```python
def run_scheduler_process(
    server_args: ServerArgs,
    port_args: PortArgs,
    gpu_id: int,
    tp_rank: int,
    pp_rank: int,
    pipe_writer,
    ...
):
    # 1. 进程监控设置
    kill_itself_when_parent_died()

    # 2. 设置进程标题
    setproctitle.setproctitle(f"sglang::scheduler_{tp_rank}")

    # 3. CPU 亲和性设置
    set_gpu_proc_affinity(server_args, gpu_id, tp_rank)

    # 4. NUMA 绑定
    numa_bind_to_node(gpu_id)

    # 5. 创建 Scheduler 实例
    scheduler = Scheduler(
        server_args=server_args,
        port_args=port_args,
        gpu_id=gpu_id,
        tp_rank=tp_rank,
        pp_rank=pp_rank,
        ...
    )

    # 6. 发送初始化信息回主进程
    pipe_writer.send(scheduler.get_init_info())

    # 7. 运行事件循环 (阻塞)
    scheduler.run_event_loop()
```

```python
def run_detokenizer_process(server_args: ServerArgs, port_args: PortArgs):
```

## 四、进程间通信 (IPC)

### 4.1 ZMQ 通信架构

SGLang 使用 ZeroMQ 进行进程间通信：

```
┌─────────────────┐                      ┌─────────────────┐
│ TokenizerManager│                      │    Scheduler    │
│   (主进程)       │                      │    (子进程)      │
└────────┬────────┘                      └────────┬────────┘
         │                                        │
         │        scheduler_input_ipc             │
         │ ────────────────────────────────────► │
         │        ZMQ PUSH → ZMQ PULL             │
         │                                        │
         │           tokenizer_ipc                │
         │ ◄──────────────────────────────────── │
         │        ZMQ PUSH → ZMQ PULL             │
         └────────────────────────────────────────┘

┌─────────────────┐                      ┌─────────────────┐
│    Scheduler    │                      │  Detokenizer    │
│    (子进程)      │                      │    (子进程)      │
└────────┬────────┘                      └────────┬────────┘
         │                                        │
         │         detokenizer_ipc                │
         │ ────────────────────────────────────► │
         │        ZMQ PUSH → ZMQ PULL             │
         └────────────────────────────────────────┘
```

```python
def _load_weights(self, model_path: str):
    """加载权重文件"""
    # 1. 扫描权重文件
    weight_files = scan_weight_files(model_path)

    # 2. 并行加载 (多线程)
    weights = {}
    with ThreadPoolExecutor() as executor:
        futures = [executor.submit(load_file, f) for f in weight_files]
        for future in futures:
            weights.update(future.result())

    return weights
```

## 七、内存池初始化

### 7.1 KV Cache 预分配

**文件位置**：`python/sglang/srt/mem_cache/memory_pool.py`

```python
def init_memory_pool(
    server_args: ServerArgs,
    model_config: ModelConfig,
    ...
):
    # 1. 计算可用显存
    total_gpu_memory = torch.cuda.get_device_properties().total_memory
    available_memory = total_gpu_memory * server_args.mem_fraction_static

    # 2. 减去模型权重占用的内存
    model_memory = get_model_memory_usage(model)
    kv_cache_memory = available_memory - model_memory

    # 3. 计算 KV Cache 槽位数量
    kv_cache_size = kv_cache_memory // (
        model_config.num_layers * 2 *  # K 和 V
        model_config.hidden_size *
        model_config.dtype.itemsize
    )

    # 4. 创建内存池
    req_to_token_pool = ReqToTokenPool(
        size=max_running_requests,
        max_context_len=model_config.max_context_len,
        device="cuda",
    )

    token_to_kv_pool = MHATokenToKVPool(
        size=kv_cache_size,
        dtype=model_config.dtype,
        head_num=model_config.num_attention_heads,
        head_dim=model_config.head_dim,
        layer_num=model_config.num_layers,
        device="cuda",
    )

    return req_to_token_pool, token_to_kv_pool
```

## 十、总结

### 10.1 初始化要点

1. **多进程架构**：TokenizerManager 在主进程，Scheduler 和 Detokenizer 在子进程
2. **ZMQ 通信**：使用 PUSH/PULL 模式进行单向通信
3. **管道同步**：使用 `mp.Pipe` 进行初始化结果同步
4. **内存预分配**：启动时预分配 KV Cache 内存池

### 10.2 关键配置

- `mem_fraction_static`：控制 GPU 内存预分配比例
- `tp_size/pp_size/dp_size`：控制并行策略
- `load_format`：控制模型权重加载方式

### 10.3 常见问题

1. **内存不足**：调低 `mem_fraction_static`
2. **加载慢**：使用 `safetensors` 格式
3. **多卡问题**：检查 CUDA_VISIBLE_DEVICES 设置
